# 持续补充实验结果（2026-10-08）

## CGC 危险意图覆盖扩展

在完整 JailbreakBench 和 XSTest 文件上使用冻结规则重跑，不使用 LLM Judge：

| 版本 | JBB 有害召回 | JBB 误拦 | XSTest unsafe 召回 | XSTest safe 误拦 |
|---|---:|---:|---:|---:|
| 初始完整规则 | 33.0% | 1.0% | 14.5% | 1.6% |
| 扩展组合意图规则 | **61.0%** | 5.0% | **48.5%** | 12.0% |

扩展规则显著提高了危险意图覆盖，但误拦也明显上升。当前版本不应直接作为最终版本；下一步应引入第二阶段语义判别器或人工标注校准，寻找更好的 Precision—Recall 工作点。

## MM-FOPD 独立输出攻击代理

新增了最终任务卡中的敏感值匹配攻击指标（阈值 0.5/0.6/0.7/0.8）。当前 test 结果中，敏感值在最终任务卡中被直接恢复的比例仍为 0；这说明任务卡存在摘要化和脱敏，但不能证明抵抗了语义属性推断。真正的属性推断攻击仍需独立 shadow attacker，后续不能用当前 0 值冒充完整隐私证明。

同时保留选择层连续指标：MM-FOPD 的平均选中敏感度为 0.465，阈值 0.5/0.6 的选择暴露率为 0.045/0.018，必要单元召回为 0.799，单元 F1 为 0.866。

## HSW-ST 摘要攻击补充

新增“来源锚点恢复”分析，将它与盲水印检测分开：

| 攻击 | 盲水印 ADR | 来源锚点恢复率 |
|---|---:|---:|
| 删除句子 | 1.00 | 0.833 |
| 中间截断 | 1.00 | 0.250 |
| 干净文本混合 | 1.00 | 1.000 |
| 轻度释义 | 1.00 | 1.000 |
| 摘要式压缩 | 0.25 | 0.083 |

来源锚点恢复不是水印检测，不能合并成一个更好看的 ADR。摘要攻击仍然是实际短板，后续需要在输出中加入可审计的短来源锚点或使用语义指纹恢复机制。

局部窗口检测的探索性检查显示，在摘要攻击上阈值 `z>2.5` 时检测率为 `4/12=0.333`，12 条干净对照误报为 `0/12`；该阈值未冻结，因此只作为后续实验候选，不写入主结果。

## 当前结论

本轮完成了覆盖率扩展、独立输出匹配攻击代理和来源锚点分析，但没有把不兼容的指标合并成 SOTA 结论。CGC 的主要问题从“覆盖不足”转化为“覆盖—误拦权衡”，HSW-ST 的主要问题仍是摘要压缩，MM-FOPD 的主要缺口仍是独立属性推断攻击。
