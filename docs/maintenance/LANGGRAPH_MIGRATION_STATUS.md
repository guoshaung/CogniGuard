## 严格全项目口径仍有边界

- 用户确认纯计算函数保留、由图统一调度。活跃保护/Agent/评测主路径内部已按阶段或回合迁图；历史直接 CLI 仍保留兼容，算法内部的纯计算循环不强改。Vendored 上游代码和测试不纳入注册表。原本就缺失 `fopd_c2rag_mvp` 包及数据/配置的 5 个归档入口无法保留其旧功能；如需恢复，必须取得原始依赖与数据，不以当前算法伪装历史结果。
- focused 已去除旧线程池编排，但失败后恢复和 manifest 版本仍是工程改进项；真实 MiMo 的全矩阵配对未获本轮离线验收授权。
- 课堂学习阶段由图实际分阶段调度，现有长生成器仍可进一步拆成独立纯函数以降低维护成本；这不改变当前阶段顺序和调用边界。
- 全量目录解决的是导航、计划/执行入口和新运行索引的统一，不宣称 148 个 `compatible` 项的内部输出格式、默认写入位置或外部副作用已逐项标准化；其中大量脚本仍按 `unreviewed` 风险分类。旧 CLI、图矩阵与专项仍有不同的内部结果文件，统一索引不是历史制品转换。源码目录保留以维护相对导入与冻结结果的可复现性。
- 新的内容校验只覆盖明显交接指令与当前二次函数顶点事实；对隐蔽转述、多跳串通、其他学科和真实模型变化没有安全保证。可信降级能在这些合成攻击下给出基础规则答案，但不等同于原教师团队的教学效用。SQLite 只存元数据，不是完整敏感日志仓库。
