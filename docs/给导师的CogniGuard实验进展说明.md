# CogniGuard 实验进展与后续研究说明

老师您好：

近期我主要围绕 CogniGuard 的实验验证部分继续推进。目前工作已经从前期的功能 demo 和单模块验证，推进到第一轮较完整的端到端实验闭环。整体目标是验证该系统是否能够在教育智能体场景下，同时处理学生隐私保护、教师资源版权保护、生成内容可审计追踪，以及跨模块治理控制这几类问题。

这份说明主要汇报当前已经完成的实验工作、初步结果、目前还存在的不足，以及后续希望请老师帮助把关的几个关键问题。

## 一、当前研究定位

CogniGuard 当前的研究对象是教育场景中的智能问答/辅导系统。系统面对的核心风险不是单一的数据泄露问题，而是多个风险在教育流程中的叠加：

1. 学生画像可能被过度暴露，例如完整学习记录、身份信息、学校信息、家庭背景等被发送给下游模型。
2. 教师资源可能被模型连续问答重构，例如题库、讲义、解析过程、教学设计被过度复现。
3. 生成内容缺少审计链路，后续难以判断回答是否来自受控资源、是否触发过风险控制、是否被篡改。
4. 隐私、版权和审计风险之间可能相互放大，而不是彼此独立。

因此，我目前将 CogniGuard 的论文主线暂定为：

> 面向教育智能体的学生隐私、教师版权与生成内容审计的协同保护机制。

系统中主要包含三类核心机制和一个横向治理控制器：

- MM-FOPD：面向学生画像的最小必要上下文披露，降低学生隐私暴露。
- C2-RAG：面向教师资源的版权受控检索增强生成，降低原文重构和资源泄露风险。
- HSW-ST：面向生成内容的语义水印和来源追踪，增强生成内容可审计性。
- CG：横向治理控制器，用于约束跨层数据流、权限访问、删除请求和高风险调用。

## 二、本阶段已经完成的实验工作

本阶段我完成了第一轮较完整的实验流程，重点不是只验证某个单点模块有效，而是验证系统从数据构建、攻击场景、防护机制、协同效果、稳定性分析到测试验证的完整链路是否能够跑通。

当前实验数据包括：

| 项目 | 当前规模 |
|---|---:|
| 混合数学题目 | 240 道 |
| 合成学生画像 | 24 个 |
| 教师资源条目 | 253 条 |
| 题目来源 | GSM8K、AQuA-RAT、TheoremQA |

当前已经完成的实验包括：

1. 单机制效果实验：分别评估学生画像保护、教师资源版权控制和审计追踪机制。
2. 联合协同实验：比较无保护、单机制、双机制、完整系统、完整系统加 CG 的风险变化。
3. 多次采样稳定性实验：随机采样机制超参数，并固定 JointRisk 的等分聚合定义，观察结论是否只依赖某一组参数。
4. 闭环反馈实验：验证 FOPD、C2-RAG、HSW-ST、CG 之间是否存在实际反馈关系。
5. 交叉层风险实验：观察隐私、版权、审计、权限风险是否存在相互放大或相互抑制。
6. 攻击与回归测试：覆盖隐私抽取、版权重构、越权访问、提示注入、水印扰动等风险场景。
7. 基础消融实验：初步观察关键组件移除后对整体保护效果的影响。

## 三、当前初步实验结果

### 1. 联合保护结果

在 mixed math suite 上，Full CogniGuard+CG 的 JointRisk 明显低于无保护、单机制和最优双机制组合。

| 方法 | JointRisk | 说明 |
|---|---:|---|
| 无保护 | 1.0000 | 作为风险上界参考 |
| 最优双机制 FOPD+HSW-ST | 0.3803 | 当前双机制组合中的最好结果 |
| Full CogniGuard+CG | 0.0686 | 三机制协同并加入横向治理控制 |

从结果看，完整系统相对于最优双机制仍然有进一步下降，synergy gain 为 0.3117。这说明当前系统不是简单依靠某一个模块，而是三类保护机制联合后产生了额外收益。

### 2. 稳定性实验结果

为了避免结果只是由某组默认参数调出来的，我做了 64 组随机采样，并进行了 1000 次 bootstrap 统计验证。

| 指标 | 结果 |
|---|---:|
| 采样组数 | 64 |
| bootstrap 次数 | 1000 |
| Full+CG 优于最优双机制的比例 | 1.0000 |
| Full+CG 优于最优单机制的比例 | 1.0000 |
| 相对最优双机制的平均协同收益 | 0.2706 |

这组结果说明，在当前实验设定下，Full+CG 的优势不是某一次运行中的偶然现象。不过，这仍然需要在更真实的教育任务和更强 baseline 下继续验证。

### 3. 闭环反馈实验结果

我进一步验证系统中的模块是否真的存在交互，而不是简单串联。

| 指标 | 结果 | 含义 |
|---|---:|---|
| ambiguous retrieval top-1 shift rate | 0.6417 | 学生最小上下文会改变 C2-RAG 的检索结果 |
| HSW-ST return-mode downgrade rate | 0.7833 | 审计风险反馈会促使资源返回模式降级 |
| CG cross-layer block rate | 1.0000 | 构造的跨层高风险请求被治理控制器拦截 |
| closed-loop cross-layer risk | 0.0108 | 闭环控制后的交叉层风险 |
| independent cross-layer risk | 0.6280 | 独立模块情况下的交叉层风险 |

这部分结果主要用于回应一个可能的质疑：CogniGuard 是否只是把几个模块拼在一起。当前结果显示，模块之间存在实际的信息反馈路径，例如学生上下文会影响教师资源检索，审计风险会影响资源返回模式，治理控制器会约束跨层数据流。

### 4. 版权保护实验结果

在教师资源版权保护部分，我比较了普通 RAG 和 C2-RAG-full 的版权泄露情况。

| 方法 | copyright leakage |
|---|---:|
| Plain RAG | 1.0000 |
| C2-RAG-full | 0.2707 |

当前结果说明，加入曝光预算、返回模式控制、资源溯源和变式生成后，可以明显降低教师资源被原文重构的风险。后续仍需要进一步明确“教师资源泄露”的评价标准，例如题目原文、解析过程、讲义内容、教学设计是否应采用不同的泄露判定规则。

## 四、目前结果的含义

我对当前结果的理解是：第一轮实验已经能够支持 CogniGuard 的研究方向是可验证的。

具体来说：

1. 学生隐私保护方面，系统可以通过最小必要上下文减少学生画像暴露，而不是把完整画像直接交给下游模型。
2. 教师版权保护方面，系统可以通过受控检索、曝光预算和返回模式控制减少教师资源被重构的风险。
3. 审计追踪方面，系统可以记录资源来源、输出控制和风险反馈，为后续追责和验证提供依据。
4. 协同保护方面，实验显示完整系统优于单机制和双机制组合，说明隐私、版权、审计之间存在一定协同价值。

但我也认为当前结果还不能直接作为最终论文结论。现在更适合表述为：

> 已完成第一轮端到端实验验证，结果初步支持系统设计方向，但仍需要在更真实的教育任务、更严格的 baseline、更清晰的评价口径下继续补强。

## 五、当前存在的不足

目前实验中仍有几个不足，我希望后续重点改进。

1. 学生画像主要是合成数据，虽然便于控制变量和避免真实隐私问题，但真实教育场景的复杂性还不够。
2. 教师资源版权边界还需要进一步明确，例如原题、解析、讲义、课件和教学设计是否应采用不同保护标准。
3. JointRisk 是聚合指标，虽然便于比较整体风险，但论文中需要更清楚说明各分项指标的定义；当前已改为按三类子机制风险轴等分聚合，并将 CG 的访问控制与篡改控制风险合并为一个 CGControlLeak，避免引入缺少依据的经验权重。
4. 当前 baseline 还可以继续增强，尤其是与已有隐私保护 RAG、版权检测、访问控制和智能体安全方法的对比。
5. HSW-ST 的完整大模型消融实验还没有完全跑完，目前只完成了 dry-run 和轻量验证。
6. 当前实验主要是数学问答任务，后续可以考虑扩展到作业辅导、错题推荐、教师题库辅助生成等更具体的教育场景。

## 六、下一步计划

下一阶段我计划重点补充以下工作：

1. 收敛论文主线，明确最终是突出“学生隐私保护”，还是突出“学生隐私、教师版权、生成审计的协同保护”。
2. 选择一个更具体的教育应用场景，例如作业辅导、错题推荐、教师题库保护或课堂智能体。
3. 进一步完善攻击实验，增加更直观的攻击案例和防护前后对比。
4. 补充更强 baseline，包括隐私脱敏、权限访问控制、普通 RAG、版权检测和智能体安全防护方法。
5. 完善消融实验，分别移除 FOPD、C2-RAG、HSW-ST、CG 中的关键组件，证明每个组件的必要性。
6. 优化论文图表，将 Mermaid 架构图导出为 SVG 或高清图片，避免直接在文档中渲染过小。
7. 补齐 HSW-ST 的完整模型加载式消融实验。

## 七、希望老师指导的问题

我想重点请老师帮我把关以下几个问题：

1. 论文主线是否应该定为“教育智能体中的隐私、版权、审计协同保护”，还是应该收窄为“学生画像隐私保护”或“教师资源版权保护”中的一个方向？

## 八、总结

总体来看，本阶段已经完成 CogniGuard 的第一轮完整实验验证。实验从早期 demo 推进到了可复现的数据集、攻击场景、保护机制、协同验证、采样稳定性和测试验证流程。当前结果初步表明，Full CogniGuard+CG 在学生隐私保护、教师资源版权保护和生成内容审计方面具有协同保护效果。

不过，目前结果仍属于第一轮验证性实验。后续我会根据老师意见，进一步收敛论文主线、明确实验场景、完善评价标准和 baseline 对比，使实验结果更适合支撑论文写作。

希望老师能帮我重点指导论文主线、实验场景和评价指标这几个关键问题。
