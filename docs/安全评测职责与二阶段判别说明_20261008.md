# 安全评测职责与二阶段判别说明

## 二阶段判别是什么

二阶段判别是常见的级联结构：第一阶段用快速规则筛出高风险和边界样本，第二阶段只对边界样本使用更细的语义判别器。它不是再增加一个业务保护模块，也不改变 C²-RAG、MM-FOPD 或 HSW-ST 的职责。

```text
CGC 输入层
  第一阶段：规则/模式快速筛查，高召回
  第二阶段：语义判别或独立安全分类器，降低误拦
  最终：allow / sanitize / refuse / block
```

这类“规则或轻量分类器 + 精细判别器”的级联是安全系统常用工程模式，但 CGC 尚未完成第二阶段的独立模型评测。因此当前全量结果必须保留为规则适配器结果，不能声称已经达到成熟安全框架水平。

## MM-FOPD 与属性推断攻击的职责

- MM-FOPD：只负责选择和压缩最小画像卡；
- 属性推断攻击器：单独位于 `experiments/attacks/profile_attribute_inference.py`，只读取最终卡片，尝试推断敏感属性；
- 防护指标：攻击成功率、攻击者 TPR/FPR、隐私风险降低率；
- 该攻击器不修改 MM-FOPD，也不参与画像选择。

当前 shadow attacker 仍属于低能力原型，不能把其 0% 推断率当作隐私证明；下一步需要用独立 shadow profiles 训练分类器，再在 held-out 学生上测试。

## HSW-ST 摘要攻击口径

盲水印 ADR 和来源锚点恢复是两个指标：

- 盲水印 ADR：攻击后检测器是否仍判断有水印；
- 来源锚点恢复：攻击后关键术语、公式和数字是否还能恢复来源。

当前摘要攻击盲 ADR 为 0.25；局部窗口阈值 2.5 的 exploratory detection 为 0.333，干净对照误报为 0/12。这是探索性结果，不能替代冻结阈值下的主 ADR，也不能通过降低阈值直接改写主表。
