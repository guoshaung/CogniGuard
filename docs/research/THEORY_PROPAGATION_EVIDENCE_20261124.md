# 未记录传播与证据：理论核对（2026-11-24）

> 只做理论分析，不修改 `FORMAL_DEFINITION_v0.1.md`，也不修改冻结的实验。
> 第 2、3 节的命题都已经用小规模穷举验证过，脚本见 `docs/research/theory_checks/`，结果见第 6 节。穷举验证不能代替证明，证明写在各命题下面。

## 1. 模型

- 主体集合为 V，|V| = N。单元全集为 U。见证集 W ⊆ U。
- **已确认状态** O(v)：回执中记录的、v 持有的单元，包括已预留和已交付的。
- **真实状态** H(v)：在 O(v) 的基础上，加上通过未记录传播获得的单元。
- **未记录传播事件** e = (u → v, S, t)：在时刻 t，v 获得 S，并且 S ⊆ H_t(u)。

**前提 P0（知识来源封闭）**：每个单元最初都只能由系统交付产生，也就是说它一定出现在某个 O 里。外部背景知识不在本模型之内，它由 A2 和先验单独处理。

**k-安全**：任意 |C| ≤ k 的联盟都不满足 W ⊆ ∪_{v∈C} H(v)，对每个违规见证 W 都成立。

## 2. 任意主体可以通信时

**命题 1（上界，始终成立）**。设 P0 成立，并且全部历史中未记录事件的**总数** ≤ f。事件可以发生在任意一对主体之间，可以转发任意内容（包括全部持有），可以按任意顺序链式转发。那么：如果 O 是 (k+f)-安全的，H 就是 k-安全的。

**证明**：任取 |C| ≤ k 的联盟，以及 x ∈ ∪_{v∈C} H(v)。沿着把 x 送进 C 的事件链往回追溯，可以找到最早持有 x 的主体 w，并且 x ∈ O(w)（由 P0）。w 要么属于 C，要么是某个事件的发送方。

定义 Src(C) = C ∪ {所有以 C 为终点的事件链上的发送方}。每个事件只有一个发送方，所以 |Src(C)| ≤ k + f，并且 ∪_C H ⊆ ∪_{Src(C)} O。

如果 C 违规，那么 Src(C) 就是 O 上一个人数 ≤ k + f 的违规联盟，与"O 是 (k+f)-安全的"矛盾。∎

**命题 2（精确等价，需要四个条件）**。同时满足下面四条时，"存在一种合法的传播情形，使 H 不是 k-安全的"，**当且仅当** O 不是 (k+f)-安全的：
- (E1) 任意一对主体之间都可以直接通信；
- (E2) 每个事件都可以转发发送方的全部持有；
- (E3) f 是**事先确定的总事件数上限**；
- (E4) 时间上没有其他约束：事件可以发生在发送方持有之后的任何时刻。

**证明（反方向）**：设 C' 是 O 上一个违规联盟，|C'| ≤ k + f。如果 |C'| ≤ k，不需要任何事件。否则，取任意 k 人子集 C ⊂ C'，对 C' − C 中的每个人（不超过 f 个），各安排一次事件，把他的全部持有直接转给 C 中的某一人。这样只用了不超过 f 个事件，C 就凑齐了 W。∎

**有证据时的推论**：在已确认的状态上加入 d 个**可信的事件证明**（每个证明对应一个真实发生、互不重复、并且计入 f 的事件），剩余的不确定预算是 f − d。在 E1–E4 下，判定精确地变成：在更新后的 O 上检查 k + (f − d) 人的联盟。

任何一个条件不成立时，k+f 和 k+(f−d) **只是最坏情况的上界**（命题 1 依然成立），不再精确等价。下面逐一说明。

## 3. 受约束的传播：k+f 不再精确

> 传播约束必须来自**可验证或可强制执行的系统行为**，例如沙箱网络策略、工具权限、通道的消息大小上限、平台对未中介转发的配额。不得用社会关系排除潜在的合谋者：联盟仍然是**任意** ≤ k 人。

### 3.1 通信图约束（E1 不成立）

只有图 G 中的边能进行未中介的传播，例如共享工作区、未经中介的工具通道。被中介的通道都会写回执，所以本来就计入 O。

**命题 3（精确判定）**。在 E2–E4 下，存在违规情形，当且仅当存在一组持有者 T，满足：
- T 的已确认持有合起来覆盖 W；
- T 可以划分成不超过 k 个簇；
- 各簇在 G 上的**最小 Steiner 树边数**之和 ≤ f。

**理由**：一个簇在 G 上的 Steiner 树有 t 条边，把每条边朝某个根定向，恰好需要 t 次转发，就能把整簇的知识汇集到根上；根作为联盟成员，占一个 k 名额。树中可以包含不持有任何单元的中继主体。反过来，任何 ≤ f 次的转发方案，都可以把联盟中每个成员的知识来源组织成一棵连通的转发树，所以总边数至少等于各簇 Steiner 树的边数之和。

**计算**：每个簇用 Dreyfus–Wagner 算法求 Steiner 树，再对持有者的子集做划分 DP。代价是指数级的，指数是相关持有者的数目 h。h 超过上限时，**退回到命题 1 的 k+f**。这样做仍然是安全的，代价是变保守。

### 3.2 部分转发（E2 不成立）

假设每个事件最多转发 s 个单元，例如通道有可强制执行的消息大小上限。此时命题 1 仍然成立，但只是上界：k+f 会过度拒绝。这种情况下的精确判定，要把"转发单元数"作为第二种资源，本轮不实现。

### 3.3 时间约束（E3、E4 不成立）

- 如果只有**速率限制**（每个时间窗口最多 f 次），而没有总量上限，那么在足够长的时间里，未记录事件的总数没有上界。由于知识不会遗忘，最坏情况会退化为全体并集。所以**有确定性保证的模型必须有总量上限 f**。
- 如果有可强制执行的时间窗口（例如会话结束后，通道就关闭），可以在每个窗口内各自使用命题 1 或命题 3，但跨窗口的预算要累加。

### 3.4 内容范围约束

如果某些通道只能传递某几类单元（例如工具通道会过滤保密字段，这可以由系统强制执行），就在命题 3 的转发中只允许移动这些单元。属于"部分转发"的特例，本轮不实现。

## 4. 证据：两种证据，以及错误归因的安全后果（修正）

### 4.1 两种证据必须区分

| | 持有证据 P(v, r) | 事件证明 Ev(u → v, id) |
|---|---|---|
| 含义 | v 产生的内容中，出现了源自回执 r 的内容 | 一次未中介传播**确实发生**过，带有唯一的事件编号 |
| 来源 | 水印检出、指纹匹配、内容检索 | 可信通道的签名日志、平台计数器、受信中介的证明 |
| 用法 | 把 r 的单元加入 O(v) | 在 O 上固定这次事件，并把**剩余预算减 1** |
| 伪造或错误时的后果 | O 被高估，**只损害可用性** | 预算被**低估**，**可能导致漏防** |

**普通的水印检出只是持有证据，不能当作事件证明。** 理由如下：
- 检出不能说明内容是**由谁**、在**什么时候**、经过**几次**转发到达的：同一段内容可能经过多次中继，也可能是被一次转发同时带给了多个人；
- 检出也不能说明这次传播是否属于计入 f 的那一类：它可能经过了被中介的通道，那本来就已经写了回执。

### 4.2 预算扣减的安全条件（修正上一版的结论）

上一版说"错误归因只损害可用性"。这只对**持有证据**成立。一旦拿证据去扣减剩余预算，就可能出安全问题：
- **伪造或重复**的事件证明，会让 d 偏大，f − d 偏小，从而在联盟检查中少检查了人数，造成**漏防**；
- **错误归因**：如果把真实事件 (u → v) 记成了 (u → v')，那么 d 计数没有变，但 v 的真实持有没有被固定到 O 上，同时预算又被扣掉了一次。真实情况是 v 已经持有，而系统以为只剩 f − d 次未知事件，结果同样会造成**漏防**。

所以，**只有同时满足**下面三条时，才可以使用 f − d：
1. f 是**事先约束、可强制执行的总事件预算**，而不是"目前估计的未知事件数上限"。如果 f 只是一个估计，那么发现 d 个事件并不会减少未知事件的数目，f − d 也就没有意义；
2. 每个事件证明都是真实的、可以去重（按事件编号），并且确实是计入 f 的那一类事件；
3. 被证明的事件，其内容按最坏情况（发送方当时的全部持有）写进接收方的 O。

### 4.3 推论

- 持有证据可以**随时**安全地加入 O，只会让判定更保守；
- 在有确定性保证的模式下，水印和指纹都只能提供持有证据。它们的作用是**发现**系统没有记录到的持有，而不是**放宽**判定；
- 能放宽判定的只有可信的事件证明。它来自可强制执行的通道，**与水印无关**。

**这直接影响水印的定位。** 在有确定性保证的模式下，水印的价值只能来自"发现了指纹没有发现的持有"。见第 5 节和 Gate W0。

## 5. 水印与内容指纹（为 Gate W0 提供的理论预测）

先区分三种身份：
- **内容身份**：这段文本源自哪份已交付的内容。指纹和检索就能识别；
- **发行身份**：这份内容交给了谁、对应哪张回执。水印可以携带不透明的回执 ID；**主动文本变体**（给每个接收者一个不同的版本）配合指纹检索，也能识别；
- **传播事件**：内容是怎样从一个主体到达另一个主体的。**两者都不能证明**（第 4.1 节）。

**预测**：在有确定性保证的模式下，系统需要的是"**观察到这段内容的主体 v** 持有哪些单元"。这只取决于内容身份。发行身份告诉我们内容是从哪位原始接收者那里流出来的，可是那位接收者本来就有回执记录，不会改变 v 的持有。

所以，在下面这些情况中，理想水印**预计不会**比强指纹带来额外的安全收益：
- 唯一内容；
- 同一内容发给了多个人（来源有歧义，但 v 的持有并不受影响）；
- 指纹和检索都能识别出内容的情况。

水印**可能**有额外价值的情况：
- (a) **多来源融合**后，留下的只是很短的片段，指纹或检索失效，而按片段嵌入的水印仍然可以恢复；
- (b) 强改写之后，指纹失效，而水印保留下来（这与 HSW-ST 的负结果相矛盾，需要实测）；
- (c) 在有通信图约束的判定（命题 3）里，知道原始接收者是谁，可以缩小可能的传播路径。但只要这些信息没有升格为可信的事件证明，就不能用来扣减预算。

Gate W0 会逐一检验这些情况。

## 6. 小规模穷举验证结果

脚本：`docs/research/theory_checks/check_props.py`、`check_partial.py`。规模：4–6 个主体，5 个单元，k ∈ {1, 2, 3}，f ∈ {0, 1, 2}，两个随机种子。

| 检验 | 结果 |
|---|---|
| 命题 2：任意通信、全部转发时，穷举结果与 (k+f)-联盟检查一致 | 800/800 |
| 命题 3：通信图约束下，穷举结果与 Steiner 划分判定一致 | 800/800 |
| 通信图约束下，k+f 判为不安全、而精确判定为安全的实例 | 17/800（2.1%） |
| 部分转发（每次最多 1 个单元）时，k+f 漏判 | 0/300 |
| 部分转发时，k+f 过度拒绝 | 2/300 |

在这么小的规模上，细粒度建模带来的放宽很有限。它能否在 Gate 1B 的规模（N = 60，稀疏图）上带来**有意义的可用性收益**，要靠实验回答。
