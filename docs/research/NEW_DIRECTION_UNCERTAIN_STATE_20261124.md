## 3. 理论漏洞（必须先解决，否则闭环没有清晰的保证）

### 3.1 核心两难：最坏情况的保证与证据的价值互相冲突 [R]

- 如果 Ω 必须**覆盖所有可能的未记录传播**，才能给出确定性保证，那么证据就**不会带来安全收益**：证据揭示的传播本来就已经在 Ω 之内了。
  - 而且在不加限制的情况下，Ω 的上界就是"每个主体都可能知道所有主体知道的东西"。这等价于全体并集记账，也就是 crowd control 或 union_view(0)，结果是大量拒绝。
- 如果 Ω **只包含有证据的传播**（乐观更新），证据确实能拦下更多后续泄露，但**没有确定性保证**：没有留下证据的传播仍然会漏掉。
- **证据只能抬高知识的下界，不能证明某个主体不知道什么。** 所以在有保证的模式下，证据永远不能让系统放行更多内容；它只能用来解释"为什么要拒绝"，或者把一部分不确定的传播固定为已知传播。

**唯一能让两者兼容的形式**，是**有界的未记录传播**。

### 3.2 有界未记录传播可以归约为更大的 k [R]

**命题（草案）**：假设未记录的转发**最多 f 次**，并且每次转发最坏会把发送方的全部持有转移给接收方。那么，"≤ k 人的联盟在 ≤ f 次未记录转发之后仍然安全"，就**等价于**在 K_obs 上检查"≤ k + f 人的联盟"。

- 理由：f 次转发最多能把 f 个联盟外主体的持有带进联盟，链式转发也包括在内。反过来，任何 k + f 人的联盟，都可以通过 f 次转发，把其中 f 个人的持有集中到 k 个人手里。
- 有了证据之后：如果已经确认了 d 次转发，就把它们写进 K_obs，剩下的不确定预算是 f − d。判定变成在更新后的 K_obs 上检查 k + (f − d) 人的联盟。
- **这意味着**："不确定状态下的鲁棒控制"在这个模型里，**可以直接复用现有的 `check_release`**，只要调整 k 和 knowledge。
  - 优点：实现简单，正确性直接继承 CA-PD；
  - 风险：新机制在算法上可能被看作"CA-PD 加上一个更大的 k"，算法新意很小。新意只能来自"证据如何安全地降低 f − d"，以及"水印如何提高 d"。

**还要单独研究的情况**：
- 只转发**部分**单元。最坏情况仍按全部持有处理，否则要扩展 DP；
- 转发只能沿**通信图**进行。这时 Ω 可以用图上的闭包更精确地近似，不必直接把 k 加大到 k + f。

### 3.3 已经发生的泄露与还能阻止的泄露 [R]

- 同步文件中的例子：B 实际上已经有 a、b，C 有 c，那么 {B, C} **已经**可以恢复秘密。此时任何后续的披露控制都无济于事；只有当 c 还没有发给 C 时，才有东西可以拦。
- 因此，Gate 0 必须把实际发生的违规分成两类：
  - **无法阻止的**：违规在任何后续披露之前就已经存在；
  - **披露导致的**：违规是由一次放行造成的，而掌握真实状态的系统（Oracle）会拒绝这次放行。

  **闭环的价值，只能用第二类来衡量。**

### 3.4 威胁模型需要收窄 [R]

- 恶意的合谋者可以改写文本来去掉水印，也可以干脆不让内容重新进入受控系统。所以，内容内证据主要能捕获的是**非恶意的传播**：工具调用、记忆共享、流水线转发、主体的误操作。
- 论文中的威胁模型应当写成：**诚实但会泄露的主体**之间未被记录的传播，加上有界的恶意合谋。不能声称水印能对抗恶意合谋者主动隐藏的传播。

### 3.5 证据的语义 [R]

- 检出水印，只能说明"这段文本的来源里有回执 r"，不能说明"某个主体掌握了 r 的全部单元"。保守的做法是把检出看作持有 r 的全部单元。这样做是安全的，但会增加拒绝。
- **伪造或错误归因**会把某个主体的持有估计得偏高，它只伤害可用性（被当作拒绝服务攻击的手段），不伤害安全性。**漏检**才伤害安全性，但只在乐观模式下如此。这种不对称性要写进论文。
- **内容指纹**：服务器本来就保存着已交付的文本，可以直接用指纹匹配来检测内容的重新进入，不需要嵌入任何东西。只有当文本经过了**指纹失效、但水印还能保留下来**的变换时，水印才有额外价值。HSW-ST 之前的负结果显示：指纹在部分实验中优于水印，连续重水印会导致错误归因，强的跨模型改写会破坏归因。所以 Gate 3 是决定性的一步。

### 3.6 A1、A2 仍未通过

E3b-v2 显示：真实改写下，计量漏判约 40%；谓词超标约 36%。这与状态失真是**两个独立的问题**，水印解决不了。新主线的保证仍然以 A1、A2 为前提，必须在论文中如实写明。

## 7. 是否建议正式调整主线

**现在不建议正式调整。建议先跑 Gate 0–2，再做决定。** 理由如下：

1. 第 3.1 节的两难决定了：要有确定性保证，就只能用有界未记录传播的模型；而在这个模型下，鲁棒控制会归约为更大的 k（第 3.2 节）。新意能否成立，取决于"证据降低 f − d"带来的**可用性收益**，这必须靠 Gate 1–2 测出来。
2. 如果 Gate 1 显示，在理想证据下，相比"直接用 k + f 的无证据鲁棒控制"，可用性的收益很小，那么水印和反馈就没有必要存在，应该停止。
3. 水印重新进入论文，会扩大范围；而 HSW-ST 已有的负结果显示，水印未必优于指纹。
4. 原有的 CA-PD 主线，加上 E9、E10，已经能支撑一篇范围较小、但能自洽的论文。新主线一旦被 Gate 否决，这条主线仍然是可行的退路。

**判定规则**：Gate 0 和 Gate 1 都通过，才进入 Gate 2；Gate 2 通过，才正式把新主线写成论文主线，并开始 Gate 3（真实水印）。
