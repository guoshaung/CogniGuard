# C²-RAG 本地合成教育数据四方法实验

## 实验设置

- 数据：mixed_math_suite dev split 的 65 个教师资源和 48 个 clean 查询。
- 候选范围：全部 65 个资源，检索前不按目标资源过滤。
- 目标映射：使用任务数据中的 `source_resource_id`，修正原先把合成笔记 ID 当作原始题目资源 ID 的配对问题。
- 方法：BM25、Dense、RRF、Late Interaction。
- 评价：Recall@10、Recall@100、MRR、MAP。

## 结果

| 方法 | Recall@10 | Recall@100 | MRR | MAP |
|---|---:|---:|---:|---:|
| BM25 | 1.000 | 1.000 | 1.000 | 1.000 |
| Dense | 1.000 | 1.000 | 1.000 | 1.000 |
| RRF | 1.000 | 1.000 | 1.000 | 1.000 |
| Late Interaction | 1.000 | 1.000 | 1.000 | 1.000 |
| Cross-Encoder on RRF | 1.000 | 1.000 | 1.000 | 1.000 |

## 解释

四种方法都已经在同一批本地开放候选资源上实际运行，但当前 65 个资源与 48 个查询的匹配关系过于容易：目标资源在词面和知识点上都非常明显，因此所有方法都能在前 10 命中。该结果可以证明代码、数据格式和评价链路正确，不能证明四种检索方法之间存在性能差异。

下一轮真实数据需要扩大候选库、增加相近知识点和难负样本，并保留公开许可字段。BEIR SciFact 的 300 查询实验已经证明，在真正开放的 5,183 文档候选库中，四种方法能够拉开差距：RRF 的 Recall@10 为 0.833，Late Interaction 的 MRR/MAP 分别为 0.674/0.666。
