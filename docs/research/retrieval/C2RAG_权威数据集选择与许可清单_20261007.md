# C²-RAG 权威数据集选择与许可清单

## 选定的数据集

### 1. BEIR SciFact：通用检索主基准

- 来源：BEIR 官方数据发布页。
- 规模：5,183 篇文档、300 条测试查询。
- 作用：比较 BM25、Dense、RRF、Late Interaction 和 Cross-Encoder 的开放候选检索质量。
- 指标：Recall@10/100、MRR、MAP。
- 当前结果：RRF 的 Recall@10 为 0.833；Late Interaction 的 MRR/MAP 为 0.674/0.666。
- 边界：它是科学文献检索，不是教育版权数据，因此只用于检索器验证。

### 2. TheoremQA：大学 STEM 教育领域数据

- 来源：TIGER-Lab 官方仓库。
- 论文：EMNLP 2023，`TheoremQA: A Theorem-driven Question Answering Dataset`。
- 规模：800 条人工标注问答，覆盖 350+ 个数学、电子计算机、物理和金融定理。
- 仓库许可：MIT；具体数据文件仍应在论文和仓库说明下使用。
- 作用：验证高等数学和 STEM 教育问题的领域检索、知识点匹配和教学回答。
- 边界：官方数据主要是问答，不直接提供教师版权文档和多轮攻击标签，不能直接当作完整版权安全基准。

### 3. GSM8K：基础数学教育数据

- 来源：OpenAI 官方 `grade-school-math` 仓库。
- 规模：约 8.5K 条高质量小学数学文字题。
- 作用：验证基础数学问题的领域检索、相似问题召回和教学回答效用。
- 边界：它是数学推理数据，不是检索安全或版权泄露数据；需要自行建立问题—资源检索协议，并单独报告数据许可和构造方式。

### 4. OpenStax：真实开放教材资源

- 来源：OpenStax 官方教材平台。
- 作用：建立真实教师资源库，用于 C²-RAG 的来源、版权预算、多轮重构和 HSW-ST 水印实验。
- 使用要求：逐本教材记录书名、章节、版本、来源 URL 和具体许可；只有明确允许再利用的内容才进入实验库。
- 边界：OpenStax 是资源库，不提供现成的版权攻击标签，需要用公开攻击模式构造正常—攻击配对。

## 主系统采用的算法

这些算法不是四个都堆叠成独立模块，而是分工组合：

```text
Dense：高召回候选
    ↓
RRF：融合词面和语义排序
    ↓
Late Interaction：候选精排
    ↓
C²-RAG：来源、版权预算、多轮状态和返回粒度控制
```

BM25 作为轻量词面基线；Cross-Encoder 作为精排对比方法。最终论文主结果采用 Dense + RRF + Late Interaction，其他方法用于消融和对比。

## 实验使用顺序

| 阶段 | 数据 | 目标 |
|---|---|---|
| 已完成 | BEIR SciFact | 验证四种检索算法能在开放候选库中拉开差距 |
| 下一步 | TheoremQA + GSM8K | 验证数学教育领域迁移，不把所有结果混成一个分数 |
| 冻结后 | OpenStax 许可教材 | 运行真实教育资源上的版权、多轮和水印实验 |
| 并行安全测试 | BIPIA | 评估检索内容中的间接提示注入隔离 |

## 数据与指标边界

- BEIR、TheoremQA、GSM8K 主要评价检索和教育任务效用。
- OpenStax 主要评价真实教育资源上的版权控制和水印保真。
- BIPIA 主要评价上下文中的间接提示注入。
- 合成学生画像继续用于 MM-FOPD 隐私实验，不把未经授权的真实学生数据放入项目。

因此，论文中应分别报告检索质量、教育效用、版权安全、水印鲁棒性和提示注入隔离，不把不同数据集的分数简单平均成一个总分。
