# 多智能体教学：交接污染与串通靶场

> 本页记录 2026-10-15 的历史先导实验。2026-10-16 新实验的代码、冻结数据及评分请看 [teacher_security/README.md](../../../experiments/teacher_security/README.md) 和 [源码地图](../../code-map.md)。新旧评分口径分别报告。

## 已接入的系统边界

教师提示词库和六套 DAG 拓扑仍由 `configs/teacher-prompts.yaml`、`configs/teacher-teams.yaml` 管理。每个节点只读其声明的最小任务字段；消息有运行时签名、拓扑绑定、标签范围和重放检查。`TeacherDAGGenerator` 默认启用 `handoff_guard_mode=enforce`，也可显式设为 `off/observe_only` 以做受控对照：在合法签名消息交给下游之前、以及最终答案交给学生之前，对明显的越权指令及本题可验证的顶点结论作窄范围检查。`on_blocked=fallback` 时，受阻节点不读取污染上游内容，而由可信的本地规则后端只凭最小任务视图生成替代答案；运行记录标为 `degraded`，不能等同于原模型完成教学。最终交付口有独立的数据库审计记录，防止汇总教师自身受污染时绕过交接边。已有的冻结公开基准适配器显式保持旧 `off` 口径，避免静默改写先前对照。

教师批次运行默认启用交接校验与可信离线降级，并在该次新输出目录写入 `teacher_audit.sqlite3`。数据库中的审计表只存运行、节点、边的状态、原因码和计数；另有版本化目录表，保存可信的 20 份教师系统提示词及 10 份教学技能指令。运行时先从可信 YAML 导入并核对哈希，再**从数据库读回**提示词/技能执行 DAG；不会只存一份不用的副本。库里不保存学生问题、画像、教师生成原文、攻击载荷或答案。提示词本身属于可信应用配置，应限制数据库文件访问。需要让其他 `TeacherDAGGenerator` 调用持久化时，可将 `COGNIGUARD_TEACHER_AUDIT_DB` 指向一个受限访问的本地 SQLite 文件；未设置时不会为测试或普通调用悄悄创建数据库。

远端现有 MySQL 配置在只读连接探测中认证失败，LangGraph 环境也没有 MySQL 驱动；用户随后提供的单个候选口令经一次不回显的只读认证测试仍失败。没有继续轮试或改动 MySQL。使用标准库 SQLite 保持运行；后续如要接入 MySQL，应先用正式凭据和最小权限账号配置，不复用弱口令。

## 靶场与分层指标

```bat
run.cmd experiments show --name teacher-pollution-lab
run.cmd experiments plan --name teacher-pollution-lab --output experiments\results\langgraph_tool_jobs\teacher-lab-plan-new
run.cmd experiments run --name teacher-pollution-lab --output experiments\results\langgraph_tool_jobs\teacher-lab-run-new
run.cmd experiments show --name teacher-pollution-real
run.cmd experiments run --name teacher-pollution-real --output experiments\results\langgraph_tool_jobs\teacher-real-new --allow-model-calls --timeout-seconds 1800
```

靶场中攻击者控制一名或两名教师节点的输出；消息仍由合法节点签名，故能区分“来源有效”与“内容可信”。案例包括单节点角色伪装、单节点错误事实、两节点一致错误事实、两节点协同索取私密字段、最终汇总教师污染，以及两道正常二次函数题。离线入口使用确定性后端、不调用模型 API；真实入口让未受污染的教师节点调用同一 MiMo 模型，攻击节点仍是脚本化可控输出，单次硬上限 60 次模型调用。两者均不提供真实学生资料或攻击者网络工具。检测器只读交接文本和题目，攻击目标只由事后评分使用。

分别报告 `origin_only`、`content_guard`、`guard_with_fallback` 的污染到达、攻击回合中断、正常任务完成、降级次数和本题正确性代理，避免把“拒绝回答”冒充教学可用。来源验签无法发现拥有合法身份的恶意教师；本次窄范围校验可拦截所列脚本化攻击，但不提供对任意提示注入或串通的保证。SQLite 审计记录可核对每条边与最终交付口为何放行或隔离。

## 这次离线观察（2026-10-15）

最新版离线靶场固定 5 个攻击案例与 2 个正常对照，每个条件各运行一次，结果在 `experiments/results/langgraph_tool_jobs/teacher-pollution-lab-20261015-5/artifacts/`：

- 仅验签：污染到达最终输出 5/5，攻击回合中断 0/5；正常对照完成 2/2。
- 交接与最终输出校验：污染到达 0/5，但攻击回合中断 5/5；正常对照完成 2/2。
- 校验加可信离线降级：污染到达 0/5，攻击回合中断 0/5；固定题目正确性代理 5/5，正常对照完成 2/2；有 5 次教师降级，其中最终交付降级 1 次。

SQLite 中对应 21 次图运行、63 个教师节点、42 条交接边，并单独记了 2 次最终交付口拦截；同库另存 20 个提示词版本、10 个技能版本。标准教师组合的独立离线接线完成 3 道题、9 次教师节点、6 条交接边，正常消息没有误拦。这里的分母很小且攻击和答案都是脚本化的；正确性代理只检查两道二次函数题的顶点和对称轴，不代表真实教学质量、普遍防护率或统计显著性。

## 真实 MiMo 开发试验（不是独立测试）

首跑 `teacher-pollution-real-20261015-1` 用 21 次真实调用：仅验签时攻击标记出现 1/5、正常完成 1/1；内容校验时攻击标记 0/5，但正常 0/1 完成；校验加降级时攻击标记 0/5、正常 1/1 完成。正常消息中的**变式反例**被误判为本题错误，这是首跑暴露的真实缺陷。

针对首跑的已知误拦，开发版校验器补充了“反例与其自身公式核对”及上标 `²` 的解析。随后保留同一批攻击，并增加一条不同顶点的正常题，重跑 `teacher-pollution-real-20261015-2`：共 30 次 MiMo 调用；仅验签攻击标记 1/5、正常完成 2/2；内容校验攻击标记 0/5、正常完成 **1/2**；校验加离线降级攻击标记 0/5、正常完成 2/2，固定题目正确性代理 5/5。新增正常题仍有误拦，说明规则泛化不足。降级答案来自本地规则后端，不能声称 MiMo 自身在攻击下答对 5/5。

攻击标记仅表示预定义污染片段进入最终文本，不等于真正遵循恶意指令；本靶场没有真实敏感字段可被外泄。第二轮是看过首轮输出后修改规则的**开发集复测**，不得作为独立测试集成绩，也没有统计显著性或跨模型结论。

## 下一轮必须补的证据

1. 冻结当前规则，在未用于修改规则的新任务/新正常反例上测误拦与教学效用；再做攻击者可调整措辞的真实模型单节点污染与双节点协同 A/B，保持模型、任务与调用预算配对。
2. 扩到不同学科/题型和无法规则验算的主观任务；加入转述、翻译、拆分成多跳信息的绕过案例。现有顶点校验不覆盖这些情形。
3. 将来源验签、内容校验、最小字段、独立事实核验、可信降级逐项消融；记录被拒后还能否完成有用讲解和误拦正常内容的比例。
4. 用人工或可信题库答案评价教学正确性、完整性与个性化；当前 `task_correct_proxy` 只检查固定题目的顶点和对称轴，不是教学质量分数。
5. 在数据库侧验证并发写入、备份/保留期、权限和脱敏；如未来改用 MySQL，另做最小权限账号与迁移测试。
