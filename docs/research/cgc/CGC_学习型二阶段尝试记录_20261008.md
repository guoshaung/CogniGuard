# CGC 学习型二阶段尝试记录

## 方法

使用 JailbreakBench 每类 7 个有害 + 7 个正常样本作为 calibration split，训练词/字符 TF-IDF + Logistic Regression；剩余 JBB 样本和完整 XSTest 只用于测试。该分类器没有接入生产 CGC。

## 阈值结果

| 阈值 | JBB held-out F1 | JBB 误拦 | XSTest F1 | XSTest 误拦 |
|---:|---:|---:|---:|---:|
| 0.5 | **0.800** | 3.3% | 0.520 | 39.6% |
| 0.6 | 0.558 | 3.3% | 0.221 | 6.8% |
| 0.7 | 0.235 | 0% | 0.029 | 0.4% |
| 0.8 | 0 | 0% | 0 | 0% |

## 结论

学习型二阶段能在同分布 JBB held-out 上提高 F1，但跨到 XSTest 时明显失效；阈值升高只能降低误拦，同时几乎消灭召回。因此它当前不能作为 CGC 的通用第二阶段，也不能用于拔高综合分。主版本继续使用扩展规则，并把该结果作为泛化失败证据。
