**本实验的目的**：不是证明新机制一定成立，而是判断它能否解决"简单的 k+f 扩展"无法充分解决的安全问题。

## 1. 数据与请求流

- E5 的合成数据：K = 16 和 32，种子 0–9；
- E6 的 Eedi 数据：K = 16，作为复核；
- 请求流与 E5 相同：N = 60，6 个共谋小组，c = 0。共谋小组照常防御：**任意** ≤ k 人，k = 4。

## 2. 未记录传播（新增事件，按理论第 1 节建模）

- **通信图 G**：这是系统可强制执行的"未中介通道"，例如共享工作区。分两种：
  - 稀疏图：每个主体有 3 个邻居，按种子生成；
  - 完全图：作为对照。在完全图上，按理论命题 2，Ours 应当等同于 B1 和 B2。
- **总事件预算 f** 事先给定，f ∈ {2, 4}。模拟中，真实事件的总数 F_true = f，在请求流中均匀随机分布。每个事件沿 G 中的一条随机边，转发**发送方当时的全部持有**（最坏内容）。
- 违反预算假设的情形只作描述：F_true = 2f，用来观察假设被违反时各组的表现。

## 3. 证据通道（模拟）

| 证据 | 生成方式 | 可能出现的错误（只在 Gate 2 使用） |
|---|---|---|
| 持有证据 P(v, r) | 每个真实事件以召回率 r 产生"接收方 v 持有源自回执 r 的内容"；延迟 δ 个请求后到达 | 漏检（r < 1）；错误归因：以概率 q 把 v 记成一个随机的其他主体；重复：以概率 p_dup 重复发送同一条证据；伪造：每个请求以概率 φ 凭空产生一条证据；多来源：一个事件以概率 p_mix 同时带有两个回执 |
| 事件证明 Ev(u → v, id) | 每个真实事件以概率 r_c 产生，带唯一的事件编号 | 只在 Gate 2 的"证明伪造"分支中出现：以概率 φ_c 伪造事件证明，或者编号重复 |

## 4. 对照组

| 组 | 判定方式 | 怎样使用证据 |
|---|---|---|
| **B0** | 在 O 上做原始 CA-PD 检查，k = 4 | 不使用 |
| **B1** | 在 O 上检查 k + f 人的联盟（理论命题 1） | 不使用 |
| **B2** | 在 O 上检查 k + (f − d) 人的联盟 | **全部证据**（包括持有证据）都计入 d，并且固定到 O 上 |
| **B3** | 在 O 上做原始 CA-PD 检查，k = 4 | 只把持有证据加入 O，不考虑预算 |
| **Ours** | 命题 3：通信图 G 上的 Steiner 划分精确判定，剩余预算为 f − d_c | 持有证据**只加入 O**；**只有**可信、去重后的事件证明计入 d_c，并按最坏内容固定到 O 上；相关持有者超过 8 个时，退回 B1 的判定，并记录退回率 |
| **Oracle** | 在真实状态 H 上做 CA-PD 检查，k = 4 | — |

## 5. 指标（按理论第 1 节和用户决策第 7 条）

- **VR_rel**（主动防御收益只用这一项计算）：违规由本组的一次放行造成，并且 Oracle 在同一真实状态下会拒绝这次放行；
- **VR_pre**（单独报告）：违规在本组任何一次后续放行之前，就已经在真实状态上存在。这部分无法通过后续控制撤销；
- **UR_normal**、**DR_normal**（不必要的拒绝，以 Oracle 为参照）；
- **预算低估事件数**：B2 和 Ours 中，d 大于真实已发生事件数的次数；
- 证据量、退回率、每次决策的耗时，只描述。

## 6. 判定

**Gate 0（问题是否存在）**：
- 条件：在稀疏图、f = 2 时，B0 的 VR_rel > 0（种子间配对 bootstrap 95% 区间下界 > 0），并且 VR_rel 在 VR_rel + VR_pre 中所占比例 ρ ≥ 0.3；
- 不通过就停止。

**Gate 1A（理想证据能否在同等安全下恢复效用）**：
- 设定：理想证据，r = r_c = 1，δ = 0，无任何错误；
- 核对：B1 和 B2 的 VR_rel 都应为 0。它们是在假设成立时的安全上界。任何一组不为 0 都说明实现有错；
- 条件：UR_normal(B2) − UR_normal(B1) 的区间下界 > 0；
- **不支持就停止**：这说明在理想情况下，证据也不能恢复效用。

**Gate 1B（细粒度传播建模能否优于 k+(f−d)）**：
- 设定：理想证据、稀疏图；
- 条件：Ours 的 VR_rel = 0，并且 UR_normal(Ours) − UR_normal(B2) 的区间下界 > 0；
- 核对：在完全图上，Ours 与 B2 的放行决策逐个相同（命题 2）。不相同说明实现有错；
- **不支持**：保留这个负结果，**不再继续设计复杂的鲁棒控制算法**。论文中的鲁棒控制，就以 B2（k+(f−d)）的形式出现。

**Gate 2（不完美证据下的安全）**：
- 网格：r ∈ {1, 0.8, 0.5}；q ∈ {0, 0.05, 0.2}；p_dup ∈ {0, 0.1}；φ ∈ {0, 0.01}；p_mix ∈ {0, 0.2}；δ ∈ {0, 5}。r_c 固定为 1。另设"证明伪造"分支：φ_c ∈ {0.01, 0.05}；
- **核对（理论第 4 节）**：在 φ_c = 0 的全部网格中，Ours 的 VR_rel = 0，预算低估事件数为 0；
- **主要观察（理论第 4.2 节的预测）**：在 q > 0、p_dup > 0 或 φ > 0 时，B2 出现预算低估和 VR_rel > 0；在证明伪造分支中，Ours 同样会因为预算低估而出现 VR_rel > 0。两者都只报告，不作判定；
- **通过条件**：在 φ_c = 0 的网格中，至少有一半的网格单元满足 UR_normal(Ours) − UR_normal(B1) 的区间下界 > 0。也就是说，不完美的持有证据加上可信的事件证明，仍然能在保持安全的同时恢复效用。

冻结之前，用种子 99 空跑一次，只检查能否判定，不看数值。
