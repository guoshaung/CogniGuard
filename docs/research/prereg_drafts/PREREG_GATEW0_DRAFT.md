# Gate W0：水印相对内容指纹的额外信息价值，预注册草案（未冻结）

> 状态：草案。冻结时搬到 `experiments/capd_gatew0_<日期>/`，提交并写入 sha256。
> 只用本地 CPU，**不训练水印模型，不租用 GPU，不调用付费 API。** 嵌入式检索模型（BGE、重排序）只在本地 CPU 上推理；如果本地无法运行，就把对应的组记为缺失，不用其他组补上。
> 目的：避免再次出现 HSW-ST 中"内容指纹可以替代水印"的情况。**不预设水印优于指纹。** 理论预测见 `THEORY_PROPAGATION_EVIDENCE_20261124.md` 第 5 节：在大多数场景下，理想水印预计**不会**带来额外的安全收益。

## 1. 三种身份（预先界定）

| 身份 | 回答的问题 | 能识别它的方法 |
|---|---|---|
| 内容身份 | 这段文本源自哪份已交付的内容 | 指纹、检索 |
| 发行身份 | 这份内容交给了谁、对应哪张回执 | 水印（携带不透明的回执 ID）；主动文本变体 + 指纹 |
| 传播事件 | 内容是怎样到达观察到它的主体的 | **以上方法都不能证明**。只有可信通道的事件证明可以 |

## 2. 场景（四类，每类按种子生成）

数据用 E6 的 Eedi 复习提示文本。所有文本都只在本机保存，不进仓库。

| 场景 | 构造方式 | 要检验的问题 |
|---|---|---|
| S1 唯一内容 | 每张回执对应一段不同的文本 | 基本识别 |
| S2 重复发行 | 同一段文本发给 2–5 个接收者 | 相同内容对应多张回执时，来源有歧义 |
| S3 高度相似内容 | 不同回执的文本只差一个数字或一个错误认知 | 指纹的区分能力 |
| S4 多来源融合 | 观察到的文本由 2–3 张回执的片段拼接或摘要而成，每个片段 ≤ 1 句 | 短片段的识别 |

每个场景再叠加三种文本变换：原样、轻度改写（同义替换、语序调整，用确定性规则）、只保留片段。

## 3. 对照组

**内容指纹类**（服务器保存全部已交付文本）：
- F1：SHA256 精确匹配；
- F2：MinHash（5-gram，128 个排列）；
- F3：BM25 检索；
- F4：BGE 嵌入检索（本地 CPU）；
- F5：F4 加上语义重排序（本地 CPU 的交叉编码器）；
- F6：在完整发行记录上检索：F5 的结果，加上全部回执的接收者列表。

**主动编码类**：
- A1：**主动文本变体 + 指纹检索**。每个接收者得到一个确定性改写的版本，例如数字的写法、同义词、句式不同，然后用 F5 检索。这一组用来避免把"主动编码"带来的收益错误地归功于水印检测算法；
- **W\***：**理想水印通道**。能正确恢复观察文本中每个片段的发行 ID。在"只保留片段"的变换下，片段太短、无法承载载荷时（少于 1 句），W\* 也恢复不出来；
- F5 + W\*：联合证据。

## 4. 指标

**归因层面**：
- 来源恢复的 Precision、Recall、F1；
- 来源歧义消除率：在 S2 中，被正确缩小到唯一回执的比例；
- 错误归因率。

**控制层面**（主要指标）：把各组得到的证据作为**持有证据**，输入 Gate 0–2 的 B3 或 Ours，不用于扣减预算。在相同的请求流和传播事件上，报告：
- **危险放行率**（VR_rel）；
- 正常任务效用（UR_normal）；
- **不必要拒绝率**：以 Oracle 为参照。

## 5. 判定

- **W0-1（主假设）**：比较 F5 + W\* 与 F5。在每个（场景, 变换）单元中，计算 VR_rel 的差（F5 − (F5 + W\*)）的区间下界。
  - 如果**至少有一个**单元的下界 > 0，并且在那个单元中，F5 + W\* 的不必要拒绝率**不高于** F5，就判"有额外价值"；
  - 否则判"无额外价值"。
- **W0-2**：比较 W\* 与 A1。如果在所有单元中，W\* 的控制层面指标都不优于 A1，就说明收益来自主动编码，而不是水印本身。
- **停止规则（用户决策第 6 条）**：W0-1 判"无额外价值"时，**停止水印拓展，不投入 GPU**。论文中改用内容指纹（以及可选的主动文本变体）作为持有证据。
- W0-1 判"有额外价值"时，记下在哪些（场景, 变换）中有价值，再另行预注册真实水印的实验：漏检、错误归因、改写鲁棒性、嵌入成本，以及与 Chronology 加相同反馈控制的组合比较。

**预先登记的理论预测**：在 S1、S2、S3 下，W0-1 的结论预计是"无额外价值"，因为理论第 5 节说明，持有证据只取决于内容身份。在 S4 的"只保留片段"变换下，结论有可能是"有额外价值"。

## 6. 预先说明

- 无论哪一组，都**不能**证明某个主体实际接收了信息，只能作为持有证据使用；
- W\* 是理想化的上界：真实水印只会更差。所以如果 W\* 都没有额外价值，真实水印也不会有。
