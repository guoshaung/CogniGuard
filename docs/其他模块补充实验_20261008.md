# 其他模块补充实验（组会版）

## MM-FOPD test split 补充

本轮使用 270 个合成画像、13,500 条画像记录和 144 个 test 任务，运行 8 种选择方法。

| 方法 | 敏感画像暴露率 | 平均隐私成本 | 必要单元召回 | 单元 F1 |
|---|---:|---:|---:|---:|
| Privacy Funnel | 0 | 0.0335 | 0.539 | 0.672 |
| LLM Minimization proxy | 0 | **0.0302** | 0.512 | 0.660 |
| DP-Exponential Retrieval | 0 | 0.0590 | 0.199 | 0.282 |
| **MM-FOPD** | **0** | 0.0495 | **0.799** | **0.866** |

相对开发集结果，MM-FOPD test split 的必要单元召回从 `0.745` 提升到 `0.799`，单元 F1 从 `0.829` 提升到 `0.866`。这支持方法在当前固定数据生成协议下具有稳定性，但外部方法仍是机制级适配，不能写成官方复现或 SOTA。

## HSW-ST 与 CGC 的补充安排

- HSW-ST：当前已有 KGW Only、原 Full HSW-ST、Selective HSW-ST；下一项补充是按删除、同义改写、截断、摘要、强改写分别报告 ADR，而不是只报总 ADR。
- CGC：当前已有 JailbreakBench、BIPIA、XSTest smoke slice；下一项补充是扩展 XSTest 类型和 JailbreakBench 数量，并加入独立 Judge，避免只使用字符串拒答代理。

## 组会可直接汇报

> 本轮优先补齐 MM-FOPD 的 held-out test split。结果显示，MM-FOPD 在零敏感画像暴露下取得 0.799 的必要单元召回和 0.866 的单元 F1，优于当前机制级隐私基线。HSW-ST 和 CGC 的下一步分别是按攻击类型细分鲁棒性，以及扩大公开安全基准并引入独立评价器。
