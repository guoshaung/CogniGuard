# 图像水印论文代码接入说明

本项目已将 SCE-LocGuard / DFG-LocGuard 图像水印论文代码复制到 CogniGuard 内部，作为 HSW-ST 图像水印分支的本地 research wrapper。

## 已接入代码

- `dfg_locguard/api/`：单图嵌入、AIGC 攻击、盲检和报告导出的 FastAPI/CLI wrapper。
- `dfg_locguard/scripts/`：论文实验阶段脚本，包括 EditGuard 输出生成、64-bit capsule 打包、AIGC 攻击与报告聚合。
- `dfg_locguard/src/`：语义定位、区域聚合、可视化和未来 diffusion feature guidance stub。
- `dfg_locguard/configs/`：轻量配置。
- `code/`：原 EditGuard 图像水印模型代码、options、data/utils/models 等运行依赖。

## 不纳入版本库的大文件

以下内容不纳入 Git 版本库，仍按运行环境本地提供：

- `checkpoints/*.pth`
- `models/hf_cache/`
- `dataset/`
- `dfg_locguard/outputs/`
- `dfg_locguard/api_jobs/`
- `results_summary/`

当前本机已从 `D:\pycharm\watermark_exps\checkpoints` 复制了这些 checkpoint 到本项目：

```text
checkpoints/clean.pth
checkpoints/degrade.pth
checkpoints/sam_vit_b_01ec64.pth
```

如果换机器或重新 clone，需要至少把 EditGuard checkpoint 放到：

```powershell
checkpoints\clean.pth
```

如果需要跑真实 AIGC inpainting 攻击，需要缓存：

```powershell
models\hf_cache\models--stable-diffusion-v1-5--stable-diffusion-inpainting
```

## 启动方式

CogniGuard 主后端默认使用 `8000`，图像水印论文 API 建议使用 `8010`：

```powershell
python -m pip install -r requirements.txt
uvicorn dfg_locguard.api.server:app --host 127.0.0.1 --port 8010
```

能力探测：

```powershell
python -m dfg_locguard.api.cli capabilities
```

或：

```powershell
curl http://127.0.0.1:8010/api/v1/capabilities
```

## 与 CogniGuard 的连接

`backend/app/protection/image_watermarking.py` 已按如下环境变量调用该 API：

```env
COGNIGUARD_IMAGE_WATERMARK_PROVIDER=auto
SCE_LOCGUARD_BASE_URL=http://127.0.0.1:8010
SCE_LOCGUARD_PROJECT_ROOT=.
SCE_LOCGUARD_OUTPUT_DIR=outputs/sce_locguard_jobs
SCE_LOCGUARD_TIMEOUT_SECONDS=180
```

当论文 API 不可用、checkpoint 缺失或 CUDA/模型缓存不可用时，CogniGuard 会自动退回本地轻量频域水印与本地攻击 preview，不会伪造论文管线成功结果。
