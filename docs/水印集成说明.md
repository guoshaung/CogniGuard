# HSW-ST 水印集成说明

## 概述

已成功将 HSW-ST（混合语义水印）系统集成到教学代理中，用于保护版权教师资源。

## 集成位置

### 1. PedagogicalTeachingAgent（教学代理）

**文件**: `backend/app/agents/pedagogical_teaching_agent.py`

**功能**:
- 在构造函数中接受 `watermark_system` 参数
- 当使用版权资源生成教学回答时，自动嵌入水印
- 使用语义水印模式（`mode="semantic"`），不影响文本可读性

**水印嵌入逻辑**:
```python
def _apply_watermark(self, result, snippets):
    # 提取资源ID
    # 使用第一个资源ID作为水印密钥
    # 嵌入语义水印
    # 返回带水印的文本和水印元数据
```

**返回结构增强**:
- `teaching_answer`: 带水印的教学回答文本
- `watermark_info`: 水印元数据
  - `applied`: 是否应用了水印
  - `resource_ids`: 使用的资源ID列表
  - `markers`: 语义标记列表

### 2. AgentOrchestrator（编排器）

**文件**: `backend/app/agents/agent_orchestrator.py`

**修改**:
- 导入 `HybridWatermarkSystem`
- 在初始化时创建水印系统实例
- 传递水印系统给教学代理

```python
watermark_system = HybridWatermarkSystem({"hsw": {}})
self.teaching_agent = PedagogicalTeachingAgent(
    llm_client=llm_client,
    event_sink=event_sink,
    watermark_system=watermark_system,
)
```

## 工作流程

1. **资源检索**: 版权资源代理返回受保护的教师资源片段
2. **教学生成**: 教学代理基于资源生成教学回答
3. **水印嵌入**: 自动检测资源使用并嵌入水印
   - 仅当 `controlled_resource_snippets` 不为空时应用
   - 使用语义水印，保持文本流畅性
4. **元数据记录**: 记录水印信息用于后续审计

## 水印特性

- **隐蔽性**: 使用语义水印，不影响教学内容质量
- **可追溯性**: 记录资源ID，支持版权追踪
- **自动化**: 无需手动干预，自动嵌入
- **可选性**: 如果水印系统不可用，优雅降级

## 与其他保护层的协同

- **FOPD**: 保护学生画像隐私
- **C²-RAG**: 控制资源访问和返回模式
- **HSW-ST**: 在输出层嵌入水印（本次集成）
- **TPCS**: 统一管理和审计所有保护机制

## 后续增强建议

1. **检测功能**: 实现水印检测API，用于版权验证
2. **审计链**: 将水印信息记录到审计链中
3. **统计分析**: 收集水印使用统计，监控资源使用模式
4. **配置化**: 支持动态配置水印参数（强度、模式等）
