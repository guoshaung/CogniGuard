# CogniGuard 组会伪代码与实验方案

> 日期：2026-07-11  
> 用途：毕业论文实验设计讨论与下次组会算法汇报  
> 原则：区分“论文目标算法”“独立研究实现”“系统 Demo 适配器”，不把代理公式或随机模拟结果表述为最终实证。

## 1. 先给结论：自建数据集方向正确，但不能只做封闭式自建数据

建议将数据集定位为：

> **基于公开教育任务底座构造的 CogniGuard 安全评测套件。**

也就是说，公开数据负责提供可复现的题目与教学任务分布，自建部分负责补齐本项目独有的学生隐私、教师资源策略、审计溯源和多轮攻击标注。

不建议完全放弃公开数据集，原因如下：

1. 完全自建容易被质疑“数据是否按自己的系统量身定做”。
2. 公开任务底座有利于他人复现，并提供外部有效性证据。
3. 本项目真正需要自建的并不是数学题本身，而是其上的安全语义层：学生画像、敏感等级、资源许可证、曝光预算、攻击轮次和审计真值。
4. 对公开数据进行统一适配不是无效工作，它可以成为论文中“安全场景构造方法”的一部分。
5. 学生身份信息应全部合成；教师资源应使用开放许可材料或合成材料，避免引入真实未授权个人信息和版权文本。

因此采用两类测试证据：

- **领域内有效性**：公开教育任务 + 自建 CogniGuard 安全标注。
- **泛化有效性**：冻结的未见题源、未见学生、未见资源和未见攻击模板族。

## 2. 论文实验要回答的研究问题

| 研究问题 | 要回答什么 | 主证据 |
|---|---|---|
| RQ1 单模块有效性 | MM-FOPD、C2-RAG、HSW-ST、CG 分别是否降低目标风险 | 分模块攻击实验、正常任务效用 |
| RQ2 对比优势 | 每个模块是否优于同类保护方法 | 同模型、同样本、同预算的配对基线实验 |
| RQ3 组件贡献 | 模块内部每个设计是否必要 | 组件消融实验 |
| RQ4 组合增益 | 完整系统是否优于预先冻结的单模块和双模块参照 | None / Single / Pair / Full / Full+CG |
| RQ5 协同交互 | 模块组合是否存在超出主效应相加的统计交互 | 完整 `2^4` 因子设计与交互项检验 |
| RQ6 闭环真实性 | 模块之间是否真的交换信号并改变决策 | 反馈路径干预实验 |
| RQ7 泛化与代价 | 对未见攻击是否有效，是否牺牲教学质量 | 模板族留出、误拒率、效用、延迟、token/cost |

## 3. 数据集构造方案

### 3.1 三层数据结构

```text
公开任务层
  ├─ GSM8K：初中数学文字题
  ├─ AQuA-RAT：高中代数与推理
  └─ TheoremQA：大学定理型问题
          │
          ▼
自建安全语义层
  ├─ 合成学生画像、敏感字段与多模态元数据
  ├─ 合成/开放许可教师资源与 license policy
  ├─ 资源 chunk、曝光预算和 provenance 真值
  └─ 正常教学任务、允许数据范围和期望答案
          │
          ▼
自建攻击 episode 层
  ├─ 隐私抽取与渐进泄漏
  ├─ 版权原文与多轮重构
  ├─ 越权、间接注入和画像投毒
  ├─ 文本/图像水印扰动
  └─ 跨层组合攻击
```

### 3.2 必须先划分、后生成

不能生成全部数据后随机逐行切分。应按实体和模板族先切分：

- 学生 `student_id` 不跨集合。
- 教师资源 `resource_id/source_id` 不跨集合。
- 同一道公开题的改写版本不跨集合。
- 攻击模板按“模板族”划分，测试集中保留训练/开发阶段从未出现的表达方式。
- `mixed_math_suite` 是三个子集的汇总，不能再当成第四个独立数据集重复计数。

推荐划分（用于重新构建的 v2 数据；当前仓库中的已有数据包只能称为原型/开发数据，不能追认为冻结测试集）：

```text
Train/Construction 60%：仅用于生成器、规则和模型开发
Dev/Tuning         20%：仅用于阈值、权重和提示选择
Future Frozen Test 20%：新数据完成隔离后，只在方案冻结后运行

另设 Attack-Family Holdout：整族攻击模板只出现在最终测试
```

比例不是论文贡献本身；若样本量不足，应优先保证实体隔离和模板族隔离。

### 3.3 数据集构造伪代码

```text
Algorithm 1  BUILD-COGNIGUARD-BENCHMARK

Input:
    public task sources D_public
    synthetic profile schema S_profile
    resource policy schema S_resource
    attack-template families T_attack
    random seed s
Output:
    train set D_tr, development set D_dev, frozen test set D_te
    attack-family holdout D_holdout, dataset card C

1: ValidateLicenseAndSource(D_public)
2: Normalize tasks into a common task schema
3: Deduplicate by source_id, normalized question and semantic near-duplicate
4: Split source tasks and resource identities before any augmentation
5: Split attack families into seen families and unseen holdout families

6: Create a split-local cohort of synthetic students for every split
7: Assign each student a sequence of tasks from that split only
8: for each student u and each task x in u.task_sequence do
9:     P_u <- GenerateOrUpdateSyntheticProfile(S_profile, u, x, seed=s)
10:    R_x <- GenerateLicensedOrSyntheticTeacherResource(S_resource, x)
11:    Annotate sensitivity, allowed purpose, license policy and exposure limit
12:    Create benign teaching request and expected utility labels
13:    Create attacks from the attack families assigned to this split
14:    Assign attack severity, query budget, number of turns and success oracle
15:    Keep all rounds of u and all derivatives of x in the same split
16:    Store provenance, generator version and immutable source hashes
17: end for

18: CheckEntityIsolation(student_id, resource_id, source_id)
19: CheckTemplateFamilyIsolation(T_attack)
20: HumanReview(stratified sample from every source, stage and attack family)
21: WriteDatasetCard(motivation, composition, license, limitations, splits)
22: Freeze newly constructed D_te and D_holdout before tuning protection thresholds
23: return D_tr, D_dev, D_te, D_holdout, C
```

注意：给开放或合成材料附加 `copyright_level=high` 可以验证“策略执行能力”，但它仍是版权策略代理实验，不能声称验证了真实版权诉讼意义上的侵权判定。

## 4. 综合系统伪代码

### 4.1 论文目标算法

```text
Algorithm 2  COGNIGUARD-PROTECTED-TEACHING-ROUND

Input:
    user query q
    current student response student_response
    local multimodal student profile P
    teacher-resource collection R
    policy set Π
    cross-round state H
Output:
    protected teaching answer y*
    audit evidence A
    updated profile P'
    updated cross-round state H'

1: τ <- ParseTeachingTask(q)

2: (card, fopd_log) <- MM-FOPD(P, τ, Π.privacy)
3: d_priv <- CG.Authorize(
       route = profile_to_diagnosis,
       payload = card,
       state = H
   )
4: if d_priv is DENY then
5:     return SafeRefusal(), Audit(d_priv), P, H
6: end if
7: card <- ApplyAction(card, d_priv)
   // 论文目标 enforcement；当前 Controller 只记录 minimize metadata，不改写 payload

8: diagnosis <- ProfileDiagnosisAgent(τ, card)

9: (controlled_resource, resource_trace, E') <- C2-RAG(
       query = q,
       task = τ,
       context = card,
       resources = R,
       exposure_state = H.exposure
   )
10: H1 <- H with exposure = E'
11: d_resource <- CG.Authorize(
        route = resource_to_teaching,
        payload = controlled_resource,
        state = H1
    )
12: if d_resource is DENY then
13:     return SafeRefusal(), Audit(d_resource), P, H1
14: end if
15: controlled_resource <- ApplyAction(controlled_resource, d_resource)
    // 论文目标 enforcement；当前 Controller 只记录 minimize metadata，不改写 payload

16: draft <- TeachingAgent(q, diagnosis, controlled_resource)

17: (watermarked_answer, watermark_trace) <- HSW-ST.EmbedAndBind(
        draft,
        protected_spans = {terms, formulas, numbers},
        resource_trace
    )

18: d_final <- CG.FinalAudit(
        watermarked_answer,
        card,
        resource_trace,
        watermark_trace,
        H1
    )
19: y* <- EnforceFinalAction(
        watermarked_answer,
        d_final,
        actions = {allow, regenerate, downgrade, refuse}
    )

20: assessment <- LearningAssessmentAgent(y*, student_response)
21: evidence <- ValidateProfileUpdateEvidence(assessment)
22: P' <- P
23: if CG.ApproveProfileUpdate(evidence) then
24:     P' <- BoundedProfileUpdate(P, evidence)
25: end if

26: H' <- H1
27: [TARGET — CROSS-LAYER FEEDBACK NOT FULLY CONNECTED IN CURRENT DEMO]
28: if HSW-ST reports leakage or tampering then
29:     DowngradeNextC2RAGReturnMode(H')
30: end if
31: if CrossLayerRisk(card, resource_trace, watermark_trace) is high then
32:     BlockOrMinimizeNextThirdPartyCall(H')
33: end if
34: A <- AppendHashChainedAudit(fopd_log, resource_trace, watermark_trace, d_final)
35: return y*, A, P', H'
```

## 5. 分块伪代码

### 5.1 MM-FOPD：最小任务相关画像披露

```text
Algorithm 3  MM-FOPD

Input: local student profile P, current task τ, privacy policy π
Output: minimum context card c, selected records S, privacy trace L

1: records <- EncodeMultimodalProfileLocally(P)
2: for each record r in records do
3:     relevance <- TFIDFSimilarity(r.text, τ.text)
4:     knowledge <- KnowledgePointMatch(r, τ)
5:     confidence <- r.confidence
6:     recency <- NormalizeRecency(r.timestamp)
7:     sensitive_penalty <- max(0, r.sensitivity - π.sensitivity_threshold)
8:     base_score[r] <- 0.50*relevance + 0.25*knowledge
                           + 0.15*confidence + 0.10*recency
                           - 0.20*sensitive_penalty
9: end for

10: attention <- Softmax(
        0.50*TextOverlap + 0.30*KnowledgeMatch + 0.20*Confidence,
        temperature = 0.5
    )

11: [TARGET — ORTHOGONAL PROJECTION IS NOT YET CONNECTED TO FINAL SELECTION]
12: if orthogonal projection is enabled then
13:     (task_subspace, sensitive_subspace) <- OrthogonalDecompose(records)
14:     projected_score <- ProjectToTaskSubspace(task_subspace, τ)
15:     RemoveSensitiveProjection(projected_score, sensitive_subspace)
16: end if

17: candidates <- RemoveLocalOnlyAndOverSensitiveRecords(records)
18: S <- InformationBottleneckSelect(
        candidates,
        base_score,
        attention,
        top_k = 3,
        max_information_bits = 3.0,
        privacy_lambda = 0.5
    )
19: c <- BuildMinimumContextCard(S, τ)
20: c <- RedactRawValuesAndDirectIdentifiers(c)
21: AssertNoRawMultimodalOrFullProfile(c)
22: L <- {selected ids, rejected ids, PER, task coverage, leak flags}
23: return c, S, L
```

实现提醒：当前 `select_enhanced()` 调用了正交分解，但分解结果尚未参与最终选择；第 11–16 行属于“设计目标/待接入”。在完成接入前，不应把实验提升归因于正交投影。

### 5.2 C2-RAG：版权约束检索与累计曝光控制

```text
Algorithm 4  C2-RAG

Input: request q, task τ, context card c, resources R, exposure state E
Output: controlled resource o, return mode m, provenance trace G, state E'

1: for each resource r in R do
2:     score[r] <- 0.45*QueryRelevance(q,r)
                     + 0.08*ContextRelevance(c,r)
                     + 0.20*KnowledgeFit(τ,r)
                     + 0.10*DifficultyFit(τ,r)
                     - 0.15*CopyrightLevel(r)
                     - 0.20*E[r.chunk_id]
                     - 0.10*RepeatedFocus(r.chunk_id)
3: end for
4: candidates <- TopK(R, score, k=3)
5: r* <- candidates[0]                  // 当前实现
6: // BestPermittedCandidate(candidates) 是后续改进，不是当前行为
7: e <- E[r*.chunk_id]

8: if e exceeds resource maximum then
9:     m <- VARIANT only if allow_variant and e < 0.60
10:    otherwise m <- REFUSE
11: else if CopyrightLevel(r*) < 0.35 and e < 0.15 and QUOTE is permitted then
12:    m <- QUOTE
13: else if CopyrightLevel(r*) >= 0.70 and VARIANT is permitted then
14:    m <- VARIANT
15: else if e < 0.30 and SUMMARY is permitted then
16:    m <- SUMMARY
17: else if e < 0.45 and OUTLINE is permitted then
18:    m <- OUTLINE
19: else if e < 0.60 and VARIANT is permitted then
20:    m <- VARIANT
21: else
22:    m <- REFUSE
23: end if

24: o <- RenderResourceByMode(r*, m)
25: delta <- 0.35*LCS(o,r*) + 0.25*NgramOverlap(o,r*)
              + 0.30*SemanticSimilarity(o,r*) + 0.10*RepeatedFocus(r*)
26: E'[r*.chunk_id] <- decay*E[r*.chunk_id] + delta
27: G <- Commit(resource id, chunk id, license, mode, hashes, E, E')
28: return o, m, G, E'
```

### 5.3 输出保护：文本 HSW-ST 与图像 SCE-LocGuard 双支路

```text
Algorithm 5  OUTPUT-PROTECTION-BRANCHES

Input: output type t, text draft y or image I, protected text spans K,
       resource provenance G, audit context C
Output: protected output o, protection evidence W, unified trace A

1: if t == TEXT then
2:     placeholders <- ProtectTermsFormulasAndNumbers(y, K)
3:     y_p <- ReplaceProtectedSpansWithPlaceholders(y, placeholders)

4:     for attempt = 1 to 5 do
5:         y_candidate <- RewriteWithKGW(
               y_p, gamma = 0.25, delta = 1.75, window_size = 4
           )
6:         y_candidate <- RestorePlaceholders(y_candidate, placeholders)
7:         violations <- FidelityViolations(y_candidate, y)
8:         if violations is empty then break
9:     end for

10:    if violations == {"too_similar_to_draft"} then
11:        perform one additional rewrite and restore placeholders
12:        violations <- FidelityViolations(y_candidate, y)
13:    end if
14:    if "concept_drift" is in violations and fallback_to_draft_on_drift then
15:        y_candidate <- y
16:        mark used_draft_fallback = true and KGW watermark unavailable
17:    else
18:        keep the last candidate and record remaining fidelity_violations
19:    end if
20:    Z_global <- GreenTokenZScore(y_candidate)
21:    Z_local <- SlidingWindowMaxZ(y_candidate, window=80, stride=20)
22:    detected <- (Z_global > 2.85)
23:    W <- CommitTextWatermarkEvidence(
           watermark id, seed commitment, answer hash, Z scores
         )
24:    o <- y_candidate
25: else if t == IMAGE then
26:    (I_w, W_sce) <- SCE-LocGuard.EmbedAndBind(I, G, C)
27:    (I_a, M_pred, verify_evidence) <- SCE-LocGuard.VerifyAfterAttack(
           I_w, C.attack_image, C.seed, C.registry_reference
       )
28:    I_p <- SCE-LocGuard.LocalizeRepairAndVerify(I_a, M_pred, C)
29:    W <- MergeImageProtectionEvidence(W_sce, verify_evidence)
30:    o <- I_p
31: else
32:    return ERROR("unsupported output type")
33: end if
34: A <- BindAndHash(W, G, Hash(o), C.agent_trace)
35: AppendUnifiedAuditRecord(output_type=t, output_hash=Hash(o),
       source_trace=G, protection_evidence=W, audit_context=C)
36: return o, W, A
```

实现提醒：文本输出走 HSW-ST 的保护 span、KGW 改写和盲检测；图像输出走 SCE-LocGuard 的区域定位、局部修复和验证。两条支路最后写入统一审计记录，但不共享不匹配的文本 span 或图像 mask 类型。完整文本 KGW 路径位于 `protection/audit_trace/src/main.py`；当前集成 Demo 主要使用语义标记和 SHA256 绑定，不能把 Demo 检测结果当成 KGW 结果。现有实验已分别真实验证 HSW-ST 文本链路和 SCE-LocGuard 单图像链路，但尚无类型一致的 `C2-RAG -> Qwen -> SCE-LocGuard` 端到端适配器，不能宣称联合链路已完成。

### 5.4 CG：跨 Agent 数据流治理

```text
Algorithm 6  CG-AUTHORIZE

Input: message M=(sender, receiver, type, payload), policy Π, round state H
Output: authorization decision d and compliance metadata; current payload remains unchanged

1: if Route(sender, receiver) is not in Π.route_whitelist then DENY
2: forbidden <- RecursiveFind(payload, raw/full/direct-update fields)
3: if forbidden is not empty then DENY

4: disclosure <- min(0.45, PayloadLength(payload)/4000)
5: disclosure <- disclosure + 0.1*SensitiveTokenCount(payload)
6: if disclosure > 0.75 then DENY

7: compliance <- EvaluateInternalFERPA_COPPAPolicyMapping(M, H)
8: if compliance requires consent not present then DENY
9: if compliance is local-only and M targets a third party then DENY
10: if compliance decision is MINIMIZE then record minimize metadata
    // [TARGET — NOT IMPLEMENTED] transform the payload before current dispatch
11: AppendHashChainedComplianceEvent(M, compliance_policy_decision)
    // 当前记录策略映射决策，不保证已记录后续 budget/guardrail 的最终 enforcement

12: H.round_disclosure <- H.round_disclosure + disclosure
13: if H.round_disclosure > 3.0 then DENY

14: if guardrail adapter is enabled then
15:     run deterministic input/action rail checks
16:     if any rail blocks then DENY
17: end if
18: return decision, compliance metadata and the original permitted payload
```

### 5.5 图像篡改定位分支

```text
Algorithm 7  DFG-LOCGUARD-SEMANTIC-REPORT
```

## 6. 攻击与比较实验伪代码

```text
Algorithm 8  PAIRED-ATTACK-BENCHMARK

Input:
    frozen benign/attack test cases D
    methods M
    attack families T
    seeds S
    common model and query budget B
Output:
    raw run table, confidence intervals, significance tests and Pareto results

1: Freeze model version, prompt version, decoding parameters and thresholds
2: for each test case x in D do
3:     for each attack family t applicable to x do
4:         attack_spec <- BuildAttackSpec(t, x, budget=B)
5:         for each method m in M applicable to t do
6:             for each seed s in S do
7:                 Reset method state, exposure budget and conversation state
8:                 attack <- InstantiateFreshAttack(attack_spec, seed=s)
                   // 同一 seed 下策略与预算一致，但各方法的攻击器状态相互独立
9:                 result <- RunRealEndToEndSystem(m, x, attack, seed=s)
10:                security <- ScoreWithIndependentOracle(result, x.ground_truth)
11:                utility <- ScoreBenignTaskQuality(result, x)
12:                cost <- MeasureLatencyTokensAndCalls(result)
13:                Save every raw decision, output hash and trace
14:            end for
15:        end for
16:    end for
17: end for

18: Aggregate repeated seeds within each independent test case,
    or retain case_id as the cluster in every resampling procedure
19: Compare methods on exactly the same cases using paired statistics
20: For one binary outcome per case, use paired bootstrap CI and McNemar test
21: For case-level continuous leakage/utility differences,
    use paired bootstrap CI and Wilcoxon test
22: Correct the pre-registered family of multiple comparisons, e.g. Holm
23: Report effect size, independent case count and precision/power basis
24: Stratify by dataset, education stage, attack severity and seen/unseen template
25: Plot security-utility-cost Pareto frontier
26: return raw table and statistical summary
```

关键要求：`RunRealEndToEndSystem` 必须使用系统真实输出。不能根据“模块开关是否开启”直接赋予 AuditFailure、UnauthorizedAccess 或 JointRisk，也不能在执行失败后用随机数补结果。

## 7. “每个模块分别比，最后综合比”的正确组织方式

你的原思路是对的，但不要把所有方法硬塞到同一张表。先做层内公平比较，再做系统级组合比较。

### 7.1 层内比较

| 模块 | 攻击/任务 | 建议比较方法 | 主安全指标 | 必须同时报告 |
|---|---|---|---|---|
| MM-FOPD | 完整画像、原始多模态、渐进泄漏、跨学生、反演 | 边界控制：NoProfile/FullProfile；内部消融：规则摘要；基线：PII masking、RBAC/ABAC、noise-added top-k proxy (non-DP)；本方法：FOPD | ASR、PII/间接属性泄漏、PER | TaskCoverage、误拒率、card 长度 |
| C2-RAG | 逐字提取、改写、多轮拼接、相似题批量、资源内注入 | 边界控制：PlainRAG；内部消融：截断/SummaryOnly/GuardrailOnly；基线：独立 n-gram block；本方法：C2-RAG | 累计重构率、LCS、n-gram、语义泄漏 | availability、正确率、拒绝率 |
| HSW-ST | 删除、截断、混合、摘要、翻译、强改写 | 边界控制：No watermark；内部消融：semantic-only/KGW-only/protect-only；本方法：full HSW-ST | WDR/ADR、tamper detection、TraceBindRate | FPR、TKR/FKR/NKR、质量 |
| CG | prompt injection、越权、跨 Agent、画像投毒、逃审计 | 边界控制：No controller；内部消融：route ACL only/regex guardrail/budget only；本方法：full CG | ASR、BlockRate、policy violations | benign false block、延迟 |

当前仓库中 `PresidioStyle`、`MemFree-Ngram`、`SHIELD-Agent`、`BloomScrub-Rewrite`、`R-CAD-Approx` 等是近似/代理实现，其中部分复用了本项目组件。未接入作者官方代码前，论文表格必须标注为 `proxy` 或 `approximation`，不能写成“完整复现原方法”。

### 7.2 组件消融

- MM-FOPD：去 task attention、去 information bottleneck、去 cumulative disclosure gate；正交投影接入最终选择后再做 `w/o orthogonal`，当前只能比较 sensitivity gate 开关。
- C2-RAG：去 exposure budget、variant、provenance；HSW-ST→C2-RAG 反馈接入后再做反馈消融。
- HSW-ST：当前可做 no watermark、KGW only、protect only、full，以及全局检测和 trace binding 消融；局部窗口接入最终 classifier 后再做 `w/o local detection`。
- CG：去 route ACL、去 forbidden-field scan、去 cumulative budget、去 compliance state、去 hash-chain audit。

### 7.3 系统级组合

组合增益分析可保持当前三个核心模块的 2×2×2 设计，再加入 Full+CG：

```text
None
FOPD only / C2-RAG only / HSW-ST only
FOPD+C2-RAG / FOPD+HSW-ST / C2-RAG+HSW-ST
Full without CG
Full + CG
```

“最佳单模块”和“最佳双模块”必须在开发集选择并冻结，不能在测试集看完结果后再挑选。上述设计只能直接支持“组合增益”结论；若论文要声称存在统计意义上的“协同交互”，应补齐 CG 在各组合上的开关，运行完整 `2^4` 因子设计，并检验模块主效应与交互项。

系统级主结论应来自真实攻击 ASR 和正常任务效用。`JointRisk` 可以作为辅助汇总指标，但必须：

1. 先公开公式和权重；
2. 在开发集冻结权重；
3. 提供不同权重下的敏感性分析；
4. 不能由模块启用开关直接决定分项风险；
5. 同时展示各原始风险指标，避免平均数掩盖单点失败。

## 8. 指标与统计报告

### 8.1 主指标

- 每个攻击族：`Attack Success Rate ↓`。
- 正常任务：`Benign False Refusal/Block Rate ↓`、`Task Utility ↑`。
- 隐私：direct/indirect PII leakage、raw-profile flag、PER、TaskCoverage。
- 版权：LCS、n-gram overlap、semantic leakage、cumulative reconstruction rate。
- 审计：WDR、FPR、ADR、TraceBindRate、tamper detection、TKR/FKR/NKR。
- 系统代价：端到端延迟、LLM 调用数、输入/输出 token、估算成本。

### 8.2 统计要求

- 所有方法在完全相同的测试 case 上配对运行。
- 攻击生成和模型采样使用多个固定 seed，但 seed 是同一 case 的重复测量，不增加独立样本量。
- 先按 case 聚合 seed，或在 bootstrap 中以 `case_id` 为 cluster；不能把每个 seed 当成独立样本。
- 每个 case 只有一个配对二元结局时，才使用 McNemar；比例差同时给出 case-level paired bootstrap 95% CI。
- 连续指标基于 case-level 配对差值使用 paired bootstrap / Wilcoxon，并报告差值与效应量。
- 对预先定义的一组多攻击、多基线或多消融比较使用 Holm 等多重比较校正。
- 报告独立 case 数，并说明样本量的功效分析或置信区间精度依据。
- 当前超参数采样 CI 只能说明“对配置扰动是否稳定”，不能代替测试样本 CI。
- 按题源、学段、攻击强度和 seen/unseen 模板分层报告。
