# CogniGuard 组会伪代码：综合部分与分块部分

> 版本：2026-08-03  
> 汇报顺序：先讲综合算法，再讲 MM-FOPD、C2-RAG、文本 HSW-ST、图像水印、CG，最后讲实验执行。  
> 表述边界：当前图像分支是带 HMAC 来源注册和 k-of-3 定位证据的 **EditGuard wrapper**；DFG feature extractor 与 trainer 尚未完成。`REAL` 表示真实研究管线，`FALLBACK` 表示论文服务不可用时的本地轻量降级；论文严格模式遇到降级必须失败，不能把两类结果混合报告。

> **截至 2026-08-03 的实验状态与透明协议修订**：正式图像 manifest 已完成并冻结为 3,000 张、4 个来源，划分为 train/dev/test=`2109/333/558`。117 张 dev 子集上的 `k=1` 九阈值阶段属于**探索性/开发选择**，最终报告为 `R_cal.status="no_candidate_satisfies_constraints"`；真实边界是 `τ=0.34` 通过 11/12、仅失败 `clean_max_mask_fpr`，同时 `τ=0.36` 也通过 11/12、仅失败 `erasing_0.05_mean_mask_iou`，二者同为最高通过数候选。看过 117 结果后，机制型协议修订固定单一确认候选 `τ=0.34,k=2`：`posthoc_to_117=true`，因为提高通道一致票数直接针对孤立通道 clean 假阳性；`preregistered_before_216=true`，表示该选择在任何 216 推理之前冻结，而不追溯声称该选择在 117 执行前已经固定。首次 confirmation builder 因旧的“单一最高通过数候选”断言与真实 tie 冲突而 **fail-closed**，候选执行 0 行。第二次尝试 `channel_vote_confirmation_formal3000_v2_amendmentv1_20260803T034717Z_21971` 已由 builder 成功生成 216 bundle、lock 和候选前 claim；216 complement 实际为 4 个数据集、29 个内容域，且与 117 子集在 `sample_id`、图像 SHA-256、`source_family` 三类标识上的交集均为 0。但配置继承 source domain floor=4，而 runner 在 API 启动前要求 confirmation floor>=9，故该次以 `exit=2` fail-closed，API/候选执行 0 行、test 消耗 0 行；这不是 216 实验结果。决定不绕过 runner，统一采用 `source floor=4`、`confirmation floor=9`、`effective floor=max(4,9)=9`、`selected domains=29` 的强契约。该修订改变 source-tree SHA，所以必须在最终源码上再次完整重跑九阈值，之后才能创建新的 216 bundle。当前真实状态仍为：`R_conf=<尚未产生>`、`F_selected=<尚未生成>`、`R_test=<尚未启动>`，不得用代码预期值填充。

数据用途必须分开：学生画像数据用于 MM-FOPD 隐私实验；带权利标签和使用规则的教师资源用于 C2-RAG 版权实验；本次 3,000 张图像只用于图像水印鲁棒性与定位实验，不能替代前两类数据，也不能把 NASA、Met 或 Open Images 表述成“教师版权配套数据集”。

## 一、综合伪代码

```text
Algorithm 1  COGNIGUARD-MULTIMODAL-PROTECTED-TEACHING

Input:
    student request q
    current student response r_student
    local multimodal profile P
    teacher-resource collection R
    privacy/copyright/flow policies Π
    frozen image-watermark policy F_img and run attestation J_img
        (required by PAPER_STRICT)
    cross-round state H
Output:
    protected answer y*
    optional protected teaching image I_w
    audit evidence A
    updated profile P' and state H'

1:  τ <- ParseTeachingTask(q)

    // Student-privacy domain
2:  (card, L_priv) <- MM-FOPD(P, τ, Π.privacy)
3:  d1 <- CG.Authorize(profile_to_diagnosis, card, H)
4:  if d1 == DENY then
5:      return SafeRefusal(), NONE, Audit(d1), P, H
6:  end if
7:  diagnosis <- ProfileDiagnosisAgent(τ, card)

    // Teacher-copyright domain
8:  (resource_view, mode, L_res, E') <- C2-RAG(
        q, τ, card, R, H.exposure
    )
9:  H1 <- H with exposure = E'
10: d2 <- CG.Authorize(resource_to_teaching, resource_view, H1)
11: if d2 == DENY then
12:     return SafeRefusal(), NONE, Audit(d1,d2,L_res), P, H1
13: end if
14: draft <- TeachingAgent(q, diagnosis, resource_view)

    // Generated-content audit domain: text branch
15: (y_w, L_text_wm) <- HSW-ST-TEXT(
        draft,
        protected_spans = {terms, formulas, numbers},
        provenance = L_res
    )

    // Generated-content audit domain: image branch
16: I_w <- NONE
17: L_img_wm <- NONE
18: L_img_policy <- NONE
19: if NeedsTeachingImage(q, diagnosis, y_w) and ImageBudgetAvailable(H1) then
20:     I_0 <- GenerateOrBuildTeachingImage(q, diagnosis, y_w)

                F_img.formal_selection.selection_source

                F_img.formal_selection.confirmation.outcome

                h0,

            )

31:         AssertRequiredCapabilities(cap, required)

33:         AssertSameLiveRunInstance(h0, h1)

                    required.localization_channel_vote_min,

                manifest_lock_hash=
                    F_img.formal_selection.source_formal.manifest_lock_sha256,
                calibration_report_hash=
                    F_img.formal_selection.calibration.report_sha256,
                confirmation_report_hash=
                    F_img.formal_selection.confirmation.report_sha256,
                raw_vote_evidence_hash=
                    F_img.formal_selection.confirmation
                         .raw_localization_vote_evidence_sha256,
                run_instance_nonce=h0.run_instance_nonce,
                api_job_root=h0.api_job_root
            }
35:     else
36:         cap <- QueryImageWatermarkCapability()
37:         L_img_policy <- {
                recovery_threshold=cap.recovery_threshold,
                localization_channel_vote_min=
                    cap.localization_channel_vote_min,
                paper_eligible=false
            }
38:     end if
39:     (I_w, L_img_wm) <- IMAGE-WATERMARK-EMBED(
            I_0, answer_id, resource_id, Π.image_watermark,

        profile_trace = L_priv,
        resource_trace = L_res,

        image_watermark_trace = L_img_wm,
        image_policy_trace = L_img_policy,

44: evidence <- ValidateProfileUpdateEvidence(assessment)

        L_priv, L_res, L_text_wm, L_img_wm, L_img_policy, d1, d2, d3
    )
```

组会口头概括：

> CogniGuard 先在本地把学生多模态画像压缩成最小任务卡，再对教师资源执行版权约束检索；生成答案后，文本进入 HSW-ST 文本水印分支，需要教学图时进入当前基于 EditGuard 的图像水印分支，最后由 CG 对跨模块数据流、输出和画像更新进行统一审计。图像开发链应准确表述为“117 张 `k=1` 九阈值探索性选择→看到真实双 11/12 后作机制型修订并在 216 前冻结 `τ=0.34,k=2`→其余 216 张只做一次单候选 pass/fail”；论文严格模式只消费该确认通过后生成的冻结策略。在线流程不读取 dev/test，也不调参数。DFG-LocGuard 是后续训练增强项，当前不能作为已完成算法汇报。

## 二、分块伪代码

### Algorithm 2：MM-FOPD 学生画像最小披露

```text
Input: local profile P, task τ, privacy policy π
Output: minimum context card c, selected records S, trace L_priv

1:  records <- EncodeLocally(P.text, P.image, P.audio, P.video, P.behavior)
2:  Keep raw image/audio/video, biometric fields and zS only on local device
3:  candidates <- RemoveDirectIdentifiersAndLocalOnlyRecords(records)
4:  for each record x in candidates do
5:      rel <- TaskRelevance(x, τ)
6:      kp  <- KnowledgePointMatch(x, τ)
7:      rec <- Recency(x)
8:      q   <- DataQuality(x)
9:      pen <- SensitivityPenalty(x, π)
10:     score[x] <- 0.45*rel + 0.25*kp + 0.15*rec + 0.15*q - pen
11: end for
12: S <- InformationBottleneckTopK(candidates, score, k=3)
13: c <- BuildTaskCard(zK, zP, coarse_zA, S)
14: AssertNoRawMultimodalData(c)
15: L_priv <- {selected_ids, rejected_ids, PER, task_coverage, leak_flags}
16: return c, S, L_priv
```

### Algorithm 3：C2-RAG 教师资源版权约束

```text
Input: query q, task τ, context card c, resources R, exposure state E
Output: controlled resource o, mode m, trace L_res, new state E'

1:  candidates <- RetrieveByTaskAndKnowledge(q, τ, c, R)
2:  for each resource x in candidates do
3:      risk[x] <- CopyrightLevel(x)
                     + Exposure(E, x.chunk_id)
                     + RepeatedFocus(x.chunk_id)
4:      utility[x] <- Relevance(x) + KnowledgeFit(x, τ) + DifficultyFit(x, τ)
5:      score[x] <- utility[x] - risk[x]
6:  end for
7:  x* <- BestPermittedCandidate(candidates, score)
8:  m <- SelectMode(
        rights=x*.rights,
        exposure=E[x*.chunk_id],
        choices={QUOTE, SUMMARY, OUTLINE, VARIANT, REFUSE}
    )
9:  o <- RenderByMode(x*, m)
10: leak <- ExactCRR(o, all protected resources)
11: delta <- ExposureCost(leak, SemanticSimilarity(o,x*), RepeatedFocus(x*))
12: E'[x*.chunk_id] <- Decay(E[x*.chunk_id]) + delta
13: L_res <- Commit(resource_id, chunk_id, rights, mode, hashes, E, E')
14: return o, m, L_res, E'
```

### Algorithm 4：HSW-ST 文本水印与来源绑定

```text
Input: answer draft y, protected spans K, resource provenance L_res
Output: watermarked answer y_w, evidence L_text_wm

1:  placeholders <- ProtectTermsFormulasAndNumbers(y, K)
2:  y_p <- ReplaceProtectedSpans(y, placeholders)
3:  repeat at most 5 times
4:      candidate <- KGWRewrite(y_p, gamma, delta, seed)
5:      candidate <- RestoreProtectedSpans(candidate, placeholders)
6:      violations <- FidelityCheck(candidate, y)
7:  until violations is empty
8:  if ConceptDrift(violations) then candidate <- SafeFallback(y)
9:  Z_global <- GlobalGreenTokenZ(candidate)
10: Z_local <- SlidingWindowZ(candidate)
11: detected <- WatermarkClassifier(Z_global, Z_local)
12: L_text_wm <- Bind(
        watermark_id, seed_commitment, answer_hash, Z_global, Z_local, L_res
    )
13: return candidate, L_text_wm
```

`truth_bbox` 的统一语义是半开区间 `[left, top, right, bottom)`：数组切片使用 `top:bottom, left:right`；若用 PIL 画真值矩形，右下角必须写成 `(right-1, bottom-1)`，不能把 `right/bottom` 当作包含端点。

三通道分别以 `abs(residual)>τ` 产生 0/255 票，再求和，因此原始票值只能为 `{0,255,510,765}`；最终二值掩码严格定义为 `raw_votes >= 255*k`。117 探索阶段使用 `k=1`；看到真实双 11/12 后作出的机制型修订固定 216 确认候选为 `τ=0.34,k=2`，对应重放阈值 510，并明确记录 `posthoc_to_117=true`、`preregistered_before_216=true`。原始票必须原子保存为真正的、非交错 16-bit 灰度 PNG，不能先转 `uint8`，否则 510/765 会溢出。共享验证器 `dfg_locguard/experiments/localization_artifacts.py` 同时被 117 阈值分析、216 确认分析和正式 runner 调用；它还拒绝越出当前 `api_jobs` 的路径、符号链接/重解析点、HTTP 响应与留存报告不一致、输入 SHA/seed/尺寸/后缀漂移，以及 raw-vote 哈希、直方图、预测掩码、面积或攻击 regime 无法独立重放的行。正式传统攻击与 AIGC 攻击的每一个成功行都必须附带 canonical localization evidence，不能只验证有 GT mask 的行。

```text
                          for every watermark run
14:             if FormalPaperRun and not paper_eligible then
                    MarkRunInvalidAndFailClosed()
                end if
15:         end for
16:     end for
17: end for
18: Compute paired case-level bootstrap CI and significance tests
19: Aggregate only REAL/paper-eligible runs; report fallback counts separately
20: Never count component dataset and mixed aggregate twice
21: return raw runs and statistical report
```

Algorithm 8 是最终系统级配对比较设计，不表示一份数据集可以验证所有模块。尤其不能用图像水印的 3,000 张图片替代学生隐私数据或带权利标签的教师资源。

## 四、组会呈现顺序

1. 用 Algorithm 1 先讲完整闭环和四条证据流：画像、资源、文本水印、图像水印；强调在线论文流程只消费已经冻结的策略，不在线调参。
2. 用 Algorithms 2–5 分别讲 MM-FOPD、C2-RAG、文本水印和 EditGuard wrapper，再用 Algorithm 7 讲 CG。
3. 用 Algorithm 6 展示正式 3,000 数据及 formal/117/216 三层 lock，按“117 张 `k=1` 探索性选择→披露 `0.34/0.36` 双 11/12→机制型修订在 216 前冻结 `0.34+k=2`→其余 216 张只做一次 pass/fail”讲清楚开发链；同时展示首次 builder 因 tie fail-closed，以及第二次 builder 已预注册 216 bundle、但 domain floor `4/9` 冲突导致 API 前 `exit=2`，两次均执行 0 行。说明 clean 契约为 source/confirmation/effective=`4/9/9`、实际 29 域，并因 source SHA 改变再次重跑九点；不能把任何 216 前冻结追溯表述成 117 前固定。
4. 用 Algorithm 8 解释系统级比较为什么必须使用模块专用数据，不能让图像集替代学生隐私或教师版权资源集。
5. 用 Algorithm 9 解释冻结后的 test-only 协议：EditGuard wrapper 为 58,590 行传统条件+6,696 行 AIGC；TrustMark/WAM 各为 58,590 行传统条件+558 原图负控，不进入当前 AIGC 表；test 指标永不回流调参。
