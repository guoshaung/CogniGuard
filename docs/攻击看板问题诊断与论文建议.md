## 二、论文发表的数据集与实验设计建议

### 您的担心分析

您提到的核心问题：
1. **别人都有数据集，但你的是针对系统评价** ✅ 这其实是优势！
2. **用开源数据集又和基于LLM的多智能体无关** ✅ 可以巧妙结合！

### 解决方案：三层实验设计

#### 策略A：构建领域特定的合成数据集（推荐）

**核心思路**：CogniGuard是一个**系统级防护框架**，不是单纯的数据处理方法。

**数据集设计**：

1. **学生画像隐私数据集** (Privacy Profile Dataset)
   - 合成100-500个学生学习档案
   - 包含：学习历史、错题记录、多模态数据（手写轨迹、语音）
   - 标注：隐私敏感度等级
   - 已有基础：`scripts/generate_synthetic_multimodal_data.py`

2. **教师课件版权数据集** (Copyright Resource Dataset)
   - 收集50-100个教学资源
   - 包含：题库、解答、教案
   - 标注：版权敏感度、改写难度
   - 可使用开源教育资源 + 人工改编

3. **攻击场景数据集** (Attack Scenario Dataset)
   - 7种标准攻击场景（已实现）
   - 扩展到20-30种变体攻击
   - 包含：提示词注入、数据提取、权限绕过

**论文贡献点**：
- ✅ 首个多智能体教育系统的安全评估数据集
- ✅ 包含隐私、版权、审计三个维度
- ✅ 提供攻击-防御对抗样本

#### 策略B：在现有数据集上构建多智能体安全层（推荐）

**核心思路**：使用开源教育数据集，但评估的是**安全防护效果**，不是教育效果。

**推荐数据集**：

1. **数学数据集**：
   - MATH dataset
   - GSM8K
   - 提供题目、解答

2. **教育对话数据集**：
   - EdNet
   - ASSISTments
   - 提供学习行为日志

**实验设计**：

```
基准系统（无防护）  vs  CogniGuard系统（有防护）

评估指标：
├─ 教育效果保持率（Utility Preservation）
│  ├─ 诊断准确率
│  ├─ 教学内容质量
│  └─ 学生满意度
│
├─ 安全防护效果（Security Effectiveness）
│  ├─ 隐私泄露率 ↓
│  ├─ 版权侵权率 ↓
│  ├─ 攻击成功率 ↓
│  └─ 审计覆盖率 ↑
│
└─ 系统开销（Overhead）
   ├─ 延迟增加
   ├─ Token消耗
   └─ 计算成本
```

**论文贡献点**：
- ✅ 在标准数据集上评估安全性（可复现）
- ✅ 安全-效用的权衡分析
- ✅ 多智能体系统的防护框架

#### 策略C：真实场景小规模实验 + 合成大规模验证（最佳）

**阶段1：真实数据**（N=20-50）
- 收集真实学生学习数据（匿名化）
- 真实教师课件（授权使用）
- 进行详细的案例分析

**阶段2：合成数据**（N=500-1000）
- 基于真实数据分布合成大规模数据
- 用于统计显著性验证
- 消融实验和参数分析

**论文结构**：
```
1. Introduction
   - 多智能体教育系统的安全挑战

2. Related Work
   - LLM安全
   - 隐私保护
   - 版权保护
   - 多智能体系统

3. CogniGuard Framework
   - 三层防护架构
   - TPCS控制器
   - 实现细节

4. Experimental Setup
   - 真实场景数据收集（小规模）
   - 合成数据生成（大规模）
   - 评估指标

5. Results
   - 防护效果评估
   - 效用保持分析
   - 消融实验
   - 案例研究

6. Discussion & Conclusion
```
