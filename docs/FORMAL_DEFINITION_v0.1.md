## 1. 基本对象

### 1.1 离散秘密
一个**秘密** σ 由以下四部分组成：
- **取值空间** 𝒮：有限集合，|𝒮| = K。取值可以是单个对象（考哪道题），可以是集合（考哪几道题），也可以是**有序序列**（教学步骤的安排）。【建模选择：𝒮 包含哪些候选】
- **真实取值** s\* ∈ 𝒮：由秘密的主人选定，只保存在后端。对外只公开承诺 c = HMAC_salt(s\*)。
- **先验** π：𝒮 上的概率分布，表示攻击者**在看到全部公开信息之后**对 s\* 的信念。
  - s\* 由主人随机选定时（例如考哪道题），π 是均匀分布；
  - s\* 有惯例可循时（例如教学设计），π 用空视图实测得到（见第 4 节）。
- **增益函数** g : 𝒲 × 𝒮 → [0, 1]：攻击者猜 w、真实取值是 s 时，攻击者"猜对了多少"。要求 g(s, s) = 1。【建模选择：由资产主人给出】
  - 恒等增益：g_id(w, s) = 𝟙[w = s]，只有完全猜对才算；
  - 集合型秘密（考哪 m 道题）：g(w, s) = |w ∩ s| / m；
  - 有序秘密（教学步骤的安排，w 和 s 都是 m 个不同元素的序列）：
    g(w, s) = β · |set(w) ∩ set(s)| / m + (1 − β) · ord(w, s)。
    ord(w, s) 的定义：记 C = set(w) ∩ set(s)。当 |C| ≥ 2 时，ord 取 C 中所有元素对里、两边前后关系一致的对所占的比例；当 |C| < 2 时，ord = 0。
    这样 g(s, s) = β + (1 − β) = 1（m ≥ 2）。β 由老师给出，敏感性分析中取 β ∈ {0.3, 0.5, 0.7}。

**依据**：秘密是有限取值上的随机变量，攻击者的收益用增益函数刻画，这是定量信息流的标准设定（Smith, FoSSaCS 2009；Alvim 等, CSF 2012 提出 g-泄露；专著 Alvim、Chatzikokolakis、McIver、Morgan、Palamidessi、Smith, *The Science of Quantitative Information Flow*, Springer 2020）。

### 1.2 单元
单元是系统可能交付出去的一条信息。在**结构层面**，每个单元 u 对应一个**谓词** φ_u : 𝒮 → {0, 1}，并且 φ_u(s\*) = 1，即它对真实取值成立。看到 u，就知道 s\* ∈ 𝒮_u = { s : φ_u(s) = 1 }。

单元的类型（谓词的形式）：

| 类型 | 例子 | 谓词 |
|---|---|---|
| 属性 | "重点复习括号运算" | 题目的知识点 = 括号运算 |
| 成员 | "期末会考分数乘法" | x ∈ s |
| 顺序 | "先讲反例，再给定义" | x 在 y 之前 |
| 位置 | "第一步是画数轴" | s 的第 1 项 = x |
| 关联 | 一张"员工—住址"表 | 把两个标识连起来（第 5.3 节） |

所以**组合和顺序都能表达**：组合靠多个谓词同时成立，顺序靠顺序谓词和位置谓词。

一组单元 A 透露的信息是 𝒮_A = ∩_{u∈A} 𝒮_u。

### 1.3 泄露量（相对先验的增量）
看到 A 之后，攻击者的后验是 π(· | A)，即把 π 限制在 𝒮_A 上再归一化。

- 先验可猜性：V_g(π) = max_w Σ_s π(s) g(w, s)
- 后验可猜性：V_g(π | A) = max_w Σ_s π(s | A) g(w, s)
- **泄露量**：L(A) = log₂( V_g(π | A) / V_g(π) )，单位是比特

这里只算**相对先验的增量**：凡是攻击者凭公开知识本来就能推出的，L = 0，系统不需要保护。这对应"独立开发、根据公开知识自行推出不构成泄密"的法律直觉【待核实】，也正好解决了"大模型本来就会做这道题"的问题。

**特例**：采用恒等增益和均匀先验时，L(A) = log₂( K / |𝒮_A| )。也就是说，候选被排除了多少，就泄露了多少。

**单调闭包**：对一般的增益函数，L(A) 不一定随 A 增大而增大。我们使用 L\*(A) = max_{B ⊆ A} L(B)：攻击者总可以忽略一部分信息，所以拿到更多单元，泄露量不会减少。

### 1.4 保护阈值与推导集
对每个秘密，主人设定保护阈值 τ（比特）。【建模选择：默认取"攻击者猜中的把握不超过 1/2"，即恒等增益加均匀先验时 τ = log₂ K − 1】

**推导集**：使 L\*(A) > τ 的**极小**单元集合。全部推导集记为 𝒲_τ(σ)。
推导集总是相对于一个**给定的单元全集 U** 来定义的。实验中如果截断了单元，结论只对保留下来的单元成立。

推导集不再靠人工标注，而是**由谓词算出来**。人工标注的推导集，比如资产包里已有的那些，是 τ 取最大值时的特例，可以用来核对。

**引理 1**：对任意单元集合 A，L\*(A) > τ 当且仅当 A 包含 𝒲_τ(σ) 中的某个推导集。
（证明：L\* 单调；如果 L\*(A) > τ，取 A 的一个满足条件的极小子集即可。反方向由单调性直接得到。）

这条引理把"信息论的泄露量"和"已有闸门的组合检查"接了起来。现有代码只需要把推导集换成按谓词算出来的版本，其他部分都不用改。

## 2. 接收者、合谋与交付

- 接收者集合 R；每次交付都写入一条回执，记录交给了谁、交付了哪些单元。A_r 是 r 至今收到的全部单元。
- **合谋**：任意不超过 k 人的接收者子集 C，合谋视图 A_C = ∪_{r∈C} A_r。
  - E3a 已经说明，用登记关系来限制合谋范围并不可取（它的收益恰恰来自不防跨组合谋），所以这里采用"任意 k 人"。
- **安全状态**：对每个秘密 σ、每个人数 ≤ k 的合谋 C，都有 L\*(A_C) ≤ τ_σ。

## 3. 非结构化输出与计量器

系统实际交付的是一段文字 x，而不是单元编号。**计量器** M 把文字翻译成单元集合：M(x) ⊆ U。

- **结构保证所需的条件（计量器可靠性）**：如果 x 实际透露了单元集合 A_x，那么 M(x) ⊇ A_x。也就是只许多算，不许漏算。
- 数据集中的每段文字都由已知的单元集合生成，所以 A_x 是已知的，可以直接测量计量器的**漏判率**。

## 4. 实测泄露（大模型攻击者）

谓词只是对文字含义的**近似**：一段文字可能透露得比它的谓词更多，比如措辞或语气里带出了额外信息。所以还要用攻击者实测：
- 让攻击者在 𝒮 中给出猜测 w，采样 N 次，估计期望增益 V̂(x)，取 95% 置信上界；
- 实测泄露 L̂(x) = log₂( UCB(V̂(x)) / V₀ )，其中：
  - 先验由设计决定时（均匀先验），V₀ = V_g(π)；
  - 否则 V₀ 取空视图实测值的 95% 置信**下**界。分子取上界、分母取下界，宁可高估泄露。
- **谓词充分性检验**：比较 L̂ 与 L\*(A_x)。如果 L̂ 明显大于 L\*，说明文字带出了谓词以外的信息，要把这些情况单独报告。这就是新版 E3b 的内容。

## 5. 保证（在下列假设下）

**定理（草案）**：如果下面四条假设成立，并且闸门只放行使状态保持安全的交付，那么任何人数 ≤ k 的合谋，对任何秘密的泄露都不超过 τ。
- A1 **计量器可靠**：M(x) ⊇ A_x；
- A2 **谓词充分**：文字透露的信息不超过它的单元谓词（第 4 节检验）；
- A3 **先验正确**：π 已经包含了攻击者能获得的全部公开知识；
- A4 **合谋有界**：合谋人数 ≤ k，并且所有交付都有回执。

证明由引理 1 和闸门的检查直接得到。论文中要逐条报告每个假设在实验里被违反的比例，不能只给定理。

## 6. 三个实例

### 6.1 实例一：考哪道题（教师保密资产，主实验）
> 定位：题目是 Eedi 的**真实题目**，但"将考哪道题"是我们**抽样构造**的秘密。论文中不得称之为真实的考试泄露事件。
- 𝒮：从题库中按规则抽出的 K 道候选题，K ∈ {8, 16, 32}；s\* 均匀随机选定。先验是均匀的，**由设计保证**；
- 单元：s\* 的属性谓词，包括学科、知识点、某个错误选项对应的错误认知、正确答案的数值、题干中出现的数；
- 增益：g_id；扩展为"考哪 m 道题"时，用集合增益；
- 泄露量和推导集都可以**精确计算**；
- 依据：心理测量学中的题目曝光控制（Sympson & Hetter, 1985）和题目预知研究；国家考试试题在启用前的保密级别【待核实】。

### 6.2 实例二：教学设计（教师保密资产，带顺序）
- 𝒮：从若干个设计元素中选 m 个并排列的所有方案。元素包括资产包里的真实元素，以及同类的合理替代；
- 单元：成员谓词、顺序谓词、位置谓词；
- 增益：有序增益，β 由老师给出；
- 先验：用空视图实测（教学惯例会让某些顺序更常见）。

### 6.3 实例三：学生 / 员工的敏感属性（隐私侧）
- 𝒮：某个人敏感属性的可能取值，例如出行目的地、病情类别；
- 单元：一张数据表。表与表之间通过共同的列连起来（关联谓词）；
- 推导集：能把"公开的锚点"（例如某个已确认的房间号）一路连接到敏感列的最小表集合，按连接图算出；
- 数据：Sum Leaks 的 119 个场景。数据集自带的 `defense` 字段给出了人工标注的敏感组合，用来与计算出的推导集核对。

## 7. 与相关工作的区别（一句话版）
- OCELOT：只按单条轨迹记账，跨原子只做成对的联合校准，而且不对用户通道收费；
- 本文：按接收者记账，把有界合谋的组合推断作为一等公民。推导集由谓词精确算出，并用大模型攻击者检验谓词是否充分。
