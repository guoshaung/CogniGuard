# RKW 知识来源水印复核：已否定、未验证与路线判断

> 2026-11-24，集成负责人。只做复核与归类：不新增研究命题，不开发新算法，不做参数搜索。
> 依据：本仓库 `codex/hsw-st`、`codex/gate-w0-real`，research-sync（HSW R33–R39、HSW-REPRO-02）的提交与结果文件。所有结论都标明出处提交。

## 1. 先分清三种"水印编码"

| 编码对象 | 含义 | 已有实验 |
|---|---|---|
| **发行实例编码** | 载荷 = 一次发行或回执（发给谁、哪一次） | KBPW M1（发行 ID）、M2 / M3（发行 × 事实）——`065bb82`、`40213d3`、`631409e` |
| **来源级编码** | 载荷 = 知识来源或资产（这段内容出自哪份资源），同一来源的所有发行共用 | HSW-ST 原设计："使用第一个资源 ID 作为水印密钥"（`docs/水印集成说明.md`）；**HSW R39 逐资源 KGW 密钥**（research-sync `c882227`）；R37N 独立换密钥（`ee68a9d`） |
| **单密钥存在性检测** | 载荷为 0 比特：只判断是否带水印 | CertInsert EVAL-03 / 04（OPT、GREEDY-dyn）、KGW、Unigram、PostMark 基线（`codex/hsw-st`） |

另有三条**载体可行性**探路，它们还没有走到编码这一步：KOSW（知识正交语义子空间）、AFK（锚点书写形式）、R35（按知识修改风险门控的 KGW）。

**RKW 的原始记录**：仓库中只有名称级记录。`NEW_DIRECTION_UNCERTAIN_STATE_20261124.md` 第 1 节写"拓展一：风险感知知识水印（RKW）"，第 4 节的查新表写"按组合风险分配水印容量：本轮没有找到；经典背包算法不算原创 → 拓展一候选"。**仓库和 research-sync 中都没有找到 RKW 的数学定义、目标函数或预注册。** 如果原始设计在其他地方（例如组会稿、Windows 本地文件），需要用户提供，下面第 3 节的归类会据此修订。

按现有记录，RKW 的目标可以拆成：

1. 来源级知识溯源，在多主体传播后仍能恢复；
2. 按组合风险（见证、联盟）分配水印容量；
3. 恢复出的来源证据进入不确定知识状态，并降低联盟风险；
4. 优于非水印来源追踪。

## 4. 最强非水印基线留给水印的空间（BGE + NLI，`fcf1374`）

Codex 在 27 个无水印模型端点（9 条链）上的数字，**集成侧已独立复现**（99 / 4 / 38，F1 0.825）。X3-E2E 中，BGE + NLI 把危险放行每次运行降到 1.0–3.0，在它之上水印增量为 0（`experiments/x3_e2e_integration/RESULT.md` 第 5 节）：

- 真实在场单元 137 个；BGE 候选覆盖 125 个（检索遗漏 12 个）；NLI 确认 99 个（候选内漏确认 26 个）；误确认 4 / 103。
- **来源级水印最多能补的**，是检索遗漏的 12 个单元：它能说出"来源是 s"，但仍要核验器确认 s 的哪些单元在场。按 NLI 在候选内的确认率（99/125 ≈ 0.79）估计，期望增量约 9.5 / 137（约 7%），而且前提是载体能在 LLM 改写后存活，目前没有载体做到。
- 候选内的 26 个漏确认属于核验器的错误，来源身份帮不上。只有能指出"哪些单元仍在"的**单元级**载荷才可能补上，但这正是第 3 节中证据最弱的一项。
- 理想上界：候选内完美核验是 125/137，加上来源级完美溯源是 137/137。

## 5. 现有证据是否支持继续该路线

**作为论文的主要原创贡献：不支持。**

1. 四类载体（句首码字、逐资源 token 偏置、语义子空间、锚点形式）在真实 LLM 改写或压缩下，或者在可行性门槛上，都没有通过。
2. 来源级水印的治理增益受第 4 节上限约束：相对 BGE + NLI，最多约 7%–9% 的单元，而且依赖一个尚不存在的存活载体。
3. 与 Gate W0-0 一致：身份载荷本身不改变决策，价值只来自多确认的知识单元，而这一点 BGE + NLI 已经覆盖了 72%（理想候选内 91%）。

**但不能写成"知识来源水印无效"。** 以下三项从未被检验：

- 来源级编码在真实传播中的表现；
- 单元级载荷配合一种存活载体；
- 按组合风险分配容量。

论文中可以如实写为"未验证的开放问题"。如果要继续，**只需要回答一个决定性问题**，这不是新命题，而是 RKW 原目标 1 的直接检验：在 `065bb82` 的真实传播链上，是否存在任何已有的来源级载体（R39 的逐资源 KGW 即可，不开发新算法）。它在模型改写端点上的来源定位，需要在相同误报下超过 BGE 对检索遗漏单元的覆盖。若否，RKW 路线按证据关闭。

## 6. 对论文定位的影响

- 用户未接受"CA-PD 为唯一核心"。本复核不改变这一点，只提供证据。
- 来源感知动态联合控制：X3-E2E 显示，其安全增益等于证据召回（性质 B3）。BGE + NLI 是**最强非水印来源追踪基线**，而不是原创水印贡献的替代品。
- 水印能否成为原创贡献，取决于第 5 节那一个检验。在它之前，现有证据只支持把 KBPW 写成负结果，把 RKW 写成未验证的方向。
