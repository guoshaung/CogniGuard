## 1. 共享条件（三方必须完全相同）

| 项 | 取值 |
|---|---|
| 判定内核 | 现有 `check_release`（CA-PD），k ∈ {2, 3}；f ∈ {0, 1, 2}；授权由 `AccessRegistry.is_authorized` |
| 证据接口 | `pe-0.1`，只通过 `augment_knowledge` / `trusted_event_credits` 进入决策 |
| 资产与秘密 | E5 合成（K = 16、32，见证 w 2–4）、E6 Eedi、E7 Sum Leaks；外加两个场景（第 3 节） |
| 传播 | Gate 0–2 的 world 模型：未记录转发 ≤ f，sparse/complete 图；内容变换 identity / paraphrase / fragment（片段长度 ∈ {5, 20, 50, 100} 词） |
| 种子 | 主实验 0–29；空跑 99 |
| 安全规则 | fail closed：证据缺失、版本不符、检测器异常 → 不放宽 |

## 2. 对照组（同一决策函数，只换证据来源）

| 组 | 证据 | 说明 |
|---|---|---|
| R0 | 只有回执 | CA-PD 本身 |
| F-strong | 强内容指纹（MinHash + SimHash + BM25 + BGE 检索与重排序，取并） | 模型版本同 Gate W0 附录 |
| CRED | 签名内嵌凭证（发行号 HMAC） | 并行扫描已证明它能恢复 W0 的五个"合法翻转" |
| LOG | 可信通道日志 → `trusted_event` | 唯一允许使用 k+(f−d) 的组 |
| WM | 普通来源水印（KGW 类） | 只产持有证据 |
| WM+K | 普通水印 + 知识单元核验（简单交集） | 知识绑定水印必须超过它，才算"有算法区别" |
| KBW | 候选知识绑定水印（Codex） | 待测方法 |
| Oracle | 真实持有 | 上界 |

## 3. 场景

1. **教育四 Agent**：教师（资产主人）、助教 Agent、两个学生 Agent；资产为 Eedi 题目秘密；学生间存在未记录转发。
2. **软件工程资产保护**：仓库所有者、两个编码 Agent、一个外部审查 Agent；资产为私有 API 密钥派生信息 / 未公开模块设计（用现有 `code-domain adapter`）；转发通道为共享工作区。

## 4. 指标（每组同一张表）

| 指标 | 定义 |
|---|---|
| 危险放行 / 联盟违规率 VR | Oracle 会拒绝而该组放行的次数；g ≤ k 联盟中 L\* > τ 的比例 |
| 正常任务效用 UR_normal | 与 E5–E10 相同 |
| 误拒率 | Oracle 允许而该组拒绝 |
| 错误授权率 | 任何组都不得 > 0（授权只由注册表决定）；> 0 即实现错误 |
| 错误归因率 | `candidate_issuance_ids` 不含真实回执的比例（只描述，不进决策） |
| 预算低估次数 | 计入 d 的事件中非真实或重复的次数（只有 LOG 组可能 > 0） |
| 开销 | 每次决策耗时（含检测）P50/P95；检测器 GPU 时间单列 |

## 5. 预先写下的判定（草案）

- **H-KBW（主）**：在 fragment 和 paraphrase 下，KBW 相对 **F-strong、CRED、WM+K 三者中最强者**，危险放行差的配对 bootstrap 下界 > 0，且 UR 下降 ≤ 0.01。任何一个基线已经为 0 危险放行时，判 STOP（"基线已安全"）。
- **H-LOG（实现核对）**：LOG 组在伪造率 φ = 0 时预算低估为 0；φ > 0 时报告低估与危险放行（Gate 2 已显示伪造事件证明几乎必然低估）。
- **H-Auth（实现核对）**：所有组错误授权率 = 0。
- 只描述：知识丢失（改写后单元消失）与残留标记（标记在、知识不在）各自造成的误拒和错误归因。
