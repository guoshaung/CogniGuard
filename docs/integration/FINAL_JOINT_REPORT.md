## 1. 两个机制的数学建模

### 1.1 机制 A：CA-PD（有界联盟组合泄露控制）

记号沿用 `FORMAL_DEFINITION_v0.1.md`。

- 秘密 σ = (𝒮, s\*, π, g)；单元 u ↔ 谓词 φ_u；单元集合 A 的泄露 L(A) = log₂(V_g(π|A)/V_g(π))，单调闭包 L\*；阈值 τ；
- 见证 𝒲_τ(σ)：使 L\* > τ 的极小单元集。引理 1：L\*(A) > τ ⇔ A ⊇ 某个 W；
- 知识状态 K = (K_i)_{i∈N}；k-安全：∀C ⊆ N，|C| ≤ k，∀W：W ⊄ ∪_{i∈C} K_i；
- 放行规则 Allow_k(r, R, K) ⇔ Auth(r, R) ∧ ∀W：W ∖ (K_r ∪ R) 不能被至多 k − 1 名其他主体的持有覆盖；
- 判定：每个 W 上的最小集合覆盖，位掩码 DP，复杂度 O(min(N, 2^m) · 2^m)，与 k 无关；m > m_max 时保守拒绝；
- 运行时约束：预留 → 提交复核（策略版本、授权），跨进程命名锁；
- 命题 4：k ≥ max\|W\| ⇒ k-安全 ⇔ 全局并集安全。

### 1.2 机制 B：证据驱动的动态知识状态（pe-1.0）

- **观测** o = (holder h, 声明单元 U_o, 发行候选 I_o, 可选事件声明 e_o)。核验器 V 给出 (C_o, S_o, ê_o)：
  - C_o ⊆ U_o：经核验在产物中出现的单元（词面包含度 ≥ 0.95，或 NLI 判为 entailment）；
  - S_o = U_o ∖ C_o：疑似；
  - ê_o：只有签名有效的通道日志才非空。
- **状态**（只增不减）：
  - K^r_t：回执；
  - K^c_t = K^r_t ∪ {(h, u) : u ∈ C_o} ∪ ⋃_{ê_o=(a→b)} {(b, u) : u ∈ K^c(a)}（最坏情况事件闭包）；
  - K^s_t = K^c_t ∪ {(h, u) : u ∈ S_o}。
- **决策**：Allow^L(r, R) ⇔ Auth(r, R) ∧ Allow_{k′}(r, R, K^L_t)，L ∈ {r, c, s}，k′ = k + max(f − d, 0)。d 只计签名有效、端点已知、去重后的事件，且只在 f 可强制执行时计；**内容证据（含 NLI）对 d 的贡献恒为 0**。
- **授权**：Auth 只由 `AccessRegistry` 决定，与任何证据无关。

**性质 B1（单调）**：K ⊆ K′（逐主体）⇒ Allow_k(r, R, K′) ⇒ Allow_k(r, R, K)。所以 K^r ⊆ K^c ⊆ K^s 时，证据只会把允许变成拒绝，不会反过来。
*证明*：K′ 上能覆盖 W ∖ (K′_r ∪ R) 的 ≤ k − 1 个帮手，在 K 上覆盖的是更大的缺失集，不会更容易；所以 K 上存在违规联盟时，K′ 上一定也存在。∎

**性质 B2（核验可靠 ⇒ 不增加误拒）**：若核验可靠，即 C_o ⊆ H_t(h)（被确认的单元确实在持有者手中），并且事件闭包不超出真实持有，那么 K^c_t ⊆ H_t。于是任何由确认层引起的拒绝，在真实状态 H_t 上也会被 Oracle 拒绝。所以确认层**不增加误拒**，且危险放行不多于仅回执。
*证明*：由 B1，K^c ⊆ H 时，¬Allow(K^c) ⇒ ¬Allow(H)。∎
推论：误拒只能来自核验的假阳性（C_o 中不真实的单元）或疑似层。实测与此一致：词面核验 precision = 1.0、误拒 0【已复核】；NLI 报告的 4/835 误拒对应其非零假阳性【Codex 报告，未推送】。

**性质 B3（降幅是召回的函数）**：在每个危险请求恰好依赖一个未登记单元的夹具中，危险放行的减少量 = 被确认的、相关的单元数。所以"召回 99/137"和"危险放行 137 → 38"是**同一个量**，不能当作两个独立结果。

## 3. 相同证据条件下与最强基线（含 OCELOT）的比较

| 问题 | 结论 | 依据 |
|---|---|---|
| CA-PD 的优势是不是额外信息带来的 | **不是**：E5–E7、E10 中所有臂读相同回执 | 2.1 节 |
| 动态知识状态的优势是不是额外信息带来的 | **是**：增益 = 证据召回（B3）。按接收方或按轨迹记账的方案拿到同样的确认持有，也会得到同样的拒绝；在 k = 1 时，"按接收方记账 + 动态证据"就是本机制本身 | 2.2、2.3 节 |
| 与 OCELOT 在相同证据下比较 | **证据不足**：没有忠实复现（OCELOT-Edu 是提示词近似，阶段 1b 暂停），附录是否跨接收方计费仍【待核】。可比的只有结构近似：per_recipient_bits、global_bits（按轨迹或个人增量记账）、pairwise_only（成对联合校准）。它们在相同回执下输给 CA-PD（E5–E7）；在相同证据下，它们与动态知识状态同样受益 | E5–E7；`PRIOR_ART_AUDIT` F 节 |
| 与全局并集账本 | k ≥ max\|W\| 时等价；X3-E2E 的 k = 2 单元格正是这种情况（w = 2），所以退化 | 命题 4 |

## 4. 创新点（如实）

| 类型 | 内容 | 不能声称的 |

| 建模 | 组合推断下离散秘密的谓词单元、g-泄露、见证（引理 1）；把"有界联盟能否补齐见证"作为放行判据 | 集合覆盖 DP 本身是标准算法 |
