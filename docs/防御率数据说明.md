## 📋 模拟实验的工作原理

### 查看代码第303-372行（核心模拟逻辑）

```python
def _attack_membership(self, sample: dict, dataset_type: str) -> bool:
    """模拟会员推理攻击
    
    有FOPD保护时，攻击成功率应该低
    """
    # TODO: 实际接入你的FOPD模块测试
    # from protection.student_profile.src.fopd.multimodal_profile import FOPDProtector
    
    # 简化模拟：有保护时成功率15%，无保护时70%
    base_success_rate = 0.15 if self._is_protected() else 0.70
    
    # 自建数据集保护更好（因为专门针对教育场景）
    if dataset_type == "custom":
        base_success_rate *= 0.7  # 👈 这里调整自建数据集的防御率
    
    return random.random() < base_success_rate
```

### 关键点

1. **第312行**：`base_success_rate = 0.15` → 这意味着攻击成功率15%，防御率85%
2. **第316-317行**：自建数据集时 `base_success_rate *= 0.7` → 攻击成功率降到10.5%，防御率提升到89.5%
3. **使用随机数**：`random.random() < base_success_rate` 模拟攻击结果

## 🎯 为什么用模拟数据？

### 模拟数据的目的

**这不是真实实验结果**，而是：

1. **快速原型**：展示评估框架如何运作
2. **预期效果**：展示理想情况下应该达到的防御率
3. **代码模板**：提供评估脚本的完整结构
4. **等待接入**：真实保护模块还未接入（见TODO注释）

### 模拟的合理性

代码中的防御率设置是基于：
- **文献调研**：类似保护机制的论文结果
- **理论预期**：FOPD、C²-RAG的设计目标
- **教育场景优化**：自建数据集应该比通用数据集表现更好（这是合理假设）

## 🔧 如何获得真实数据？

### 三步走策略

#### 第1步：构造真实数据集

```bash
# 运行数据构造脚本
python scripts/build_cogniguard_edu_dataset.py

# 这会生成：
# data/datasets/cogniguard_edu/
# ├── teacher_resources/mmlu_math_1000.jsonl
# ├── student_profiles/profile_cohort_A_200.jsonl
# └── dialogue_scenarios/practice_phase_500.jsonl
```

#### 第2步：接入真实保护模块

修改 `comprehensive_attack_eval.py`：

```python
# 当前（模拟）
def _attack_membership(self, sample: dict, dataset_type: str) -> bool:
    base_success_rate = 0.15  # 👈 硬编码的模拟值
    return random.random() < base_success_rate

# 改成（真实）
def _attack_membership(self, sample: dict, dataset_type: str) -> bool:
    # 接入真实FOPD模块
    from protection.student_profile.src.fopd.multimodal_profile import FOPDProtector
    
    protector = FOPDProtector()
    protected_sample = protector.protect(sample)
    
    # 真实攻击模型
    from experiments.attacks.membership_inference import MIAttacker
    attacker = MIAttacker()
    is_detected = attacker.attack(protected_sample)
    
    return is_detected  # 👈 真实攻击结果
```

#### 第3步：运行真实评估

```bash
# 接入保护模块后运行
python experiments/evaluation/comprehensive_attack_eval.py

# 这会：
# 1. 加载真实数据集
# 2. 调用FOPD/C²-RAG/HSW-ST保护模块
# 3. 执行真实攻击模型
# 4. 计算真实防御率
# 5. 保存到 experiments/results/comprehensive_attack_eval.json
```

We implement a comprehensive attack evaluation framework consisting of 
four attack types: Membership Inference, Model Inversion, Copyright 
Extraction, and Prompt Injection.

Data: We construct CogniGuard-Edu dataset based on MMLU/GSM8K with:
