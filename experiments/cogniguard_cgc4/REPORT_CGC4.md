## 任务 A：前瞻式披露控制

### 模型

- 单元构成见证超图 W（形式定义下的推导集）。
- N 个主体，分两种安全分组：合并（k = N）和每主体独立（k = 1）。
- 任务类型 = （主体，若干互为替代的选项），任务按 q 独立同分布到达，共 H 步。
- 硬安全约束：任何一组的知识都不包含见证。

### 算法

**A1：增量机会损失。**

- 公式：选择使 Σ_t q̂_t·(1 − γ^{#alive_t(K ∪ o)}) 最大的选项。A0 就是 CGC3 的 CONFLICT，即 φ = 1[还剩选项]。
- 增量计算：披露 o 后，只扫描与 o 相交的见证（按单元建立的倒排索引）。对每个这样的见证，求剩余部分 r = W \ (K ∪ o)；某个存活选项 o' 被杀死，当且仅当 r ⊆ o'。超过最大选项规模的剩余部分直接跳过。
- 每次决策的代价是 O(Σ_{u∈o} deg(u) × 选项数)，而不是"全部见证 × 全部选项"。

**变体与对照**（使用相同的未来信息 q̂ 和 H）：

| 名称 | 说明 |
|---|---|
| A1_DRO | A1 加上 q 的 L1 球最坏情形 |
| MPC(d) | 深度 d 的期望最大化，叶节点用 A1 |
| BEAM(w, d) | 8 个公共场景，束宽 w |
| SAA(S, h) | 样本平均的事后最优 |
| SAA_DEFER | 允许延迟的 SAA |
| OPT_SERVE / OPT | 精确 DP；OPT 允许延迟 |

**开发集选定的参数**：γ = 0.3，r = 0.5，MPC d = 3，BEAM w = 3 / d = 3，SAA S = 16 / h = 4。

**任务分布估计**有三种：
- 真实 q；
- 历史估计：从 3P 条历史任务算经验频率，做 Laplace 平滑。**这是主结果**；
- 均匀分布。

**分布偏移**：测试序列来自 0.5q + 0.5·Dirichlet。

### 结果

测试种子，主结果用历史估计的 q̂。所有条件下所有方法都是 0 次违规。

- **OPT 增益中 A1 拿到的比例**：small 80%，KSL 74%，Eedi 78%。
- 剩余差距中，OPT_SERVE − A1 只有 0.1–0.3 个百分点，其余几乎都来自**延迟**（主动放弃一个可服务的任务）。
- 近似的延迟规划（SAA_DEFER）反而有害：base −1.1、tight −1.8、large k = N −5.1 个百分点。

**计算与内存**（毫秒 / 次决策，峰值内存）：

| 条件 | A1 | SAA | BEAM | MPC |
|---|---|---|---|---|
| base | 0.42 ms / 79 KB | 6.5 ms / 2.0 MB | 13 ms / 3.2 MB | 81 ms / 5.3 MB |
| large，k = N | 1.7 ms / 424 KB | 11.9 ms / 13 MB | 72 ms / 82 MB | **3,200 ms / 1.0 GB** |

在 large k = N 下，A1 比 MPC 快约 1,900 倍，内存约为其 1/2,400，效用相同（−0.004，区间含 0）。

**预测范围消融**（base / conflict，各 30 个实例，相对 A1 的差）：

| 方法 | base 差值 | 耗时 | conflict 差值 |
|---|---|---|---|
| MPC d = 1 | −0.001 | 0.15 ms | −0.003 |
| MPC d = 2 | 0 | 2.6 ms | — |
| MPC d = 3 | +0.002 | 59 ms | — |
| SAA h = 2 | −0.001 | — | — |
| SAA h = 4 | +0.001 | — | — |
| SAA h = 6 | +0.003 [−0.000, 0.006] | 22 ms | — |

在 conflict 条件下，所有范围的差值都在 ±0.003 以内。**加长预测范围几乎没有收益。**

**分布估计与鲁棒性**：
- 用真实 q、历史估计 q̂ 或均匀 q，A1 的效用几乎相同。
- 分布偏移下，MPC 和 SAA 比 A1 多 +0.2 到 +0.5 个百分点（例如 KSL：+0.005 [0.002, 0.008]）。
- DRO 没有带来增益（|Δ| ≤ 0.002）。
- 软机会值 A1 与硬可达 A0 没有差别（|Δ| ≤ 0.004）。

**泄露**：KSL 实例最终攻击者 V₁ 为 A1 0.389、CA-PD 0.404。A1 在完成更多任务的同时，泄露并没有更高。

### 失败模式

1. **Sum Leaks 衍生序列没有余量**：每个场景只有 2.5 类任务、1.3 个见证，所有方法都是 100%。目前的真实衍生数据无法检验 A。
2. **k = 1（每主体独立）、大规模时约束很松**：增益只有 +0.7 个百分点。
3. **近似延迟有害**，而延迟正是 OPT 剩余优势的来源。
4. **分布偏移下 A1 略逊于规划器**（−0.2 至 −0.5 个百分点）。DRO 修正无效。
5. **agentic PrivacyBench 适配性**：据 PrivacyFlow（arXiv 2610.40714）的描述，它有 986 个有序任务序列、5,873 个任务，事实是原子单元。但隐私标注是**逐事实的允许集合**，没有组合 / 推断标注；论文中也没有找到数据发布地址。没有组合见证，A 就退化为逐事实访问控制。**目前不能直接适配**，需要补充组合标注。

## 任务 B：联合信道治理

### 模型

- 治理方知道 x\*，但不知道攻击者视图 K0；它对 K0 持有一个信念（一组候选视图及概率）。
- 如实机制 M(o | x) 定义在所有候选攻击者格的并集上。
- **安全按逐个输出判定**：真实视图下，每个可能出现的输出 o 都要满足 max_s P(s | 格, o) ≤ max(τ, 格内先验 V₁)。平均互信息只作附注，不替代逐输出最大值。
- 4,592 个候选视图中有 2 至 4 个不确定单元。信念分两种：独立（product）和成对捆绑（corr）。治理方也可能错误地用乘积近似去刻画相关的真实信念。
- serial 结构因规模过大被排除（D5）。

### 结果

332 个测试实例，τ ∈ {0.34, 0.5}。

| 机制 | 独立信念：效用 / 违规率 | 相关信念（精确模型）：效用 / 违规率 | 真实相关、模型用乘积近似：效用 / 违规率 |
|---|---|---|---|
| ORACLE_LP（知道真实视图） | 0.819 / 0 | 0.864 / 0 | 0.864 / 0 |
| **ROBUST_LP**（对全部候选视图加约束） | **0.512 / 0** | **0.738 / 0** | **0.521 / 0** |
| CHANCE_LP，ε = 0.05 | 0.521 / 0.5% | 0.738 / 0 | 0.617 / 2.1% |
| CHANCE_LP，ε = 0.2 | 0.664 / 1.1% | 0.784 / 6.2% | 0.646 / 5.5% |
| MAP_LP（只看最可能视图） | 0.821 / **21.5%** | 0.871 / **15.1%** | 0.871 / **15.1%** |
| SIM_ROBUST（可模拟审计） | 0.118 / 0 | 0.247 / 0 | 0.055 / 0 |
| STEP_QIF（逐步 QIF） | 0.585 / **15.1%** | 0.738 / **19.9%** | 0.738 / **19.9%** |
| CAPD_F（形式 CA-PD） | 0.752 / **29.6%** | 0.846 / **28.1%** | 0.846 / **28.1%** |
| ROBUST_LP + 时延标签 | 0.512 / 0（以真实信念计的违规概率 0.1%） | 0.738 / 0 | 0.521 / 0 |

**配对差**：

| 比较 | 独立信念 | 相关信念 | 乘积近似 |
|---|---|---|---|
| ROBUST_LP − SIM_ROBUST | +0.393 [0.345, 0.441] | +0.491 | +0.466 |
| ROBUST_LP − ORACLE_LP（不知道视图的代价） | −0.307 | −0.127 | −0.344 |

用乘积近似刻画相关信念时，结果仍然安全（乘积的支撑集包含相关的支撑集），但更保守：比精确模型低 0.22。

**其他发现**：

- **多主体**：518 个实例。
  - 只对请求者加约束（k = 1）的 LP，对联盟违规 **21.8%**，最大超出 0.66；
  - 改用 k = 2 后为 0 违规，效用 −0.058 [−0.072, −0.045]。
- **压缩**：
  - 精确归并（世界按 秘密 × 允许输出 × 所在格 归并）：变量降到 23%，**100% 保持最优值**，求解时间中位数为 58%。
  - **见证剪枝**（丢掉"即使完整放行也到不了阈值"的视图）：只有 65% 保持最优值，**36% 的解违反被丢掉的视图**。它带来的 +0.074 效用全部来自泄露。原因是：拒答 / 降级的输出模式可以把世界集合切成任意子集，而"完整放行"只能按取值划分。**被剪掉的视图仍可能通过治理行为泄露。**
- **其他可观察行为（时延）**：给鲁棒 LP 的放行加上"低风险快 / 高风险慢"的标签，几乎没有产生额外违规。原因是鲁棒 LP 在高风险世界里本来就很少放行。这是一个阴性结果；当底层机制不保守时，时延标签可能有害，本轮没有测试。
- **平均互信息能否掩盖违规**：在违规实例中，没有出现互信息低于 0.1 bit 的情况。本数据中"平均值掩盖个别输出"的现象没有在这个阈值下出现，但所有判定仍以逐输出最大值为准。

### 失败模式

1. 鲁棒 LP 的代价大（相对 Oracle −0.13 至 −0.34）。
2. 机会约束 LP 在模型误设时违规率超过 ε 的名义水平：ε = 0.2 时实测违规 5.5–6.2%。按真实信念计的违规概率为 3.7–4.2%，在 ε 内；但单个实例的违规比例可以更高。
3. 见证剪枝不安全。
4. 联合 LP 的规模随攻击者格的并集增长，serial 结构已经超出时间预算。

## 任务 AB：统一可达性与联合泄露约束

### 设定

- 攻击者知道所有机制；治理方与攻击者同步计算后验 π_t。
- **所有组使用同一条安全规则**：每个实际发出的输出都满足 max_s P(s | 历史, o) ≤ max(τ, V₁(π_t))。
- 所有组的信息相同（π_t、q、H），都没有核验预算，τ 相同。
- 选项选择只依赖 π_t 层面的量，不依赖 x\*，所以选择本身不构成侧信道。
- 为保证动作空间公平，增加了 CAPD_D（带可模拟降级的 CA-PD）和 CAPD_D + A（D4）。

### 结果

376 个实例 × 12 条序列，τ ∈ {0.34, 0.5}。下表为每步效用；6 个保证组的违规都是 0。

| 组 | τ = 0.34 | τ = 0.5 | 合并 |
|---|---|---|---|
| CAPD | 0.695 | 0.773 | 0.737 |
| CAPD + A | 0.713 | 0.785 | 0.752 |
| CAPD_D（加降级） | 0.702 | 0.783 | 0.745 |
| CAPD_D + A | 0.721 | 0.795 | 0.761 |
| CAPD + B | 0.635 | 0.824 | 0.736 |
| **CAPD + A + B** | **0.737** | **0.893** | **0.820** |
| CAPD_F（参照，无保证） | 0.646（违规 125 步） | 0.824（违规 376 步） | 0.742（11% 实例违规） |

**效应分解**（合并两个 τ，配对 bootstrap）：

| 效应 | 估计 [95% 区间] |
|---|---|
| A 不带 B（CAPD + A − CAPD） | +0.014 [0.011, 0.018] |
| B 不带 A（CAPD + B − CAPD） | −0.001 [−0.017, 0.016]；τ = 0.34 时 **−0.060**，τ = 0.5 时 +0.050 |
| A 带 B（CAPD + A + B − CAPD + B） | **+0.084 [0.075, 0.094]** |
| B 带 A（CAPD + A + B − CAPD + A） | +0.069 [0.055, 0.084] |
| **交互项** | **+0.070 [0.061, 0.079]** |
| 只加降级动作（CAPD_D − CAPD） | +0.008 [0.006, 0.010] |
| **同动作空间下的 A + B（CAPD + A + B − CAPD_D + A）** | **+0.060 [0.046, 0.075]** |
| A + B 对 CA-PD | **+0.083 [0.069, 0.098]** |

**解释**：

- B 单独使用时，每一步都把当步效用最大化，把攻击者后验推到阈值边缘，后续请求就无法再安全放行。在紧阈值（τ = 0.34）下，它甚至比 CA-PD 更差。
- A 的可达性项把"给未来留余量"加了回来，所以 A 在有 B 时的价值是没有 B 时的 6 倍。
- 联合 LP 的价值不来自降级这一额外动作：只加降级只有 +0.8 个百分点。

### 失败模式

1. **增益集中在少数结构**：B 带 A 的增益在 and_max 上为 +0.69，在 relation 上为 +0.07，其余结构只有 +0.01 至 +0.03（fact、mixed 的区间含 0）。
2. **B 单独使用在紧阈值下有害**。
3. **A 的未来可达性用的是可模拟代理**（未来能否安全放行或降级），不是未来 LP 的价值。
4. **规模小**：H = 5，选项都是单个单元。

## 下一步建议（本轮未执行）

1. **A**：
   - 构造约束更紧的真实衍生任务流：Eedi 已显示 +4.5 个百分点；Sum Leaks 需要把多场景合并成长序列。
   - 为 agentic PrivacyBench 补组合标注，或另找含组合敏感性的真实序列。
   - 研究低成本的"可证明有益的延迟"规则，以接近 OPT 剩余的 1.1–1.3 个百分点。
2. **B**：
   - 研究鲁棒 LP 的低保守近似，例如只对与决策相关的视图做精确约束，同时保证安全。
   - 做多步滚动的鲁棒 LP。
   - 在不保守的底层机制上重新测试时延等其他可观察信道。
3. **AB**：
   - 把 A 的可达性代理换成未来 LP 价值的近似。
   - 扩大到多单元选项和更长时域。
   - 检查增益为何集中在 and_max 类结构。
