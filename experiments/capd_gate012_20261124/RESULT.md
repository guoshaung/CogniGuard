## 3. 不完美证据下的安全表现（理论第 4 节）

| 噪声单元 | B3：危险放行 | B2：危险放行 | B2b：危险放行 | Ours：危险放行 |
|---|---|---|---|---|
| r = 0.8 | 26 | 0 | 0 | 0 |
| r = 0.5 | 52 | 0 | 0 | 0 |
| q = 0.2（错误归因） | 21 | **9** | 0 | 0 |
| 组合单元 | 20 | **11** | 0 | 0 |
| φ_c = 0.05（伪造事件证明） | 0 | 0 | 0 | 0，但 **269/270 次运行出现了预算低估** |

- **把持有证据当作事件证明（B2）**，在错误归因下会造成危险放行。这证实了用户决策第 3 条的修正。
- **只把证据加入账本（B3）**，在证据完美时等同于 Oracle；一旦证据漏检或归因错误，就会出现危险放行。所以它不能作为有安全保证的方法。
- **伪造事件证明**时，Ours 的预算低估几乎每次都会发生。这一次碰巧没有造成危险放行，但安全性完全依赖事件证明不可伪造。
- **违反预算假设（F_true = 2f）**：B1、B2、B2b、Ours 都没有出现危险放行；B0 出现 189 次。这说明在本模拟中，安全余量还比较宽，不能推广到一般情况。

## 4. 局限

- 结果来自确定性模拟，"共谋成员之间的未记录转发"是 world 一侧的假设。在随机传播和 Eedi（见证以 w = 2 为主）上，问题基本不出现（理论命题 4）。
- 只做了全量转发、静态的无向图；部分转发和动态拓扑都没有覆盖。
