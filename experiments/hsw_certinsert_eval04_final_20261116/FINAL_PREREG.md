# EVAL-04-FINAL · T6 双嵌入器预注册

冻结日期 2026-11-16。本轮变更由用户在 T6 内容处理前指定。EVAL-04-M 的规则转写更正在对应 DEVIATIONS.md。按原 M 门槛应保留 GREEDY-dyn。本轮同时评测 OPT 与 GREEDY-dyn，避免把开发组的探索性优势当成独立验证，亦保留和 EVAL-03 的连续对照。

## 样本与方法

- 预先保留的 OpenStax 章节来自阶段 0 的 CHAPTER_ALLOCATION.json。只从这些固定模块抓取，按冻结历史渲染器抽取原题干，排除图表依赖、解析不全及精确重复。历史排除只使用已归档的模块、章节和可用哈希。规范化为 Unicode NFKC、小写与折叠空白。题干须 8–500 英文词。物理、化学、生物、数学优先均衡，以固定哈希排列作学科轮询，每学科缺额依序向其余三个学科分配。数学可纳入 contemporary-mathematics，统计和天文不补进四学科队列。冻结 200 个题干及其输入哈希后才生成。若不足 200，记录可用分母与失败，不扩选未保留章节。
- T6 来源输出用 Mistral-7B-Instruct-v0.3 Q4_K_M，区别于 T5 的 Qwen 家族。只给题干，一题一次，最多 1024 个新 token，temperature=.7、top_p=.9、top_k=40、repeat penalty=1。使用 EVAL-03 内容提示和 Mistral 原生聊天模板。种子为 SHA-256(`EVAL04-FINAL-20261116|generate|case_id`) 前八位转整数再按位与 0x7fffffff。运行错误、截断与格式检查分别记录，不重试或修补。数据与结果在本机，公开发布仅包含脱敏定位和度量。
- OPT 是 T6 主方法，GREEDY-dyn 是同源对照。两组共用未加水印文本、EVAL-03 手工词表、冻结背景 q、k=4、密钥、原始公开检测器、结构规则、保护边界、预算和证书，沿用 EVAL-04-M 的隔离实现。OPT 每源求解上限 60 秒。正式嵌入、公开复检、失败和证书状态逐源保存。第 0 阶段的 L* 未产生，自动词表、多词表曲线和依赖 L* 的 D-multi 使用 NOT_AVAILABLE 状态。
- 实证理由限于 M 的生成讲解组。OPT 覆盖 137 对 135，统一动态评分低 8.65%，开头／中段 100 词检出各略高。OPT 的求解耗时较长，因此继续把运行成本与效果并列报告。其他指标沿用原始分母，T6 独立决定是否复现这些差异。
- KGW 和 Unigram 的重写输入都是各源对应的原始未加水印 T6 讲解。只在 OPT 和 GREEDY-dyn 任一成功的源集合上各运行一次，冻结排序、源输出哈希及其在两组的成功状态后才调度。保持 EVAL-03 的 Qwen 7B 重写后端、提示、超参、检测阈值和各自原 tokenizer，区别于用于构建 T6 源文本的 Mistral。两组都失败的源无这两个基线的计划任务。失败无替补，不在成功交集上重定义并集。
- 冻结后续评价遵循原任务中的全文与 OCR、头中尾 100 词、头中 200 词、一次目标 70% 压缩、学习攻击等定义。先报告两嵌入器全 200 源覆盖，再分别报成功后的条件检出和共同成功源配对比较。KGW 与 Unigram 单列并集分母及实际完成率。未生成人工评分。两位独立审核者应仅看无水印源输出和对应题干，40 源按固定哈希选取，人工标注完成情况单列。
