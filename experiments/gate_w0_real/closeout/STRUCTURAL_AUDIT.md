# HSW-ST 结构审计与 pe-1.0 联动

**KBPW 维持 STOP。多智能体知识来源追踪继续以可核验知识单元及其治理贡献为主。** 本次使用冻结的 180 个真实 Pilot 端点，每个版本各 45 个。重新运行原检测器逐条匹配已保存的发行预测。所有计算复用既有文本、检索预测和人工式评审，未调用生成模型。

## KBPW 的损失逐层归因

分母是终稿中仍有至少一条知识事实支持的发行标签。一个发行在同一端点最多计一次。宽松扫描要求原码字的两个词按原序相邻，允许标点、空白、大小写和句首位置变化，也允许缺少 `that`。严格格式阶段复用原分句和正则。理想知识核验仅在正确码字还可见时，用冻结的事实评审判定绑定事实是否保留。M1 以该发行任一事实保留为准。两种上界使用原发行集合和评分标签，只用于诊断，且限于可识别的原码字词面。

- **M1**。有支持发行 81 个，宽松扫描、完整原前缀、严格格式、原检测、理想核验均为 28 个（34.6%）。53 个缺码字。M1 本身没有 Jaccard 或 margin 门槛。
- **M2**。有支持发行 82 个，宽松扫描、完整原前缀和严格格式均为 32 个。Jaccard 0.95 淘汰 4 个，margin 0.05 额外淘汰 0 个。原检测为 28/82（34.1%），理想核验为 32/82（39.0%）。50 个缺码字。
- **M3**。有支持发行 82 个，宽松扫描、完整原前缀和严格格式均为 31 个。Jaccard 淘汰 3 个，margin 额外淘汰 0 个。原检测为 28/82（34.1%），理想核验为 31/82（37.8%）。51 个缺码字。
- **纯文本对照**。45 个端点共 82 个有支持发行，按冻结协议空码本，发行恢复 0。无嵌入对照独立于载体损失分母。

每种标记方法的 28 个原检测命中均来自确定性转发和截断。只看模型摘要与两档改写的 27 个端点，原检测三组均为 0，理想核验上界分别为 M1 0/53、M2 4/54（7.4%）、M3 3/54（5.6%）。7 个可恢复机会全部来自同一条三源轻改写路径的重复轮次和不同版本，Jaccard 为 0.739–0.882，margin 为 0.094–0.369。各组的真实摘要和强改写都没有可见正确码字。本批观测到的**格式独立损失为零**。原检测复跑一致，7 个漏检可由现有阈值解释，主因仍是码字消失。

M3 的受控校准预测为第 1、2、3 个事实分别 43.4%、41.9%、41.2%。显著性权重为 1、1、2，实际选择第 1、3 位。真实 Pilot 分别暴露 90 次，载体存活 31/90（34.4%）、19/90（21.1%）。只看模型操作，分别为 3/54（5.6%）、0/54，事实本身仍分别保留 36/54、48/54。校准排序与已选择两位的观测顺序一致，绝对存活率高估明显。第 2 位没有被 M3 选用，真实存活率无分母。重复轮次和确定性操作的混合限制了对预测泛化的判断。

在 `f65ebab` 上重放 Gate W0 的 30×2 种子和两个 M2 臂。382 次原上游有载体的观察中，**382/382 的前缀范围与末五词完全不相交，0/382 保留正确相邻码字**。这是句首写入与末尾取样的结构性冲突，理想解码在这些既有后缀中的上界也是 0。该结论覆盖冻结的 Gate W0 规则，短片段的其他构造有各自分母。完整复制凭证的既有反例及全部历史 STOP 判定保留。

## 实际来源追踪与 CA-PD

内容检索复用 065bb82 的逐条 BM25、BGE 和 BGE + TinyBERT 重排序预测。资产 F1 按检索候选计分。每个候选资产的登记单元送入 Claude `eec96b6` 上的 `TextUnitChecker` 和 `RuleVerifier`，具体单元按 confirmed 计分。发行候选只作为审计记录。唯一发行恢复与候选覆盖单独计。评审标签在全部治理决定写出逻辑完成后才用于评分。

重点子集是纯文本的 27 个真实模型摘要、轻改写与强改写端点。

- **BM25** 恢复 24/54 个资产标签，资产 F1 0.615。确认 2/137 个具体知识单元，F1 0.029。发行候选包含 24/54 个真实发行，唯一发行恢复 0/54。固定见证回放的危险放行从 137 降至 135。
- **BGE** 恢复 49/54 个资产标签，资产 F1 0.810。确认 6/137 个具体知识单元，F1 0.084。发行候选包含 49/54，唯一发行恢复 0/54。危险放行从 137 降至 131。
- **BGE + 重排序** 恢复 48/54 个资产标签，资产 F1 0.762。确认 6/137 个具体知识单元，F1 0.084。发行候选包含 48/54，唯一发行恢复 0/54。危险放行从 137 降至 131。

在四种版本合计的 108 个模型端点上，BGE 资产 Precision、Recall、F1 为 72.9%、91.2%、0.810，具体单元为 100%、4.5%、0.086，唯一发行恢复 0/215。在每方法 3,888 个固定见证请求中，BM25、BGE、BGE 加重排分别少放行 16、24、23 个有真实见证的请求。三组观察到的不必要拒绝均为零。全 180 端点另单列在指标文件，含原样转发和截断控制。

治理回放使用现有 `AccessRegistry`、`SecurityState` 和 `CapdPolicy`，固定 k=2、f=0。对每个端点枚举登记资产的三单元见证，给请求者预置一个模拟可信回执，逐个请求另一单元，第三个单元由观测持有者可能补齐。静态与知识动态臂共享权限、回执和请求。该固定见证夹具量化具体单元补全对决策的贡献，效应受夹具结构影响，不能外推为生产风险下降比例。低单元召回和高资产召回的差距是本批来源追踪的主要结果，已检索资产的其余单元仍停留在疑似层。

## 交接

治理侧读取 `artifacts.jsonl` 与 `observations.jsonl`。持有者、回执、授权和时序为此回放的显式夹具，实际联动由可信运行上下文绑定。单元核验输出在 `verified.jsonl`，决策在 `decisions.jsonl`。所有 540 条观察通过 Claude 的 formal provider 契约，参考消费者契约无错误。对全部观察移除发行候选后，核验输出中影响账本的字段逐条一致。文本证据无可信事件主张及已验证发行身份，治理抵扣为零。结构计数和逐码字证据见 `structural_counts.json`，三层指标与回放合计见 `ca_pd_metrics.json`。

在实验工作树用本地 Python 执行 `structural_audit.py --contract <f65ebab 检出> --data <原合成目录>` 和 `link_ca_pd.py --contract <eec96b6 检出>`。
