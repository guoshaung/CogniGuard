# 核验器对照协议

基线为 631409e 的 pe-1.0 回放和冻结 BGE 资产候选。主报告使用已有 180 个端点，其中单列 108 个模型端点和 27 个无水印模型端点。开发数据使用 fixtures.py 中六个独立手写来源族及其改写与反例。压力测试使用另外四个手写来源族。开发、压力测试和冻结回放的来源 ID 与传播链 ID 均隔离。手写样本用于定阈值和检验具体错误，规模不足以估计生产误报率。180 个端点及其知识键不会用于定阈值。

每条核验只使用冻结候选单元及已登记的参考表达。模型输入候选证据窗口为单句和相邻两句，归一化排序与最高窗口分数在运行前固定。BGE 使用句向量 cosine，NLI 使用窗口蕴含参考表达的三类 softmax 蕴含分数。增强 NLI 在同一分数上同时要求数值、单位、显式条件和否定线索一致。每个打分方法独立在开发组选择阈值，要求零错误确认，在可行阈值中最大化正确确认并取最低阈值。若最高负例分数与正例重叠，报告由此产生的召回损失。读入测试文本前写出模型权重、开发数据哈希与阈值。压力集单独评分。

Containment 使用 Claude TextUnitChecker 0.95。理想诊断只确认冻结候选中的真实在场单元，仅应用于独立评分后的计数及标为反事实的夹具结果。实际治理臂用 eec96b6 的 RuleVerifier、SecurityState 与 CapdPolicy 重放原有请求、回执和权限。错误确认率同时报告 FP/(FP+TN) 和 FP/(TP+FP)。危险放行和过拒率分别报计数与相应危险请求、安全请求分母。模型在本地运行，开销区分加载、独立开发打分及测试打分。
