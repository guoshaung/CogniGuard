# 执行与限定

- 第一次 CUDA 打分器初始化失败。复用旧 F 模块导入时会把 CUDA 隐藏给子进程。第二次只对独立评分子进程恢复启动前的显卡可见性，继续使用冻结权重和打分桥。首次没有输出逐文档结果。
- OPT 对已证实结构不可行的文档跳过打分。阈值、间距、组、预算或位置约束仍参与该判定。资格相关的锚点与检测验证使用成品文本。不把静态目标的最优性推广到按插入历史改变代价的动态目标。
- 表中自然度是冻结 3B 分数，没有人工自然度评级。部分源文自身已命中，逐篇单列零插入成功。
- EVAL-03 的公开检验在 W 固定后只依赖不同词命中数。失败原因使用实际重复命中和约束，避免把不显著归因于某个命中词本身的 q。
