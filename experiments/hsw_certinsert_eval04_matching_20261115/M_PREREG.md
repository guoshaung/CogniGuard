# HSW EVAL-04-M 开发预注册

2026-11-15。以任务书第 1、4 节及用户确认的附录 M1 为准。比较仅限冻结资料库 R。T1–T6 不作为输入。

## 1. 方法定义

沿用 EVAL-03 CertInsert 的词表、k=4 的源文专用词选择、锚点与密钥、背景 q、Poisson-binomial 上尾、正文结构保护、候选位置条件、6% 词预算、8 词间距、每句至多一处、每模式组一次、证书及原始信息不变式。目标 p<0.001，公开检测 p<0.01。原文命中与插入的不同词取并集，p 由冻结检测器按并集大小计算。原文已达标记为零插入阳性，覆盖表同时列出实际插入数。词表、检测器和证书不改。

### M1 · 三组与共同复评

- GREEDY-dyn 是 EVAL-03 原动态贪心，逐次按已经插入的词更新旧评分窗口。使用原容量准入、位置、大小写、成本、排序和停止逻辑。原阈值及打分资源界限保留，资源中断单列。
- GREEDY-fix 与 OPT 共用一次性评分表。每个合法位置与词的成本是在未改动原文上的总 −Δlog-prob。GREEDY-fix 只把原贪心的逐步分数替换为该表。
- OPT 用 OR-Tools CP-SAT 对不超过 15 个词子集的可行放置求全局最优。检验含原文自然命中，达到严格 p<0.001。使用 6% 预算、不同句、不同组、8 词间距及同一合法候选图。有明确不可能达到目标的样本可用精确可行性判定跳过 3B 打分。同一文档求解总时限 60 秒。非最优返回或超时单记，不以已找到的解或贪心替代。将浮点边成本按其精确二进制比例转为整数并校验总范围，避免用四舍五入改变目标；若无法精确编码则单列失败。最优总代价相同时偏好更少词，再按字母序。同一词组合、同成本的具体位置由固定单线程求解器给出确定性解。
- 三组最终成功输出统一用原动态窗口复评。按原文字符位置从前往后依次加入各自最终放置，对每步用 EVAL-03 的前五句、目标句、后一句窗口及已加入内容计算 −Δlog-prob。此顺序对所有方法一致。报告总成本和最大单处成本；复评失败单列。固定表成本只用于优化和验证全局最优，不用于论文的自然度比较。
- 候选预测沿用旧泊松二项代码；公开复检在最终文本上独立重选 W、核对锚点和源数值／公式不变，并逐字节恢复。若 OPT 的数学可行解未通过这些旧检查，作为已验证无效组合排除并在 60 秒内继续精确求解。所有对外计入成功的 OPT 文本须满足 p<0.001。

## 2. 输入、统计和复核

- 纳入原始 R 的全部 300 篇一次生成讲解。从 R_build 的非生成教材文档按 SHA-256 排序固定抽取 300 篇。抽样种子 `EVAL04-M-20261115`，标签 `textbook`，排序键 `seed|label|document_id` 的 UTF-8 SHA-256。两个组分别报告。使用 EVAL-03 的 Markdown 结构适配器和原正文词数计数；缺原题干的教材文档只用冻结记录内的可用题干或标题信息。教材和讲解公开发布时只提供去文本数值和哈希。
- 固定原 Qwen2.5-3B Q4_K_M 和历史前向打分桥，评分端沿用 EVAL-03 的 CUDA、上下文上限 1024 token 及完整上下文的总 log-prob。250,000 前向 token、300 秒原动态文档打分限额和超限状态单报。相同完整上下文的原始分数可缓存，但 GREEDY-dyn 仍使用当前已选插入的窗口。记录两部分打分缓存哈希。
- 长度箱 <100、100–200（含 200）、201–400、>400。摘录用 EVAL-03 英文字词和窗口规则，少于 100 词不作为已评估摘录。分别记录分母和缺失。插入耗时剔除 3B 评分时间。
- 两者成功且具有完整统一代价的文档进行配对，差值为对照减 OPT。绝对差及单处最大代价均报告。相对改善以配对样本的平均差除以对照平均总成本，仅在该分母为正时解释；逐篇相对差也只在对照成本为正时计算，单列其余分母。按组文档重采样 2,000 回，固定种子 20261115，报告百分位区间。
- 只在 OPT 成功、对照未成功的同一文档做失败原因审查。Poisson-binomial p 只由冻结 W 与不同命中数量决定。同一个命中不能归咎于其单词背景频率较高，另检查贪心是否重复命中或是否受句子／间距、组和预算限制。保留原失败状态和检测器不变式失败。
- 五个手算例与 50 篇冻结抽取的真实 R 文档做独立暴力比对。抽取在查阅评分或结果前对 600 篇固定哈希排序，标签 `brute`。比较全约束静态最优成本、词集合和可行性；同价同词的放置可能有多个最优解。未完成不视作通过。

## 4. 冻结判定

只使用 300 篇生成讲解比较 OPT 对原版 GREEDY-dyn。OPT 覆盖点估计须不低于原版，并至少符合原任务书的一项。覆盖率提高至少 3 个百分点，或共同成功文档的动态复评平均成本降低至少 10% 且配对 bootstrap 绝对改善区间下界大于 0，或开头与中段 100 词的检出率分别不低超过 5 个百分点。缺失或不可定义的证据不视为达标。

通过则建议 T6 采用 OPT，否则保留 GREEDY-dyn。OPT 对 GREEDY-fix 单独报告，用于隔离求解器收益。教材组不参与判定。检测器和阈值冻结，误报率不重测。程序只做开发测算，跑完和推送后停止。

OR-Tools 9.11.4210，单求解线程。冻结的模型、数据、入口、硬约束组件路径和 SHA-256 载于 M_FREEZE.json。旧密钥只记录哈希承诺。
