# 结构化知识泄露与双重熵 V2：数学建模与理论审计

> 范围：本文只做建模和等价性审计，数值例子全部来自精确枚举（`exp_partial.py`、`exp_pairs.py`、`results/*.json`）。
> 原 DEGC 维持 STOP，不再调参；CA-PD 内核（`cogniguard/governance/reconstruction.py`）未改动，本文通过适配器调用它。

## 1. 对象与记号

### 1.1 世界、秘密与知识单元

- 有限潜在世界集 Ω，先验 π（**合成**，默认在 Ω 上均匀）；真实世界 x*。
- 受保护秘密 S = σ(x)。
- 知识单元 u：一个确定性观测 f_u : Ω → 𝒪_u。持有 u 的主体得知 f_u(x*)。
- 攻击者知识状态：单元集合 K。观测 V_K = (f_u(x*))_{u∈K}。
- 联盟 C 的视图为 V_{K_C}，其中 K_C = ∪_{i∈C} K_i（汇集即精化）。k = N 时 C 可以是全体主体。

### 1.2 攻击者侧不确定性：H(S | V)

攻击者在视图 v 下的后验为 π_v(s) = P(S = s | V = v)。记：

- Bayes vulnerability V₁(v) = max_s π_v(s)（一次猜中的概率），min-entropy H_∞(S | v) = −log₂ V₁(v)；
- Shannon 熵 H(S | v)；
- g-vulnerability V_g(v) = max_w Σ_s π_v(s) g(w, s)，用于部分正确，例如串行结构中"位置对了几个"。

### 1.3 治理侧不确定性：H(K | E)

- 治理方是资产所有方，**知道 x\***（CA-PD 的受保护目标本来就由所有方定义），但不知道 K。
- 证据 E 包括：自己放行过的消息、对消息的检测结果（可能漏检或误报）、核验结果。
- 治理方对 K 的后验记为 μ_E，治理熵为 H(K | E) = H(μ_E)。

两个熵是**不同随机变量**的熵：H(S | V) 是攻击者对 S 的不确定性，H(K | E) 是治理方对 K 的不确定性。本文**不**把二者定义为同一个风险量的函数。问题在于：把它们**同时**用作决策依据，是否带来可验证的增益。

### 1.4 关于先验的声明

精确参考结果中的候选空间与均匀先验都是**合成的**，只是一个可完整枚举的测试床。真实攻击者的先验未知。LLM 攻击实验（`attack_llm.py`）在提示里**明确告诉**攻击者候选空间和均匀先验，所以测到的是"能力上界"式的吻合度，不能当作真实攻击者先验的证据。

## 2. 完整见证判定在 QIF 中的位置

**命题 1（见证 = 与取值无关的确定）。**

单元集 W 是见证，当且仅当对所有 x ∈ Ω 都有 V₁(V_W(x)) = 1，即 S 是 V_W 的函数。

因此 CA-PD 的判定（存在规模 ≤ k、含接收方的联盟 C，使 K_C ∪ M 覆盖某个见证）等价于：∃C，∀x，V₁ = 1。

*证明*：见证族由 `engine.build` 按此定义枚举出极小集合。测试 `test_kernel_agrees_with_coverage_table` 在 9 种结构、各 150 个随机状态上，验证了未改动的 `check_release` 与覆盖表逐一一致。∎

**推论 1（两类遗漏）。** CA-PD 的"安全"判定不排除以下两种情况：

- (a) **取值相关的提前确定**：存在 x 使 V₁(V_K(x)) = 1，但 K 不含见证。例如 AND/max 结构中，攻击者得知 a = 3 时 S = max(a, b) = 3 已确定。在 9 种结构的非覆盖视图中，这类状态的先验加权比例为 0–25%（`results/partial.json`：`realized_determination_without_witness`）。
- (b) **部分泄露**：1/|S| < V₁ < 1。

**命题 2（何时完整见证判定不漏部分泄露）。**

以下三条等价：

1. 对所有增益函数 g 和所有非覆盖单元集 K，CA-PD 判为安全的状态都不存在加性 g-泄露；
2. 对所有非覆盖 K，S 与 V_K 独立；
3. 单元集在见证访问结构上构成**完美秘密共享**。

*证明*：

- (2⇒1)：后验等于先验，任何 g 下泄露都为 0。
- (1⇒2)：若某非覆盖 K 与 S 不独立，则存在事件 A ⊆ 𝒮 和视图 v，使 P(A | v) ≠ P(A)。取两猜测的增益：猜 w₁ 得 1[s∈A] − P(A) + c，猜 w₀ 得 c，常数 c 使增益非负。先验 g-vulnerability 为 c。后验期望为 c + E_v[max(P(A|v) − P(A), 0)]，由于 E_v P(A|v) = P(A) 且 P(A|v) 不恒等于 P(A)，该期望严格大于 c。
- (2⇔3)：这就是完美秘密共享的定义。∎

**实测**：9 种结构中，只有 AND/xor 在单输入视图上满足完美共享。但即使是 xor，{b, a 的高位} 也会泄露 S 的一位（V₁ 从 0.25 升到 0.5）。其余结构中，非覆盖视图里 20–100% 存在正泄露（`frac_views_any_leak`）。

**命题 3（联盟与 k = N）。**

- 汇集是精化。由 g-vulnerability 在精化下的单调性（数据处理），联盟越大，**期望** V_g 越大，因此全体联盟（k = N）的期望风险最大。测试 `test_expected_vulnerability_monotone_under_refinement` 在 9 种结构上精确验证了期望 V₁ 的单调性。
- **实现值** V₁ 不单调：多知道一点，实现的后验可能更分散。
- 因此本文的危害定义对 |C| ≤ k 的所有联盟取最大值。k = N 时包含全体联盟，不依赖"只看 k ≤ 3"。

**命题 4（Shannon 与 min-entropy 不一致，Smith 2009 的结构化实例）。**

AND/sum 结构中，只知道输入 a 时：

- min-entropy 泄露为 0（V₁ 保持 0.25）；
- Shannon 泄露为 0.66 bit（2.66 → 2.00）。

在 fact 结构中，{≥4, mod4≥2} 与 {odd, ≥6} 两个视图的 E[V₁] 都是 0.5，但 E[H] 分别为 1.00 和 1.19 bit。所以"部分泄露风险"需要先指定增益或目标，熵本身不是一个无歧义的风险量（`results/pairs.json` A 部分）。

## 3. 治理熵 H(K | E) 的等价性审计

### 3.1 hyper 表示

给定证据 E 和待放行内容 M，把 μ_E 推到攻击者后验上，得到

  Δ_{E,M} = Law(π_{V_{K∪M}(x*)})，K ~ μ_E。

这是攻击者后验上的分布，即 QIF 中的 hyper-distribution（McIver 等 2014；Alvim 等 2020）。多主体时，K 换成联盟视图的最大值。

**命题 5（充分统计量）。**

对任何只依赖动作 a 与攻击者后验 π 的损失 ℓ(a, π)（包括 V₁ ≥ τ、V_g ≥ τ、H ≤ h 等任意阈值目标），贝叶斯最优动作 argmin_a E_{μ_E} ℓ(a, π_{K∪M}) 只通过 Δ_{E,M} 依赖 E：

- 对阈值目标，只依赖 P_E(V₁ ≥ τ)，即机会约束；
- 对线性目标，只依赖 E_E[V₁]，即 hyper 的期望 vulnerability。

H(K | E) 是 μ_E 的泛函，不是 Δ 的泛函：μ ↦ Δ 是多对一映射，例如对无关单元的不确定性不改变 Δ。

**精确反例**（relation 结构，待放行"s1 的导师"，τ = 0.5，δ = 0.1，`results/pairs.json` B 部分）：

| 状态 | E[V₁] | P(V₁ ≥ τ) | H(K\|E) | 相关单元上的 H | 贝叶斯决策 |
|---|---|---|---|---|---|
| G1：确知 K = {s0} | 0.500 | 1.00 | 0.00 | 0.00 | 拦截 |
| G2：s0 的 p = 0.95，两个无关单元 p = 0.5 | 0.483 | 0.95 | 2.29 | 0.29 | 拦截 |
| G3：s0 的 p = 0.5 | 0.333 | 0.50 | 1.00 | 1.00 | 拦截 |
| G4：只有一个无关单元，p = 0.5 | 0.167 | 0.00 | 1.00 | 0.00 | 放行 |

- G1 与 G2：H(K|E) 从 0 变到 2.29，贝叶斯决策不变。
- G3 与 G4：H(K|E) 相同，决策相反。

所以 **H(K | E) 既不是决策的必要条件，也不是充分条件**。在 7³ = 343 个网格状态上，同一 H(K|E) 水平下两种决策并存的比例是 20%。

**推论 2。** 在声明的损失下，任何在贝叶斯规则之外再加 H(K|E) 门槛的规则，要么与贝叶斯决策一致，要么贝叶斯风险更高。DE2-strict（治理熵高就拒绝）属于后者，代价是误拒，见 `RESULT_V2.md`。

### 3.2 核验选择

最优的有预算核验是 POMDP 或自适应随机优化问题。

- **短视 VoI 会失效**：G5（s2、s3 都只有 p = 0.3）中，单次核验的 VoI 为 0，两次核验的 VoI 为 0.054。网格中有 252/343 个状态"VoI₁ = 0 而 VoI₂ > 0"。原因是 AND 结构需要两个单元同时成立才翻转决策。
- **按 H(K|E) 选核验**就是 GBS / 信息增益式贪心。Golovin 等 2010 证明它在有噪时可能很差，EC2 和 DRD 面向决策区域，有近似保证。
- 网格上 H(K|E) 与 VoI₁ 的秩相关为 **−0.35**，相关单元熵与 VoI₁ 的秩相关为 −0.44。治理熵高的地方，核验价值反而偏低。

因此，治理熵若有作用，只能作为核验启发式；要计为贡献，必须在相同预算下胜过非短视 VoI（本文实现了两步前瞻的 VOI2）或 EC2。

### 3.3 计算捷径

"治理熵低就直接用 MAP 状态判定"可以给出误差界。对任意分布，

  1 − max μ ≤ −log₂ max μ ≤ H(μ)（单位：bit），

所以插值判定与贝叶斯判定不一致的概率 ≤ 1 − max μ ≤ H(K|E)。但 1 − max μ 本身更紧，对乘积 Bernoulli 也更便宜（max μ = ∏ max(p, 1−p)）。所以这一计算优势用经典量即可获得，不依赖熵。

## 4. 拒绝本身的泄露（可模拟性）

**命题 6。** 若门控用**真实取值**判定（REAL：放行后实现的 V₁ ≥ τ 就拒绝），拒绝事件依赖攻击者尚未得到的取值，于是成为新的信道。攻击者看到拒绝后，可能直接越过 τ（Kenthapadi 等 2005 的 "denials leak"）。

- 若门控只依赖攻击者已知的信息与取值无关的量，则拒绝不泄露。例如 SIM：在攻击者当前视图对应的世界格内取期望。
- CA-PD 的见证判定与取值无关，因此天然可模拟。

**精确结果**（单主体、K 已知，`results/pairs.json` C 部分）：

| 结构 | REAL：拒绝中直接造成泄露的比例 | SIM 的误拒 | CA-PD：部分泄露目标下的危险放行 |
|---|---|---|---|
| fact | 4.1% | 0.21 | 0.73 |
| relation | 2.1% | 0.27 | 0.57 |
| and_max | 13.5% | 0.26 | 0.41 |
| mixed | 4.4% | 0.09 | 0.72 |
| serial、parallel、and_xor、and_sum、or_alt | 0 | 0 | 0.14–0.50 |

因此，基于真实取值的 QIF 门控**不能**直接部署。可部署的部分泄露门控必须可模拟，代价是更多误拒。方法对比实验因此同时报告 REAL 型（MINENT、BAYES）和 SIM 型（MINENT_SIM、BAYES_SIM）。

## 5. 审计结论（实验前）

| 候选成分 | 归约到 | 是否可能有独立贡献 |
|---|---|---|
| 攻击者侧 H(S\|V) 作为部分泄露风险 | min-entropy / g-leakage（Smith 2009；Alvim 等 2012）；阈值门控即 Mardziel 等 2011 | 否（理论已有）。CA-PD 漏掉部分泄露这一**实证**可以写 |
| 治理侧 H(K\|E) 作为决策量 | hyper 上的贝叶斯或机会约束决策（命题 5） | 否：既非必要也非充分 |
| H(K\|E) 作为核验启发式 | GBS / 信息增益贪心；应与 VoI、EC2 比较 | 只有在相同预算下胜过 VOI2 时才算 |
| H(K\|E) 作为计算捷径 | 1 − max μ 给出更紧的界 | 否 |
| 可模拟的部分泄露门控 | simulatable auditing（Kenthapadi 等 2005） | 理论已有；对 LLM 智能体治理的**适用性提醒**有价值 |
