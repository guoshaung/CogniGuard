# OULAD 字段表（Gate 0 冻结）

统计对象是 `data/oulad_raw/` 里的 7 个原始 CSV，不是后面选定的 3 门课。缺失率 = 缺失个数 / 行数。空字符串与空值都算缺失。用途只有四类：

- **敏感标签**：只能做推断目标，禁止参与生成请求，禁止进入攻击特征。
- **生成请求**：可以用来生成 Agent 请求。具体谓词见 `REQUEST_RULES.md`。
- **连接或分组**：只用来对齐课程、学生、评测和站点，不进入请求内容，也不进入攻击特征。
- **禁止使用**：不参与生成请求，也不进入攻击特征。

文件的 SHA-256 在 `DATA_FREEZE.json`。
