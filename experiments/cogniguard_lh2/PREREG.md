# P0 预注册：不完整治理信道下的潜在组合泄露 H₂

冻结时间：2026-11-26（本文件在生成任何开发集数据之前提交，提交后不修改；如有偏离，只记入 DEVIATIONS.md）。
代码：`model.py`（威胁模型与精确计算）、`p0_exp.py`（数据生成与评估）、`checks.py`（等价性数值检查）。

## 1. 冻结的威胁模型

| 项目 | 冻结取值 |
|---|---|
| 知识结构 | KSL 资产中的 and_xor（XOR）、and_max（AND/MAX）、or_alt（OR）、relation（关系）、mixed（混合）；均匀先验；单元为对世界的确定性观测 |
| 越界定义 | 形式定义 v0.1 的默认阈值：A 的单调闭包后验可猜性 max_{B⊆A} V₁(S \| B 在 w\*) > 1/2；按引理 1 等价于 A 包含 w\* 处的值相关推导集（audit56 修正后的形式定义，不使用值无关见证） |
| 主体与联盟 | 3 个主体：攻击端 A，中继 B、C；越界只判 A 的知识（B、C 通过传播与 A 形成联盟） |
| 初始知识 | 治理系统已向 A/B/C 做过 4 次受控请求（接收方均匀随机，单元从非外部单元中均匀随机），每次由未修改的 CA-PD 内核按接收方单独检查（k = 1），只看自己的披露日志 |
| 外部知识集合 E | 每个单元独立以 0.35 概率可从外部获得（工具/网页检索）；E 中单元不经过受控信道 |
| 通信拓扑 | star：B→A、C→A；line：C→B→A |
| 非完整受控传播预算 | 外部获取总预算 B_TOT = 3 个成本单位（含隐藏预热期）；单元成本 unit：全为 1；varied：每单元独立取 1 或 2 |
| 传播概率 | det：p_ext = 1、p_rel = 1；rand：p_ext = 0.5、p_rel = 0.5；每步先外部获取，再沿各边各转发一个发送方有而接收方没有的单元（均匀随机） |
| 攻击者策略 | 隐藏类型，各 1/2：greedy（选使期望下一步后验 V₁ 最大的可负担外部单元）、random（均匀随机）；预热期 T0 = 1 步（治理系统不可见） |
| 治理系统可观测信息 | w\*（数据所有者知道真值）、自己的全部受控披露、冻结的模型参数（E、成本、拓扑、概率、攻击者类型的混合）；不可见：攻击者类型、预热期外部获取、未来随机实现 |
| 预测时刻与窗口 | 最后一次受控请求之后；h = 3 步 |
| 治理动作自身泄露 | 本轮排除（P0 只做预测，不比较治理动作）；拒答泄露已在 KSL-V2 研究过 |

所有预测方法面对同一实例、同一外部信道和传播条件；生成器在开发集之前冻结，不因任何方法的失败案例调整。

## 2. 预测目标（主要）

y = 1 当且仅当：在真实实现中 A 在 [0, h] 内越界（包括决策时刻已经由受控披露与隐藏外部知识组合造成的越界），并且在相同隐藏状态和攻击者类型下，只有外部信道（撤回全部受控披露）时越界概率精确为 0。

三类事件分别计数：外部信道单独可造成越界（ext_capable = 1）；受控披露与外部知识组合造成的越界（y = 1）；无越界。

## 3. 比较的指标（全部只用第 1 节的可观测信息）

| 名称 | 定义 |
|---|---|
| V1_obs / H1_obs | A 的受控视图下当前猜测概率（单调闭包）与当前秘密 Shannon 熵 H(S\|k) |
| d_capd | CA-PD 最小剩余见证距离（A 的受控视图，所有单元可获取） |
| d_acc | 只计可达单元（A、B、C 的受控披露 ∪ E）的最小剩余见证距离 |
| coalition | {A, B, C, 外部} 中合并后包含推导集的最小来源数 |
| n_wit_h / wsum | 基于结构的组合风险：距离 ≤ h 的可达推导集个数；Σ 2^-距离 |
| belief_V1 / belief_cross_now | 基于信念的动态 QIF（Mardziel 等式的当前风险）：对隐藏状态的信念平均当前 V₁ 与当前越界概率 |
| KB_min | Köpf–Basin 式自适应泄露（最小熵版）：攻击者最优自适应策略下 h 步后期望后验 V₁ 相对当前的 log 比，信念平均 |
| **H2**（主） | sup_π I(S; X_{1:h} \| K = k)，π 为攻击者对外部单元的自适应选择，自然步为 p_ext 与中继转发；信念平均 |
| H2_obs | 同上但只用受控视图（无隐藏持有、满预算） |
| JOINT | 上面除 H2、H2_obs 之外全部指标的 L2 逻辑回归（标准化，C = 1.0，lbfgs，max_iter 2000），在开发集上拟合 |
| JOINT+H2 | JOINT 特征加 H2，同样拟合 |
| R_star | 精确的模型风险 P(y = 1 \| 可观测信息, 冻结模型)：对信念精确求和、前向 DP（可部署，不使用未来实现） |
| Oracle | 真实未来实现（AUC = 1，只作上界） |

Köpf–Basin 的 Shannon 版自适应泄露与 H2 在定义上相同（见 MATH_P0.md 命题 1），只做一致性验证，不作为独立基线参与比较；因此 JOINT 不含它，这对 H2 是宽松的。

单一指标的方向（数值越大越危险或越小越危险）在开发集上按 AUC ≥ 0.5 决定。

## 4. 数据划分与种子

40 个单元格 = 5 结构 × 2 拓扑 × 2 传播 × 2 成本。开发集每格 100 个实例，种子 cell·10⁵ + i；测试集每格 300 个实例，种子 5·10⁷ + cell·10⁵ + i。开发集只用于拟合 JOINT / JOINT+H2 和决定方向；测试集只评估一次。

## 5. 判定门（P0 → P1）

主要指标：测试集 AUC。辅助：AUPRC、Brier、10 分箱 ECE（只对输出概率的 JOINT、JOINT+H2、R_star）。
置信区间：测试实例配对 bootstrap，2000 次，95% 分位数区间，种子 0。

只有同时满足以下全部条件才进入 P1：

1. 数学：H2 不是已有量（Köpf–Basin 自适应泄露、QIF 动态信念风险、剩余见证距离）在相同先验、信道、策略空间和度量下的重新命名。
2. ΔAUC = AUC(JOINT+H2) − AUC(JOINT) ≥ 0.05，且配对 95% CI 下界 > 0。
3. 在 5 个结构中至少 3 个结构上，按结构计算的 ΔAUC 的 CI 下界 > 0。
4. 不使用 Oracle、额外观测权限或更强的预测信息（H2 与 JOINT 用同一信念）。
5. 能说明对应的真实 Agent 传播机制。

任一条不满足即 STOP，不进入 P1。不根据测试结果修改 H₂ 定义、主要指标或门槛。
