# P0 报告：不完整治理信道下的潜在组合泄露 H₂ —— 结论 STOP

分支 `exp/cogniguard-latent-h2`（从 `exp/cogniguard-ksl-v2` @ 9f5242b 派生）。
预注册 `PREREG.md` 与数学分析 `MATH_P0.md` 在生成任何数据之前提交（commit 92a8fb9），之后未修改。
结果文件：`results/p0_analysis.json`、`results/checks.json`、`results/{dev,test}_rows.json.gz`。

## 一句话结论

不完整门控下的组合泄露风险是真实存在的：测试集 40.2% 的状态在 3 步内发生可避免越界，而这些状态里的受控披露都通过了 CA-PD（k = 1）检查。但 H₂ 有两个问题：

- 数学上，它就是已有的自适应 Shannon 泄露（Köpf–Basin）；
- 经验上，它对联合基线只增加 ΔAUC = +0.0014 [0.0009, 0.0019]，远低于预注册门槛 0.05。

所以 P0 不通过，整体 STOP，不进入 P1。

## 1. 数学等价性（MATH_P0.md，数值检查 checks.json）

| 检查 | 结果 | 含义 |
|---|---|---|
| C1 H₂ vs Köpf–Basin（独立穷举全部攻击树，确定性，h = 2，75 个状态） | 最大差 0.0 | 严格等价：同先验、同信道、同策略空间、同度量 |
| C2 无限制获取（E = 全体，h ≥ m） | H₂ = H₁，最大差 0.0 | 退化为当前剩余熵 |
| C3 确定性、单位成本：最坏情况越界 ⇔ d_acc ≤ h | 600/600 一致 | 越界由剩余见证距离决定，与 H₂ 无关 |
| C4 完整门控（所有信道按联盟池 k = N 检查） | 3000 步，0 次越界 | 没有额外可治理风险，H₂ 仍可 > 0（误报） |
| C5 精确 P(越界) vs 3000 次蒙特卡罗 | 最大差 0.022（约 2.4 SE，30 次检验中的最大值） | 实现正确 |
| C6b H₂ 与精确风险 R\* 排序（R\* 差 ≥ 0.2 的随机状态对） | 817/2112 = 38.7% 排序相反 | H₂ 与越界风险几乎不对齐 |

随机传播情形下，H₂ 属于已有的"概率系统中的自适应攻击者"模型类（Boreale & Pampaloni【待核对原文】；Mardziel 等 S&P 2014）。中继拓扑和外部预算只改变信道和策略空间，不产生新的度量。

**最小反例**（or_alt，C6a）：两个状态的以下指标全部相同：

- V1_obs = 0.125，H1_obs = 3.0；
- d_capd，d_acc = 2；
- coalition = 1，n_wit_h = 2；
- **H₂ = 1.625、KB_min = 1.625 也相同**。

但精确风险 R\* 一个是 1.0、一个是 0.0。区别有两点：

- 高风险状态里，推导集 {cipher, key} 分别在 B、C 两个中继手里，确定性转发一步汇合；而外部渠道由于成本与预算限制，单独无法越界。
- 低风险状态里，外部渠道单独就能越界，所以按定义这是"不可避免"的。

决定可避免风险的是"推导集在哪些信道上、各自的成本和传播概率"，这正是 H₂ 这个期望 Shannon 量看不到的。

## 2. 冻结威胁模型与数据

- 5 个结构（XOR / AND-MAX / OR / 关系 / 混合）× 2 拓扑 × 2 传播（det / rand）× 2 成本 = 40 格；
- 开发集 4000、测试集 12000，种子不相交；
- 治理系统看得到真值、自己的披露日志和冻结的模型参数，看不到攻击者类型、预热期外部获取和未来实现。

测试集三类事件：

| 类别 | 数量 |
|---|---|
| 外部信道单独可越界（ext_capable） | 2153（其中实际越界 1834） |
| **受控披露 + 外部 / 中继组合造成的可避免越界（y = 1）** | **4827**（其中决策时刻已越界 955） |
| 无越界 | 5339 |

基率 40.2%，不存在"风险过于罕见"的问题（失败模式 9 不成立）。

## 6. 适用边界与可以保留的阴性 / 阳性事实

1. **问题本身成立。** 不完整门控下，按接收方单独检查（k = 1）的 CA-PD 放行的披露，经中继转发和外部检索组合后，在 3 步内越界的比例很高。这验证的是问题，不是 H₂。按任务书，"问题验证成功"不等于算法创新。
2. **真正有预测价值的是"推导集超图 + 信道模型"。** R\* = 0.980 > JOINT 0.940 > d_acc 0.762 ≫ H₂ 0.660。在冻结模型已知的条件下，R\* 是 Bayes 最优预测器（命题 5），它本质上是 CA-PD 见证结构在带概率信道上的前向可达概率，不是熵量。
3. **H₂ 反而会误报。** 完整门控下风险为 0，而 H₂ > 0（命题 4）。信念平均版 H₂ 比只看受控视图的版本还差（0.660 vs 0.705）。
4. **限制。**
   - 结构是 KSL 合成资产，先验为均匀合成先验；
   - h = 3、主体数 3、外部获取概率 0.35 等都是一次性冻结的单一取值，没有做敏感性分析；
   - 治理系统被假定知道冻结的传播模型。模型错设时 R\* 的优势可能缩小，但这不改变 H₂ 不如 d_acc / JOINT 的结论，因为后两者不依赖模型参数。
5. 本轮没有 LLM 调用，也没有付费 API。

## 7. 最终决策

**STOP。** H₂ 不作为新的信息论度量，也不进入 P1 双量控制。按任务书，不在本轮提出第三重熵或其他替代候选。
