# P0 §4.1 数学等价性分析：H₂ 与已有量的关系

本文在任何开发集或测试集数据生成之前写成。数值验证见 `checks.py` → `results/checks.json`。
文献凭已有知识列出，写进论文前必须逐条找到原文核对，标【待核对】的尤其如此。

## 0. 记号与六种量的区分

- 世界 w ∈ Ω，先验 π；秘密 S = σ(w)；单元 u 是确定性观测 f_u(w)。
- 知识状态 k = (A, f_A(w\*))，A 是已持有的单元集合；k 确定攻击者的观测格 C_k = {w : f_A(w) = f_A(w\*)}。
- 未来 h 步：攻击者每步选择一个可获取的外部单元（受预算、成本约束），自然步为外部获取成功（p_ext）与中继转发（p_rel，拓扑）。策略 π 是从观测历史到动作的映射，Π_h 是全部这样的映射。X^π_{1:h} 是 h 步内得到的（单元，值）序列。

| 量 | 定义 | 依赖什么 |
|---|---|---|
| Shannon 熵 H₁(k) | H(S \| C_k) | 攻击者后验，平均意义 |
| 最小熵 H∞(k) | −log₂ V₁(S \| C_k)，V₁ = max_s π(s \| C_k) | 后验最大质量 |
| 期望泄露 | H(S \| k) − E_X H(S \| k, X)，或最小熵版 log₂ E_X V₁(·)/V₁(k) | 对攻击者后验下未来输出取平均 |
| 最坏输出泄露 | max_x 的输出级泄露 | 单个最坏输出 |
| 真实秘密后验 | π(s\* \| C_k) | 只在 w\* 处 |
| 阈值越界概率 | P(L\*(A_t) > τ，某个 t ≤ h) | w\* 处的实现、冻结的攻击者分布、阈值 |

**H₂^{(h)}(k) = sup_{π∈Π_h} I(S; X^π_{1:h} \| K = k)** 是一个"Shannon、期望（对攻击者后验平均）、最坏策略（sup）"的量。P0 的预测目标是"阈值、实现（w\* 处）、冻结的随机攻击者"。两者在三个维度上不同：度量（Shannon vs 阈值）、平均对象（攻击者后验 vs 真实世界）、攻击者（sup vs 冻结分布）。

## 1. 命题 1（H₂ 是已有的自适应泄露）

**(a) 确定性自然步。** 当 p_ext = 1、无中继转发时，策略就是深度 h 的自适应查询树，查询集为可获取单元（Köpf & Basin, CCS 2007，"An information-theoretic model for adaptive side-channel attacks"）。对树 T，I(S; X^T \| k) = H(S \| k) − E_leaf H(S \| k, leaf)，于是

  H₂^{(h)}(k) = H(S \| k) − min_T E_leaf H(S \| k, leaf)，

这就是以后验 π(· \| k) 为先验的 h 步最优自适应攻击的 Shannon 泄露。先验、信道（确定性单元观测）、策略空间（深度 h 的自适应树）、度量（Shannon）全部相同，**严格等价**。预算和成本只是缩小了每个节点上可用的查询集，不改变定义。数值检查 C1：独立用穷举全部攻击树计算 Köpf–Basin 值，与 H₂ 的 DP 比较。

**(b) 随机自然步（p_ext < 1、中继转发）。** 自适应策略与概率系统复合后诱导一个从 S 到转录 X 的信道，H₂ 是对策略取 sup 的该信道 Shannon 互信息，即概率系统下自适应攻击者的 Shannon 泄露。这一模型类已有研究：Boreale & Pampaloni 研究了一般泄露函数下概率系统中的自适应攻击者【待核对：LMCS 2015 / FORTE 2014】；Mardziel、Alvim、Hicks、Clarkson（IEEE S&P 2014，动态秘密）研究了带自适应攻击者策略、用增益函数刻画脆弱性的概率系统。中继拓扑和外部预算只是策略空间和自然步的具体取值，不是新的度量。

**(c) 与信道容量的关系。** 信道容量是对先验取 sup，H₂ 是在固定先验 π(·\|k) 下对策略取 sup，两者不同；但对任意确定性策略，I(S; X) ≤ log₂(转录个数)，所以 H₂ ≤ min(H₁(k), Σ_t log₂|值域_t|)。

**(d) 最小熵版本。** 将目标换成 log₂ E V₁ / V₁(k) 得到 Köpf–Basin 式最小熵自适应泄露（下文记 KB_min）。它与 H₂ 度量不同，不等价，作为独立基线。

**结论**：在相同先验、信道、策略空间和度量下，H₂ 就是已有的自适应 Shannon 泄露。门 1（"不是已有量的重新命名"）在数学上不满足。按任务书："如果严格等价性成立，且不存在有明确实际价值的 Agent 特定机制，则当前候选直接 STOP。"中继拓扑是真实的 Agent 传播机制（见 §6），但它改变的是信道与策略空间，不是度量；所以仍按预注册跑完 P0 的经验部分，看 H₂ 作为一个已知量在这个新场景下是否有独立预测价值。

## 2. 命题 2（无限制获取时退化为当前剩余熵）

若所有单元可获取、p = 1、预算与 h 足够大（h ≥ \|U\|）、且全体单元联合确定 S（KSL 中对 Ω 的每个世界都成立），则最优策略可以取得全部单元，H(S \| k, X) = 0，所以 **H₂ = H₁(k)**。更一般地 H₂ 关于 h 单调不减、上界为 H₁(k)。此时 H₂ 不含当前熵以外的信息。检查 C2。

## 3. 命题 3（确定性、单位成本、独立获取：越界 ⇔ 剩余见证距离 ≤ h）

设无中继、p_ext = 1、单位成本、可获取集合为 E。对固定 w\*，最坏情况（存在某个策略）在 h 步内越界 ⇔ ∃ 推导集 D ∈ 𝒲_τ(w\*)，D ⊆ A ∪ E 且 \|D \ A\| ≤ h。

证明：⇐ 依次获取 D \ A，由引理 1 越界。⇒ 若某策略 h 步后 A' ⊇ A 越界，则由引理 1，A' 包含某个推导集 D，D ⊆ A' ⊆ A ∪ E，且 \|D \ A\| ≤ \|A' \ A\| ≤ h。∎

所以在这一类条件下，最坏情况越界完全由"可达单元上的剩余见证距离 d_acc"决定，H₂ 不提供额外判别；H₂ 与越界风险的排序也不一致（反例统计见检查 C6b）。检查 C3。注意 d_acc 必须用值相关推导集（audit56 结论），用值无关见证会重新引入 56 例错误。

## 4. 命题 4（完整门控下没有额外可治理风险）

若每一条使 A 获得单元的信道（受控、外部、中继）都经过以联盟池（k = N）为对象的 CA-PD 检查，且形式定义的假设 A1–A4 成立，则每一步之后联盟知识都不包含推导集，由引理 1，越界概率对任何策略为 0。此时 H₂ 仍可以 > 0（阈值以下的信息增益），即 H₂ 在完整门控下会报出不存在的风险。检查 C4。

## 5. 命题 5（不完整门控下的上界：H₂ 不能超过模型风险）

记 O 为决策时刻的可观测信息（第 1 节威胁模型）。对任意以 O 为输入的预测器 f(O)，按 P(y = 1 \| O) 排序在总体上逐点支配 ROC（Neyman–Pearson：在给定 O 的条件下按似然比排序与按后验排序相同），所以 **R\*(O) = P(y = 1 \| O, 冻结模型) 的总体 AUC 不低于任何 f(O)，包括 H₂ 和任何联合模型**。R\* 只用冻结的模型参数与对隐藏状态的精确信念，可以部署，不是 Oracle。

由引理 1，越界事件只取决于 A 的单元集合是否包含 w\* 处的推导集，因此 R\* 由"推导集超图 + 传播模型 + 信念"完全确定；任何对决策有用、而现有简单结构指标区分不了的状态差异，R\* 都能区分。所以：

- 现有结构指标（d_acc、合谋规模、当前风险）相同但未来风险不同的状态一定存在（检查 C6a），但这只是正确性检查：它们被 R\* 区分，不需要 H₂。
- H₂ 能留下的经验空间只是"相对 JOINT（简单指标的组合）的增量"，而且上界是 R\* 与 JOINT 之间的差距。

## 6. 真实 Agent 系统中的对应机制

- 外部信道 E：工具调用、网页检索、公开数据库，治理系统无法实时阻断或完整观测；
- 中继转发：多 Agent 共享记忆、消息转发、任务交接摘要；接收方单独看安全的受控披露，经转发在攻击端汇合。

这两种机制下的风险是真实的，但它是**风险本身**（d_acc、合谋规模、R\*）的问题，不是 H₂ 这个度量的问题。

## 7. P0 门 1 的判定

| 检查 | 结论 |
|---|---|
| 与 Köpf–Basin 自适应泄露 | 确定性情形严格等价（C1 数值验证）；随机情形属于已有的概率系统自适应攻击者模型 |
| 与信道容量 | 不等价（sup 对象不同），容量给出上界 |
| 与 Mardziel 信念式执行 | 后者控制当前（或下一步）后验脆弱性；H₂ 是同一框架下的多步 Shannon 版本 |
| 与 CA-PD 剩余见证距离 | 确定性条件下越界 ⇔ d_acc ≤ h，H₂ 不相关（命题 3） |
| 与最小合谋规模 | 合谋规模决定是否可能越界，H₂ 不决定 |
| 与完整联合后验动态风险 | R\* 在总体 AUC 上支配 H₂（命题 5） |

**门 1：不满足。** 其余门按预注册的经验评估报告。
