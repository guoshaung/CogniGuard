# 组会可引用摘要：CogniGuard-NoWM 综合实验 Phase 1

**实验**：统一请求流覆盖：

- 学生画像推断；
- 教师保密知识组合恢复；
- 跨主体共享；
- 多轮累积；
- 未记录传播；
- 授权撤销与派生访问。

传播文本、知识保留和 BGE + NLI 证据是真实的（Codex `065bb82`、`fcf1374`）；主体、授权、见证和请求流是合成的治理结构。

规模：

- 见证大小 2–5，联盟规模 k = 1–3，两种传播强度；
- 30 组配对种子，8,100 次运行；
- 冻结预注册在正式运行之前推送。

**一句话结论**：在 k ≥ 2 的有界联盟场景中，只有"BGE + NLI 动态知识状态 + CA-PD"同时做到低危险放行（0.003–0.041）和几乎不损失效用（≥ 0.995）。两个部件缺一，危险放行都会显著上升：

- 只有 CA-PD：0.15–0.42；
- 只有动态状态：0.65–0.81。

**要点**：

1. **CA-PD 独立贡献成立**（k ≥ 2，4/4）：同样的证据下，把单主体判定换成有界联盟判定，危险放行率下降 0.61–0.81，效用不变。
2. **动态知识状态独立贡献成立**（5/6）：同样的 CA-PD 规则下，加入 NLI 证据，危险放行率下降 0.15–0.56。唯一的例外是 high/k1：效用下降 0.7 个百分点，区间下界 −1.03%，越过了预注册的 −1% 界，按规则判为不支持。
3. **联合收益成立**（k ≥ 2，4/4）：两部分都必要。
4. **相对同证据基线**：
   - 固定配额（WS04）在 k ≥ 2 时效用只有 0.59–0.75，危险放行率还更高。
   - 全局并集和累计预算的危险放行更低，代价是效用降到 0.16–0.88。这属于不同的取舍点，不是 M3 占优。
   - 成对控制在 w ≥ 3 时按构造失明（0.80–0.88）。
5. **等安全比较**：危险放行率 ≤ 0.05 时，k ≥ 2 的四个单元格中效用最高的都是 M3（0.995–1.000）。如果只有回执，同样安全的最好办法是全局并集，效用只有 0.54–0.88。
6. **安全底线**：未授权成功为 0；CA-PD 的判定与暴力枚举 4,000 / 4,000 一致；判定耗时 P95 ≤ 25 μs。

**不能说的**：

- 不含水印，不代表包含 RKW 的系统；
- 成对控制是结构代理，**不是 OCELOT**；
- 真实数据只有 15 条链、12 份来源，区间只反映合成治理结构的变化；
- 画像泄露是合成的，而且没有证据可以覆盖，所以 Oracle 与 M3 之间还剩 0.003–0.118 的危险放行率。
