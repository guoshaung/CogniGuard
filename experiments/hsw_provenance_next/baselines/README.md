# 七类来源遗失对照

复用已有 OpenStax 12 来源、24 次发行及七种内容检索基线。程序逐一核对索引输入和 BGE、TinyBERT 权重 SHA-256，并沿用原校准阈值。七个新端点用此前固定的模型与阈值重新打分。内容方法使用各载体共同的纯正文，因此不会把签名格式或标记文字当成教学内容。

逐案例保留历史发行集合、实际保留事实、来源兼容集合、当前有传播证据支持的发行，以及方法预测。纯标记读出登记中的发行 ID。内容门槛要求同一行的内容与标记指向的来源兼容。可见签名由发行 ID、事实 ID 和精确事实正文计算合成样本的 HMAC，测试目标是内容绑定。代码中使用公开样本密钥，实验只比较受控修改和复制条件。

- 纯标记的发行预测为 4 TP、4 FP、1 FN。保留历史而删除全部事实、向无关文本复制标记、交换来源和标记、以及完整复制签名事实各产生一次错误标签。
- 标记加内容门槛和可见绑定签名均为 4 TP、1 FP、1 FN。两者均挡住改写正文后的全删除、无关复制和交叉绑定。剩余误归因发生在凭证与原始完整事实一起复制的情况。
- 两个额外对照分别输入独立表达的等价事实与字面相同但不带凭证的事实。所有方法均没有在这两条中指定发行 ID。
- 内容检索可以正确识别独立等价事实的兼容来源。七种内容方法没有在任一主案例中恢复唯一发行。BGE 在主案例中找到全部六个兼容来源标签，同时返回两个多余标签。

`orphan_cases.json`、`orphan_predictions.json` 和 `orphan_summary.json` 保存输入、逐行核验与混淆计数。七个主案例以先验构造，属于定向检查，不外推比例。数据中的两个完整复制案例具有同一可观测凭证及正文，其真实传播历史不同。凭证只提供绑定事实的发行证据，当前路径的继承性需要额外证据。

使用与原检索试验相同的本地 Python 环境，运行 `orphan.py --bge <BGE 目录> --rerank <TinyBERT 快照目录>`。模型配置、源码和试验输入均可在同一工作树中复核。
