# OCELOT 阶段 1b 复现审计

对照 arXiv:2606.12341v1（Jin Xie, Songze Li）和上一轮 `experiments/ocelot_edu_20261121/`。上一轮目录本轮不改。上一轮 G1、G2 按构造成立，不用于判定。

任何一臂都不称为官方 OCELOT。

## 1. 预算

原文：同一条轨迹上的代价和不超过 B* = 4 比特。保证只在单条轨迹内成立。

状态：可精确复现轨迹上界。学生通道按任务书记为 ADVERSARIAL，μ = 4，计入该学生自己的预算。这是教育场景的共同改造。

## 2. 秘密和代价

原文：秘密带先验，泄露是最小熵优势。完整代价表没有发表。

状态：替代实现，而且和上一轮不同。上一轮的先验和代价是写死的。本轮不设先验。秘密是资产包里三个声明目标。代价由两个本地代理的猜中率估计，空视图作实测基线，Jeffreys 平滑只是计数约定。三阶及以上的预测只使用成对及以下的命中，这对应附录 C.1 只联合校准预注册的对。

资产包写明这些是合成策略保护资产，不是已核验的教师版权，也不是人工金标。命中率不是侵权率。

## 3. 验证器

五种算子和“超预算就换更严算子”按原文方向实现。谓词用 Python 检查，不用 Z3，也不跑 credal 电路。哈希链是 SHA-256 加 Ed25519。

静态规则没有发表。本轮把三个声明层次上的单元当作显式触发并 REDACT，锚点和公开单元保持 NONE。这是 OCELOT⁻ 的替代。
