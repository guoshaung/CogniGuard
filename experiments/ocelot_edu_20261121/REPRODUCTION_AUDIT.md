# OCELOT 复现审计

对照任务书第 0 节和 arXiv:2606.12341v1（Jin Xie, Songze Li，2026-06-10，18 页 PDF）。PDF 于 2026-11-21 核对。摘要页和正文都没有代码链接，也没有作者邮箱。本轮没有发信索要代码或权重。仓库里没有 OCELOT-Traj-500，也没有文中预注册的三份协议。

下面每一条都标成三种之一：可精确复现、替代实现、无法复现。OCELOT-Edu 是教育场景的共同改造，不是对原文的指控。任何一臂都不得称为官方 OCELOT。

## 1. 每条轨迹的预算

原文：同一条轨迹上 Σ cost_i ≤ B，B* = 4 比特（式 1；§3.4、§4.4）。保证只在单条轨迹内成立。

状态：可精确复现。

实现：每名学生一条账本，运行和不超过 4 比特。学生通道按 ADVERSARIAL 记，μ = 4，代价是 μ 乘以基础代价。这是任务书规定的共同改造，用来替换原文“用户通道审计但不计入预算”。

## 2. 秘密的类型和最小熵优势

原文：秘密是用户自己的 8 类字段（法定姓名、出生日期、支付令牌、诊断等），带先验 P(S)，泄露定义为最小熵优势（§3.2、式 4、附录 D.1）。

状态：替代实现。

仓库里的 C²-RAG 材料没有 5 个资产包、45 个单元。现有教师资源是短句。本实验按 C²-RAG 的资源标识新建 45 个单元：5 个包，每包 1 个结构字段、2 个诊断对、2 个长度为 3 的顺序单元、2 个长度为 4 的顺序单元、2 个教学方法片段。句子是为本实验写的，标记形如 `quad_vertex-field-F1`。来源标识沿用 `teacher_math_001`、`res_0001` 等已有编号，不复制教材。

优势按有限均匀先验计算：log2(先验大小) − log2(后验大小)。这就是均匀先验下的最小熵优势。诊断对：先验 8，单侧后验 2，双侧后验 1，所以单侧 2 比特、双侧 3 比特。顺序单元：任意真子集的后验仍是 4，优势 0；凑齐后后验为 1，优势 2 比特。结构字段先验 16，单条释放优势 4 比特。教学方法片段不进入 G1 的跨轨迹定义，它的 IDENTITY 基础代价按非字段文本记 0。

原文只给出说明性数字，例如 C(IDENTITY, LEGAL-NAME) = 1.2。完整的 C(算子, 字段) 表没有发表。上表在看到任何阶段 1 结果之前写死，不使用那组人身字段的说明性数字。校准余量 ε 取附录里报告的均值 0.18 比特。

## 3. 用户通道不计入预算

原文：用户通道经过审计，但不计入预算（§3.2）。用户是秘密的主人。

状态：替代实现，而且是本实验要保留的改造。

学生不是教师资产的主人，学生通道记为 ADVERSARIAL 汇聚点，μ = 4，计入该学生自己的轨迹预算。同一份资产会进入多名学生的轨迹。这一点不拿来指责原文，只作为教育场景的设定。

## 4. 代价可加和成对联合校准

原文：在跨原子条件独立下 L̂ ≤ Σ C(o_i, f_i)（引理 1）。只对预注册的少数强依赖原子对做联合校准（附录 C.1）。高阶依赖不在保证之内。

状态：替代实现。

验证器用 Python 直接检查谓词，不用 Z3，也不跑文中的 credal sum-product 电路。成对审计返回的基础代价等于已经收取的基础代价之和，因此它看不见未登记的三阶和四阶依赖。诊断对按联合代价替换第二条的增量：第一条 IDENTITY 基础代价 2，第二条增量 1，联合基础代价 3。顺序层的每一个二元子集优势为 0，所以成对联合校准仍然收 0；凑齐后的 2 比特不收费。这就是 G2 要测量的低估机制。

## 5. 合谋

原文：合谋是同一条轨迹里的多个汇聚点共用一个 B。汇聚点从 1 增到 8 时，top-1 恢复率从 1.2% 升到 11.9%（§5.5、图 7）。没有多个用户、多条轨迹的合谋。

状态：无法复现该曲线，也不打算复现。

本实验的 G1 测量的是另一件事：每条学生轨迹各自不超预算，k 名学生把收到的输出放在一起。k 取 1、2、3、5。这是教育场景的改造，不是图 7 的复现。

## 6. 自由文本可以标 NONE

原文：未标记为字段的自由文本可以标 NONE，代价为 0。只有结构字段原子缺标时才走保守默认（§4.2）。

状态：部分替代，检测器无法复现。

NONE 的代价是 0，五种算子里的 REDACT 和 DROP 也是 0。验证器不读取金标准。模型把一个跨度标成 NONE，就按 NONE 放行。原文那个“结构字段缺标则保守处理”的检测器没有发表；本实现不用金标准去补这个检测器。提示词臂如果给出注册表以外的字段名，解析失败后回退到静态规则，而不是静默放行一个非法字段名。

静态规则版把字段、诊断、顺序单元的标记视为显式触发并 REDACT，把教学方法片段和公共脚手架标成 NONE。这符合原文对 OCELOT⁻ 的文字描述：显式触发被过度隐去，非触发文本被放过。规则表本身没有发表，所以这是替代实现，不是他们的规则表。

## 7. 压力池覆盖率

原文：压力池代价覆盖率 92.1%（校准集 96.6%），违规集中在 IDENTITY–支付令牌和 GENERALIZE–诊断（表 4、图 6）。

状态：无法复现。

没有压力池，没有校准集，也没有官方代价表。本实验不报告覆盖率数字。

## 8. Defender

原文：Qwen-3.5-9B，SFT 82,400 条加 GRPO，4–8 块 H100。另有静态规则版 OCELOT⁻，在 Traj-500 上 L = 1.07，U = 81.9（§5.1、表 2）。

状态：训练版无法复现。静态版按文字描述做替代实现。

本机只调 API，不训练。提示词臂按图 8 的文字，用未微调的开源模型做两轮标注，并标明“非官方训练版”。模型解析顺序是 `qwen3.5-9b`、`qwen3.5-9b-instruct`、`qwen3.5-flash`。前两个在 2026-11-21 的 DashScope 模型列表里没有出现；若接口返回 404，就使用 `qwen3.5-flash`，并在结果里写明它不是 9B 的 SFT+GRPO 权重。图 8 里“不确定就选更严的算子”保持原样。模型若把一切都 REDACT，就照实记录，不在看到结果后把提示词改松。

`cost_model_identity` 不是 Defender。它把金标准字段和 IDENTITY 提案送进同一个验证器，用来单独检查代价模型。它不叫官方 OCELOT，也不叫 OCELOT⁻。

## 11. 算子、验证器和账本

五种算子及升级顺序 IDENTITY → GENERALIZE → SUBSTITUTE → REDACT → DROP：可精确复现名称和“超出预算就换更严算子”的方向。GENERALIZE、SUBSTITUTE、REDACT、DROP 的输出是固定替换句或空串，标记不会留下。

验证器四个阶段的外部行为（标注不被直接采信、代价由验证器重算、超预算就升级、通过后才入账）：替代实现。没有 Z3。

账本：SHA-256 把上一条哈希和本条正文接在一起，Ed25519 对摘要签名。可精确复现这个结构。每条轨迹一把新的复现密钥，私钥不落盘。每条释放记录保存公钥、签名和条目。事后核验只用公钥。这把密钥不是用户凭证。

## 12. 教学效用

沿用一条可机械判断的效用：正常学生那一轮的释放文本是否仍包含预先写好的公共脚手架句。过度拒绝率是 1 减去这个比例。这不是 C²-RAG 人工效用评分的复现。C²-RAG 的人工评分过程无法在本轮按原文规模重做，故标为替代实现。
