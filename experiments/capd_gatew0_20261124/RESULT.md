# Gate W0 结果（冻结提交 2e963d8，预注册 `PREREG_GATEW0.md`）

## 1. 判定

| 判定 | 结果 |
|---|---|
| **W0-0（分解核对）** | **Wstar 与 Cstar 在每一次运行中都完全相同。** 理想水印额外携带的发行 ID，没有改变过任何一次联盟决策 |
| **W0-1（暂定）** | 暂定"有额外价值"，但**只出现在 fragment 变换中**（合成数据 K = 16、32；危险放行的差值下界分别为 0.33 和 0.43）。identity 和 paraphrase 变换下没有价值 |
| W0-1（最终） | **无法判定**：F4_bge 和 F5_bge_rerank 为 NOT_RUN |
| W0-2 | 在 fragment 变换下，Wstar 优于主动文本变体（A1）；在 identity 和 paraphrase 变换下，两者相同 |

## 2. 解读（必须如实说明）

1. **暂定的"额外价值"不是来自发行身份**：理想内容通道 Cstar 得到的结果与 Wstar 完全一样。它来自理想通道的一个假设："只剩 5 个词的片段，也能完整恢复来源"。
2. **这个假设对真实水印并不现实**：基于词元的统计水印需要足够长的文本，才能检出或承载载荷，5 个词的片段基本上无法承载。所以，在 fragment 变换下，真实水印的额外价值预计远低于 Wstar 这个上界。下一步需要用真实检测器去测片段长度和检出率之间的曲线，才能下结论。
3. **发行身份只在归因层面有作用**：S2（同一内容重复发行）中，只有 Wstar（1.00）和主动变体 A1_bm25（0.66）能消除来源歧义，内容指纹都是 0。但在控制层面，两者的单元级恢复完全相同，所以**不改变任何安全决策**。这与理论第 5 节的预测一致。
4. **在 paraphrase 变换下，BM25 已经足够**：危险放行为 1 次，与理想通道几乎相同。MinHash 和 SHA256 失效。

## 3. 偏离

- **S4 的归因结果被重复计算了 3 次**：代码对每种变换都运行了一次 S4，但 S4 固定使用 fragment 变换，所以 attribution.csv 中有 3 组 S4 行，它们用的查询种子不同。三组都保留，结论一致。这一点记入 `DEVIATIONS.md`。

## 4. 后续

- 由本机的 Claude 下载 BGE 和重排序模型，补跑 F4 和 F5，然后重新计算 W0-1 的最终判定；
- 如果补跑后仍是"暂定有额外价值"，并且只出现在片段场景中，就要先用真实水印检测器测量**片段长度—检出率**曲线，再决定是否投入 GPU。
