# Gate W0 结果（冻结提交 2e963d8，预注册 `PREREG_GATEW0.md`）

## 1. 判定

| 判定 | 结果 |
|---|---|
| **W0-0（分解核对）** | **Wstar 与 Cstar 在每一次运行中都完全相同。** 理想水印额外携带的发行 ID，没有改变过任何一次联盟决策 |
| **W0-1（暂定）** | 暂定"有额外价值"，但**只出现在 fragment 变换中**（合成数据 K = 16、32；危险放行的差值下界分别为 0.33 和 0.43）。identity 和 paraphrase 变换下没有价值 |
| W0-1（最终） | **无法判定**：F4_bge 和 F5_bge_rerank 为 NOT_RUN |
| W0-2 | 在 fragment 变换下，Wstar 优于主动文本变体（A1）；在 identity 和 paraphrase 变换下，两者相同 |

## 2. 解读（必须如实说明）

1. **暂定的"额外价值"不是来自发行身份**：理想内容通道 Cstar 得到的结果与 Wstar 完全一样。它来自理想通道的一个假设："只剩 5 个词的片段，也能完整恢复来源"。
2. **这个假设对真实水印并不现实**：基于词元的统计水印需要足够长的文本，才能检出或承载载荷，5 个词的片段基本上无法承载。所以，在 fragment 变换下，真实水印的额外价值预计远低于 Wstar 这个上界。下一步需要用真实检测器去测片段长度和检出率之间的曲线，才能下结论。
3. **发行身份只在归因层面有作用**：S2（同一内容重复发行）中，只有 Wstar（1.00）和主动变体 A1_bm25（0.66）能消除来源歧义，内容指纹都是 0。但在控制层面，两者的单元级恢复完全相同，所以**不改变任何安全决策**。这与理论第 5 节的预测一致。
4. **在 paraphrase 变换下，BM25 已经足够**：危险放行为 1 次，与理想通道几乎相同。MinHash 和 SHA256 失效。

## 3. 偏离

- **S4 的归因结果被重复计算了 3 次**：代码对每种变换都运行了一次 S4，但 S4 固定使用 fragment 变换，所以 attribution.csv 中有 3 组 S4 行，它们用的查询种子不同。三组都保留，结论一致。这一点记入 `DEVIATIONS.md`。

## 4. 后续

- 由本机的 Claude 下载 BGE 和重排序模型，补跑 F4 和 F5，然后重新计算 W0-1 的最终判定；
- 如果补跑后仍是"暂定有额外价值"，并且只出现在片段场景中，就要先用真实水印检测器测量**片段长度—检出率**曲线，再决定是否投入 GPU。

## 5. F4、F5 补跑与 W0-1 最终判定（附录 `PREREG_GATEW0_F45.md`，冻结提交 7bc96ff）

运行前核对：用原代码重跑 F3_bm25 种子 0、1，12/12 与 `control.csv` 一致；重算的原 W0-1 暂定判定与 `judgments.json` 完全一致。结果在 `results/f45/`。

**阈值**（种子 99 的零分布 95% 分位数，各 30 次查询）：θ₄ = 0.982（零分布中位数 0.892），θ₅ = 0.998（中位数 0.977）。合成模板高度相似，错误匹配的分数本来就很高，所以阈值很高；零分布只有 30 个点，阈值的不确定性较大。

**最终判定：W0-1 = "有额外价值"**，只出现在 fragment 变换中：

| 单元格 | F_best（F1–F5） | F_best 危险放行均值 | F3_plus_Wstar | 差的 95% 下界 |
|---|---|---|---|---|
| 合成 K = 16 / fragment | F5_bge_rerank | 0.633 | 0 | 0.30 |
| 合成 K = 32 / fragment | F3_bm25（F5 为 0.800） | 0.700 | 0 | 0.43 |
| 其余 4 个单元格（identity、paraphrase） | F1 / F3 / F5 | 0 | 0 | 0 |

所有方法的不必要拒绝率都是 0。

**描述性结果**：
- F5（重排序）在 paraphrase 下恢复了 94–99% 的单元，与 BM25 相当；在 fragment 下只恢复 22–30%，精度 0.26–0.45。
- F4 的阈值过高，paraphrase 和 fragment 下召回为 0，表现等同于精确匹配。
- 归因层（Eedi）：S2（同一内容重复发行）中，F4、F5 的歧义消除率都是 0，与其他内容指纹相同；fragment 下 F5 的单元召回为 0.32–0.35。

**解读（附录第 4 节已事先写明）**：
1. 这条"额外价值"来自 Wstar 的理想假设，即只剩 5 个词也能恢复来源。fragment 只保留每句最后 5 个词，条目编号丢失后，不同条目中特征、取值相同的句子片段完全一样，任何只看文本的方法都无法区分。它是**理想水印的上界**，不是真实水印的证据。
2. W0-0 仍然成立：Wstar 与 Cstar 每次决策都相同。价值来自"能从片段恢复内容"，不来自发行身份。
3. 按原停止规则，水印拓展**不停止**；但投入 GPU 之前，必须先测真实检测器的**片段长度—检出率曲线**（5、20、50、100 词）。KOSW 容量中位数约 207 句、AFK 有效证据 0.64–0.79 比特，预示真实水印在 5 个词上很难承载载荷。
