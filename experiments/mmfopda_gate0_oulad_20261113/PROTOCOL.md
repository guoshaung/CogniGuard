# Gate 0 冻结判定协议

先提交字段审计，再冻结 REQUEST_RULES、本文、划分、生成与攻击代码 SHA256，最后运行。只运行一次，不以结果调规则/标签/课程。不运行 Gate 1。

攻击器：LogisticRegression(C=1, class_weight=balanced, max_iter=2000, solver=lbfgs)，训练端 log1p 后 StandardScaler；DecisionTreeClassifier(max_depth=3, class_weight=balanced, random_state=20261113)。固定阈值0.5，无调参或阈值选择，无测试拟合、无测试中位数。

每标签×4截点×2模型报告：三个单方、三组两两合谋、三方合谋、原始行为上界参照；各观察方另有独立 train/test 标签置乱对照，seed固定。原始行为并非数学上界，固定浅模型可能无法达到全部信息的最优推断。

原始行为向量只含截至截点的：总点击、按类型点击、活跃日数、可用成绩数/均值/最近值/最小值、已提交数量、迟交数量、累计正迟交天数。缺少成绩均值/最近/最小用0，成绩数量用于区分。只用同一注册资格下事件。无画像/课程ID/最终结果。均为非负；log1p处理。

每学生只有一个选中课程和一条预测/配置。学生级有放回 bootstrap 1000次，固定seed；95%百分位区间。bootstrap不重新训练，表示固定模型条件下的测试学生抽样不确定性。AUC按概率含并列；平衡准确率用0.5阈值。单类抽样丢弃并报告有效重复数。三方与“最佳单方”的配对AUC差用相同抽样，重复中重新取三单方最大AUC。主点差为三方AUC减三单方测试AUC最大值；该最佳单方不是部署期调参。

闸门完全按用户门槛：任一预设标签/截点/模型三方 AUC>=0.65、该AUC95%下界>0.55、且比同标签/截点/模型最佳单方高>=0.03 → PASS；否则任一单方AUC>=0.65 → PARTIAL；否则 FAIL（STOP）。PARTIAL允许单接收方路线，但本轮也不设计防御。闸门不依赖原始行为或置乱结果。配对差区间另外报告，不额外修改上述判定。

存在3标签×4截点×2模型的筛选，多重比较不校正；结果是探索性可行性闸门，不是独立确认性发现。同期 pooled 课程结果可能由行为中的课程差异解释，不能声称对新课程/新学期泛化或合谋因果效果。按课程附报固定模型的测试分组指标作诊断，不用于另找通过结果。

数据是公开匿名教学行为，模拟请求不含画像字段但可能携带相关性；不做真人身份重识别。年龄55+与其他正类可能稀少，记录每类 train/test人数，不重采样造人；缺失标签逐标签排除。无可靠成绩公布时间，因此是明确时点假设下的离线结果。没有真实教学干预/支持必要性标签或学习后测，不评判教育收益。

per_student.csv 保存稳定随机式伪名、划分、选中队列、标签、真实/置乱目标与各配置概率/预测（long格式，仅测试学生）；仅本地，不进入 Git或远端。训练原始ID联结、请求流、特征与划分同样只保存在 var。本目录交付聚合指标、冻结证据和代码。不会上传任何数据或调用付费API。
