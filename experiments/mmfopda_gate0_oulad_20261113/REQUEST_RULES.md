# 请求生成规则 v1（结果查看前冻结）

固定课程 BBB/DDD/FFF—2014J，不再更换。仅行为、联结键、公开资源/截止日/课程日历进入生成器；禁止全部 studentInfo 画像与标签。注册表仅控制截至当时的注册资格。

- 学生 ID 的 SHA256（盐见代码）小于 0.6×2^256 为 train，余下 test；不分层、不补平衡。
- 一个学生若有多门候选课程，用独立 enrol 哈希最小者选一门；不根据标签/表现选课。训练测试学生严格不交叉。
- 周 1 为 day 0..6；第 w 周末为 day 7w−1；4/8/12 周对应 day27/55/83。全学期终点为 courses.length−1（最后不足七天仍生成一次）。day<0 的点击不计入每周占比。
- 第 w 周末资格：date_registration 非缺失且 <=周末，且 date_unregistration 缺失或 >周末。已退出不再发请求，但历史请求仍保留；不以未来退课/最终结果筛除学生。
- 仅使用非结转 TMA/CMA、已知截止日和已观察提交。分数公布日未发布：固定模拟可用日 max(date_submitted,截止日)+7；当天之后才能使用分数。不是实际成绩公布时间；全学期后才可用的分数不纳入。
- 辅导：每个有资格的周末，取当时可用且非空的最新分数（按可用日、assessment ID 排序），<40 发一次 tutoring；最近三次分数严格下降发一次 review_session；可同时发两种，每种每周至多一次。无可用分数不发；相同低分可以跨周持续触发。
- 教务：本周末已发生且此前周末之后才提交、date_submitted>截止日的非结转 TMA/CMA，每次提交发一次 extension（允许同周多次）。先前周的延迟提交不补发；day<0 的提交计入第一周。按是否延期请求建模，不区分获批。提前/按时提交不发 extension，不论分数。
- 资源：以该周 day>=0 的 sum_click 总和为分母，按 activity_type 汇总占比。每周总点击>=10 且某类型占比 >= 该课程同周训练学生占比中位数+0.20 时，发一次 format_<type>。0.20 是预定的工程偏离阈值，不是统计显著性检验。只处理正向偏好偏离，不把零点击解释为格式需要。
- 同课程周中位数仅用训练划分、该周有注册资格的全部学生；无点击学生的占比为0。无合格训练学生则阈值基准0；不使用测试分布、标签或未来周。资源词表固定为选中课程 vle 元数据的全部 activity_type，不按攻击结果选特征。
- 接收方实际消息只有 {request: 请求名}；稳定伪名仅作路由与合谋联结，不作为攻击特征。没有画像、分数、点击、课程、日期、学生ID、迟交天数或自由文本。请求被当作有意模拟的服务事件，不声称是真实已申请支持。
- 攻击特征只统计截至截点各请求名的累计次数；不包含请求时序/缺失标记/课程身份，未收到任何请求为全0。两两或三方合谋仅拼接各方计数。攻击者能观察队列名单，故能将零请求学生编码为零；不能识别无请求且未知是否存在的学生。

标签仅在请求及特征保存后联结：disability Y；imd_band 最低两档（0-10%、10-20）为1，缺失仅对本标签排除；age_band `55<=` 为1。其余合法档为0，不插补标签。
