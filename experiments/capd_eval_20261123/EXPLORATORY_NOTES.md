# 探索性记录（探索性，不属于预注册）

本文只记录 E2 正式网格跑完之后的只读复核。它不修改 `PREREG_E2.md`、E2 代码、参数网格或 `results/`。E2 第 6 节的判定不变。

## 措辞纠正

- R-edu 用到的受保护单元是 25 个。`education_targets()` 给出 15 个目标，每个目标 1 个推导集；推导集中的 `(resource_id, unit_id)` 去重后为 25。同一方法下 R-syn 是 64 个。
- 普通学习者是被降级为摘要，不是被拒绝。`results/raw.csv` 里 capd 的 320 行 FRR 都是 0.000000。按同一网格重放这 320 行，普通学习者请求 48640 次，选中 full 的 35291 次，选中 summary 的 13349 次，选中 refuse 的 0 次。summary 不透露单元，效用 0.4。
- 帕累托比较只是本次扫描中具体配置的探索性比较。`results/pareto.csv` 的 68 行是第 4 节网格里每个（组, 参数, 登记表, c）在 10 个种子上的平均，比较范围就是这些已扫描的配置。

## 只读诊断

方法：对 `results/raw.csv` 中的每一行 capd，用同一种子重建请求流，并用该行的 k 与 λ 重建 capd。每次 `select` 之前，对完整内容候选调用 `check_release`，knowledge 取自内存回执里、该候选所触及推导集的已有持有者。重放的 CRR 与 `raw.csv` 在 6 位小数上一致的行数是 320，不一致的行数是 0。普通学习者没拿到完整内容时：

- `check_release` 判为不安全：记为“系统假设至多 k 人的联盟能补齐推导集”；
- `check_release` 判为安全但仍选了 summary：记为 λ 定价，因为 λ = 0 时完整内容的分数高于摘要。

不安全时，违规联盟里除接收者以外的学生记为被假设的合作者，并按请求流里的角色计数。角色是生成器指定的，不是观察到的合作。脚本与汇总表在 `exploratory/diagnose_downgrade.py` 和 `exploratory/downgrade_summary.csv`。

计数（10 个种子合计）：

| 项目 | 次数 |
| --- | --- |
| 普通学习者请求 | 48640 |
| 选中 summary | 13349 |
| 其中 check_release 不安全 | 10416 |
| 其中完整内容安全、由 λ 定价落到 summary | 2933 |
| 不安全、且违规联盟含另一名学生 | 9784 |
| 被点名的其他学生：普通学习者 | 9119 |
| 被点名的其他学生：完整学习者 | 1278 |
| 被点名的其他学生：合谋小组成员 | 2689 |

λ = 0 的 16 行（2 套登记表 × 2 个 c × 4 个 k）里，定价类次数都是 0。λ = 1 的 16 行里，定价类次数都大于 0。这 2933 次定价类降级全部来自 λ = 1。

k = 1 的 8 行里，“含另一名学生”的次数都是 0。k = 1 时联盟只有接收者本人。

结论：降级常与“系统假设另一名学生可能合作”有关（13349 次 summary 中有 9784 次点名了另一名学生），也有一部分来自 λ 定价（2933 次）。实验没有观察真实的合作关系，所以不能断言这些假设的合作者是无辜的。
