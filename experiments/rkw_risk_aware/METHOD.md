# RKW 开发载体

以稳定资产 ID 分配五位偶校验码。12 个登记资产来自六个主题族，每族两份内容相同的实验资产，用不同码字检验内容歧义。每个资产的两次发行共享码字。五个位置各以一个教学句的等义表达二选一。普通前缀对照在同样五个位置插词。原样输入自动回归覆盖全来源和异主题两源混合。

解码扫描全部登记族，用固定的句内词面上下文识别每个位置。每族的五位均唯一并匹配登记码字时输出资产候选。识别到互斥变体时记录冲突。族和事实由公开登记定义，运行时仅输入正文。大幅重构可能丢失实际表达或匹配上下文，因此另用宽松诊断区分这两种情况。诊断不参与实际解码。

R1 的结论限于这一种载体和开发语料。候选表达由作者式审阅选取，数字和其余句框固定。自然性、同义关系和传播保真仍需逐条评估。R1 期间只运行风险正确性夹具，风险分配的效果属于后续门槛。
