# 报告：从真实攻击数据估计泄露集误设先验

预注册：`PREREG_PRIOR.md`（3442904）。数据是 E3b-v2 中 GLM-5.2 攻击者的已有采样记录，本轮**没有调用 API**。结果文件：

| 文件 | 内容 | 是否预注册 |
|---|---|---|
| `results/prior.json` | 先验估计 | 预注册 |
| `results/real_misspec.json` | 现实误设下的改进空间 | 预注册 |
| `results/exploratory.json` | 零模型对照、严格版改进空间 | 数据后加入，见 DEVIATIONS P1–P2 |

## 一句话结论

- **按预注册判据**：28% 的单个单元被攻击者"超额"利用，5 次中命中 ≥ 3 次（194/702，Wilson CI [24%, 31%]）。
- **但这大部分是噪声和阈值边界造成的，不是真正的隐藏泄露。** 如果攻击者恰好按谓词的上限猜题，同一判据下预期也会有 32% 被标为隐藏；实测 28% 反而更低。
- **真正超出谓词的只有一小部分：** consistent ≥ 3 的单元比零模型多出 5–8 pp，约占全部单元的 3%。
- **形式泄露集反而偏保守：** 42% 的形式泄露集没有被攻击者利用。
- **最终判断：** 真实误设远比上一轮的合成误设弱，而且结构简单，主要集中在泄露量恰好等于 τ 的边界单元上。

## 1. 先验估计（预注册）

**按单元类型：**

| 类型 | n | 观测隐藏率 | 零模型（谓词最优攻击者） |
|---|---|---|---|
| 正确答案 | 52 | 0.50 | 0.48 |
| 数字 | 300 | 0.31 | 0.31 |
| 知识点 | 84 | 0.27 | 0.38 |
| 错误认知 | 169 | 0.25 | 0.39 |
| 学科 | 97 | 0.11 | 0.08 |

**按 consistent 分桶**（谓词预测成功率 = 1/consistent）：

| 分桶 | n | 观测 | 零模型 | 观测 − 零模型 |
|---|---|---|---|---|
| c = 2（泄露恰好 = τ） | 370 | 0.36 | 0.50 | −0.14 |
| c = 3–4 | 204 | 0.22 | 0.17 | **+0.05** |
| c ≥ 5 | 128 | 0.13 | 0.04 | **+0.08** |

**验证集**（按秘密五五划分）：

| 模型 | 对数似然 | Brier |
|---|---|---|
| M0：全体一个比率 | −202.3 | 0.196 |
| M1：按单元类型 | −201.9 | 0.196 |
| M2：按 consistent 分桶 | **−193.4** | **0.187** |

- 按类型（M1）几乎没有提升；按 consistent（M2）提升明显。
- consistent 本来就是谓词模型的一部分，所以**误设主要可以由谓词泄露量本身预测**，不需要额外的类型先验。

**复测可靠性：** 原文与改写两次测量的一致率为 0.84，κ = 0.60。按预注册，这属于中等可靠，不是噪声主导。

## 2. 现实误设下的改进空间（预注册 §4，描述性）

设定：100 个秘密，W_true = 形式泄露集 ∪ 攻击者命中 ≥ 3/5 的单元。结果为 Δ U，单位 pp。

| 方法 − A1 | 全部隐藏单元（86 个秘密含隐藏） | 只取 c ≥ 3（数据后，46 个秘密） |
|---|---|---|
| OCELOT_P | +0.3 [−2.0, +2.4] | −1.6 [−3.8, +0.3] |
| PFLOW_P | −2.2 [−4.6, −0.1] | −3.7 [−6.0, −1.5] |
| DYNCQE_P | −0.9 | −2.1 |
| OCOST | +0.3 | −0.5 |
| CAPD_FIRST | −3.3 | −3.9 |
| **ORACLE_A1** | **+25.5 [+21.3, +29.8]** | **+14.3 [+10.2, +18.7]** |
| A1 泄露回合比例 | 48% | 24% |

- 和合成误设的结论一致：OCELOT / PrivacyFlow 类方法**仍然不比 A1 强**。
- ORACLE_A1 的空间被**高估**了，原因是它"知道"哪些单元在 5 次采样里碰巧命中，其中相当一部分是运气。

## 3. 对算法方向的含义

1. **"按单元类型给先验"没有用。** M1 不优于 M0。
2. **有用的信号是谓词泄露量本身。** 泄露量越接近 τ，被实际利用的概率越高（c = 2 时为 36%）。所以合理的方法不是建模"未知泄露集"，而是把硬阈值换成**按泄露量校准的软风险**：P(泄露 | K) = f(L\*(K))，f 从攻击数据中估计。
3. **最简单的对照必须先做：** 把阈值从"> τ"改成"≥ τ"（把 c = 2 的单元也当作泄露）。如果这一步就拿走了大部分空间，软风险方法就没有新意。
4. 真正超出谓词的泄露（c ≥ 3 中多出的 5–8 pp）规模小，而且每个单元只有 5 次采样，不足以支撑一个"不确定泄露集"算法的主要贡献。

## 局限

- 只测了单个单元，没有测"不是形式泄露集的多单元组合"，所以多单元的隐藏泄露率未知。
- 只用了一个攻击者（GLM-5.2，temperature 0.7），每个视图只有 5 次采样。
- 零模型假设攻击者恰好达到谓词上限，这是比较的基准，不是真实的攻击者模型。
