# 预注册：从真实攻击数据估计泄露集误设先验

在本文件提交之前，没有对下面的判据做过任何计算。本目录只读取已有数据，不调用任何 API。

## 0. 数据来源与已知信息（如实披露）

- 数据：E3b-v2 实验中 GLM-5.2 攻击者在 100 个 Eedi K=8 秘密上的采样记录。
  - `experiments/capd_e3b2_20261124/results/control_attack.csv`：原始模板文本（主数据）；
  - `results/attack.csv`：deepseek-flash 改写文本（复测数据）；
  - 单元视图信息：`cogniguard_data/e3b2/items.jsonl`。
- **已经看过的信息：** E3b-v2 的 RESULT.md 报告了另一个判据（p(s\*) 超过谓词预测 0.15）下按单元类型的超标比例。本实验的判据不同（见 §1），但两者相关，因此按类型的估计**不是盲估**。
- 每个单元视图只有 5 次采样，判据噪声大，这是固有局限。

## 1. 定义

- 单元 u 的谓词预测成功率 = 1 / consistent(u)（consistent = 与该单元一致的候选题数）。
- 在 τ = 2 bit、K = 8、均匀先验下，"泄露"等价于攻击者成功率 > 0.5。
- **形式泄露集**（W_obs）：谓词计算得到的极小集合。单个单元的 consistent ≥ 2，所以单元本身永远不是形式泄露集。
- **隐藏单元泄露（主判据）：** 原始模板视图下，5 次采样命中 ≥ 3 次（经验成功率 > 0.5）。
- 敏感性判据（只报告）：攻击者自报 p_true 的均值 > 0.5。
- 组合视图（全部 consistent = 1，即形式泄露集）用于估计"形式泄露集未被利用"的比例（命中 ≤ 2/5）。

## 2. 估计

- **划分：** 100 个秘密按 target_id 排序，奇数位为估计集，偶数位为验证集。
- 估计集上计算：
  - M0：全体隐藏率 π；
  - M1：按单元类型（construct / misconception / number / answer / subject）的隐藏率，用 Beta(1, 1) 后验均值；
  - M2：按 consistent 分桶（2 / 3–4 / ≥5）的隐藏率。
- 验证集上比较三个模型的对数似然（Bernoulli）和 Brier 分数，报告 Wilson 95% CI。

## 3. 复测可靠性

- 同一单元在原始文本与改写文本下的判定一致率，以及 Cohen's κ。
- κ < 0.4 时，标签只能当作"噪声很大的估计"，后续模拟必须同时报告 π 的上下界情形。

## 4. 现实误设下的改进空间（描述性，不判 GO/STOP）

- 对 100 个秘密中能被 `gen_eedi` 构造的实例：W_true = W_obs ∪ {隐藏单元泄露 {u}}。
- 用 ms.py 的同一套评价（U、泄露率，E = 20，种子按 Eedi 编号），运行 A1、CAPD_FIRST、OCELOT_P、PFLOW_P、DYNCQE_P、OCOST、ORACLE_A1。
- 报告 ORACLE_A1 − A1（真实误设代价），以及各方法 − A1。
- 这是"真实攻击者定义的误设"，用来检查 §ms 的合成误设规则是否与现实同量级。

## 5. 产出

- `results/prior.json`：π、M1、M2 的估计与验证分数，κ；
- `results/real_misspec.json`：§4 的结果；
- `REPORT_PRIOR.md`。
