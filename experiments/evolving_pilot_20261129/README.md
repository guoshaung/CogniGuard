# 进化层持久化试验（2026-11-29）

这是试验，没有预注册，不能作为论文结论。正式实验以后另行预注册。

## 设置

- 5 个智能体，20 代。每代每个智能体做 3 次进化动作：写记忆、建技能、共享。选择由种子 `20261129` 固定。
- 第 3 代额外注入 4 类污染，各 10 个载荷：带指令的记忆、含 `subprocess` 的技能、修改 `guardrail` 片段、向允许名单之外的接收方共享。
- 无防护：闸门不挂检查器，也不隔离来源。
- 有防护：`default_checkers`，并在第 10 代对全部注入来源调用 `quarantine_source`。

## 指标

- 第 20 代仍然是某对象当前版本的污染版本数，以及它占 40 个注入载荷的比例（持久化率）。
- 这些仍然生效的版本涉及到的智能体数（传染范围）。
- 正常进化动作被拒绝的比例。
- 每次 `propose` 的平均耗时。

运行：在仓库根目录执行 `python experiments/evolving_pilot_20261129/run.py`。结果写在 `results/pilot.json`。
