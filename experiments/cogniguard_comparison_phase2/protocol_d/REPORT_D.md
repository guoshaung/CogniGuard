## 3. 解读

1. **对 LLM 原生防御：** 泄露降低约 **80 pp**（从 0.81–0.85 降到 0–0.26）。代价是正常放行率比 CoDef-R 低 7–9 pp。CoDef-R 几乎什么都放（0.99），所以几乎全部泄露。按预注册的 5 pp 容许线判为不成立，但从安全与效用的平衡看，CA-PD 远远领先：Balanced 高 0.36–0.40，安全 × 放行高 0.72–0.78。
2. **对 OCELOT 按人记账：** CA-PD 的前沿显著更高（+7.7 pp 和 +44 pp）。按人记账面对合谋，只能把预算压得很低，结果大量拒绝正常请求。
3. **对 OCELOT 共用账本：** 在它最好的预算（B = 0.75，测试集上的最优点，对 OCELOT 有利）下，它与 CA-PD **基本相同**。
   - |W'| = 3 时，"共用账本 + 在补齐处拦截"与 CA-PD(k ≥ 3) 完全等价；
   - **只有 |W'| ≥ 4 且 k < |W'| 时，两者才有差别。** 探索性分析：c = 2、|W'| = 4 的 11 个场景中，CA-PD(2) 的正常放行率比共用账本最好点高 +6.8 pp，两者泄露都是 0。这正是有界联盟的中间地带，但样本很少。
4. **样本不足：** n = 27，只覆盖官方场景中编号较小的部分，没有任何新场景。

## 4. 结论与下一步

- **目前不能宣称 CA-PD 超过了 OCELOT 的全部预算前沿。** 对共用账本，它只是追平；只在 |W'| ≥ 4 的子集上有探索性的优势。
- **可以宣称的：**
  - 合谋下，相对 LLM 原生防御，泄露降低约 80 pp，平衡分大幅领先；
  - 相对按人记账的 OCELOT，前沿显著更高；
  - CA-PD 不需要调预算：取 k = c 就直接落在共用账本最好点的位置，而 OCELOT 要在测试集上调到最优预算才能追平。
- **要检验"在 |W'| ≥ 4 时超过共用账本"，需要充值续跑剩下的约 123 个场景。** 之后按预注册重新判定一次，结果是否改变以实际数据为准。
