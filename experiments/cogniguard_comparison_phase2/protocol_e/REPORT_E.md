## 3. 解读

1. **对 LLM 原生防御：** 泄露降低 **53–58 pp**（从 0.54–0.59 降到 0.01），正常放行只低 0–5.6 pp。Balanced 高 0.26–0.27，安全 × 放行高 0.51–0.55，CI 全部远离 0。
2. **对 OCELOT 按人记账：** 在所有条件下，CA-PD 的前沿都显著更高（+4.8 pp 和 +27.3 pp）。
3. **对 OCELOT 共用账本：**
   - c = 2：显著更高，但只高 **1.4 pp**；
   - c = 3：完全相同。
   - 按 |W'| 分层（描述性）：c = 2、|W'| ≥ 4 时，CA-PD(2) 的放行率为 0.972，共用账本最好点为 0.950，高 2.2 pp；|W'| = 3 时两者相同。这与理论一致：只有 k < |W'| 时，有界联盟才比"任意合谋"宽松。
4. **CA-PD 需要正确设置 k：** c = 3 时用 k = 2，泄露为 0.358。共用账本相当于 k = ∞，不需要知道联盟规模。论文必须写明这一取舍。
5. **CA-PD 的泄露（0.7–1.4%）不为零**，来自识别器的漏判。泄露很低，是因为漏判的回答多半本身信息很少。

## 4. 对论文的含义

- **最强的结论：** 联盟感知的确定性门控（大模型识别 + CA-PD），在自然语言多提问者合谋下，把泄露从 LLM 原生防御的 54–59% 降到约 1%，正常放行率只损失 0–6 pp。
- **对 OCELOT：**
  - CA-PD 始终优于按人记账的预算前沿；
  - 当联盟规模小于敏感组合大小时（c = 2），CA-PD 显著但小幅优于共用账本的最优前沿（+1.4 pp，|W'| ≥ 4 时 +2.2 pp）；
  - 其余情况与共用账本等价。
  - 不能写成"大幅超越 OCELOT"。
- 判定严格按预注册为 STOP，论文中应同时报告全部子项。
