# CogniGuard Phase 2 横向对比：方法

> 基线的出处、复现等级与公式—代码映射见 `BASELINE_AUDIT.md`。被评价的方法为 **CogniGuard-NoWM**（Phase 1，`2d8e9b8`）：BGE + NLI 动态知识状态 + CA-PD(k)，不含水印。

## 1. 两套协议

**Protocol A（相同信息下比较治理算法）**：

- 所有方法拿到同一份授权状态、知识单元、受保护目标、已知持有状态（同一状态层）、BGE + NLI 证据（只有 phase1 有文本证据）、候选（所请求的单元）、请求顺序、k 和效用定义。
- **主模式 snapshot**：状态只沿一条参照轨迹演化（Oracle 的放行：已授权且真实安全）。每个方法在同一状态上作答，答案只计分、不生效，所以各方法的危险请求和安全请求分母完全相同。
- **辅助模式 path**：每个方法自己的放行会成为回执，用来计算联盟违规率与新增秘密恢复率。
- 加入 `ExactEnum` 精确枚举，比较开销。

**Protocol B（原生完整方法）**：

- OCELOT：没有权重或代码，记 NA；
- Sum Leaks：原生 LLM 防御本轮未运行，只引用论文自报数字；
- CogniGuard：端到端延迟 = 证据检测（Codex 实测，见 RESULT）+ 规则判定。
- Protocol B 不与 A 混合解读。

## 2. 数据集（第一阶段）

| 世界 | 真实部分 | 合成部分 | 初始状态 |
|---|---|---|---|
| `phase1` | 与 Phase 1 相同：真实传播、NLI 证据 | 见证（随机跨来源）与治理结构 | Phase 1 冻结世界**含历史违规**（k = 2、3 时 19%–38% 的目标一开始就可被联盟补齐）。单独报告"排除历史目标"的危险放行率 |
| `eedi` | 官方 Eedi 考试秘密（MANIFEST `d4401ef4…`）：谓词推出的见证、精确 L（**真实语义支撑的教师保密见证**） | 每个世界抽 24 个秘密；持有者、请求与授权是合成的 | 发行只给部分单元，且全体并集不含任何见证 → **历史违规为 0** |
| `sumleaks` | Sum Leaks 场景的连接见证（MANIFEST `7c53e01b…`，与 E7 一致） | 同上 | 历史违规为 0 |

- 传播条件：low（无未记录转移），high（`phase1`：真实传播加画像泄露；其他两个世界：15 次合成转移）；
- k ∈ {1, 2, 3}；
- 每个世界 300 条请求，含中途撤销与越权请求；
- eedi、sumleaks 没有文本证据，所以 nli 层等于回执层。

## 3. 指标

| 指标 | 定义 |
|---|---|
| Harmful Release Rate | 放行的危险请求 / 危险请求（已授权，且在真实状态上 CA-PD(k) 不安全） |
| 同上，排除历史 | 只统计不涉及初始已被攻破目标的请求 |
| Task Utility | 1 − 不必要拒绝 / 安全请求 |
| Over-refusal Rate | 不必要拒绝 / 安全请求 |
| Unauthorized Success Rate | 放行的未授权请求 / 未授权请求 |
| Coalition Violation Rate（path） | 结束时可被 ≤ k 人联盟补齐、初始时不可补齐的目标比例 |
| New Secret Reconstruction Rate（path） | 结束时可补齐、但只靠未记录传播不可补齐的目标比例，即由系统放行造成的部分 |
| P50 / P95 | 规则判定耗时（μs） |
| End-to-End | 规则判定 + 证据检测（Codex 实测的 BGE / NLI 摊销耗时） |

**实际任务完成质量**：需要 LLM 或人工评审教学结果，本轮**没有**。论文中不把放行比例等同于教学质量。

## 4. 安全—效用公平比较

- 预算或参数型方法：OCELOT-PF 的 B（两种范围）、ToM 的 ρ。在**开发种子 900–909** 上，对每个单元格选出：
  - 危险放行率 ≤ 1%、5%、10% 时效用最高的参数；
  - 效用 ≥ 90%、95%、99% 时危险放行率最低的参数。
  
  达不到的目标记为 NA，冻结于 `results/dev/operating_points.json`。
- 固定规则（CA-PD、CrowdControl、WS04、SumLeaks-Local / CoDef）各只有一个点，报告它在正式集上是否达到每个目标。
- 完整 Pareto 曲线使用全部参数点。
- 对照 M3 的配对差：按种子做 bootstrap，5000 次。
