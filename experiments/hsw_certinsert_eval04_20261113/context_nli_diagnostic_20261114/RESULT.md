# EVAL-04 开发诊断结果

55 个独立词条共完成 5,500 组正向 NLI，使用与阶段 0 同一权重和 tokenizer。达到 95% 正向通过率的词条为 `that is`（98%）。原始阶段 0 仍停在流畅度筛选前，`L*` 未生成。

原句池 10,450 句，其中 5,370 句有同一文档且同样在旧句池内的紧邻前句。每词分母 100，阈值为模型蕴含概率 ≥0.9。实际最大 299 token，因长度跳过 0 组。使用本地 CUDA FP32，未调用其他模型。

47 个原候选中共有 2,420 个同词同句配对，无上下文时通过 775/2,420（32.0%），加入上一句后通过 538/2,420（22.2%），描述性差值 -9.8 个百分点。分母是词条与句子的配对数，句子可跨词条重复。模型权重一致，旧分数为 CPU，新分数为 CUDA。完整新样本与原 100 句不完全相同，配对子集可减少样本差异。

PDTB 匹配 26/47。使用 LDC 公布的 PDTB-2.0 Annotation Manual 附录 A 表 2–7，印刷页 65–70。以附录首列 100 个词形为准，只归一大小写和空白，不用近义词、词干、子串或附录 B 的变体补齐。‘是’表示词形出现过，未对这批句子的具体用法做话语关系标注。[PDTB-2.0 Annotation Manual，附录 A](https://catalog.ldc.upenn.edu/docs/LDC2008T05/manual/pdtb-annotation-manual.pdf#page=70)
