# 数学分析：LP 对偶影子价格与 OCOST、A1 的关系（数据前）

文献按已有知识列出；写进论文前必须核对原文。

## 1. 已有方法的归属（不是新方法）

- **SP_LP 不是新方法。** 它就是网络收益管理里的确定性 LP（DLP）竞价价格（bid-price）控制【待核对：Williamson 1992；Talluri & van Ryzin 1998，Management Science】：
  - 资源 = 推导集的剩余容量 |r| − 1；
  - 产品 = 任务选项；
  - 价格 = 容量约束的对偶变量。
- **OCOST 也是已有方法。** 它是在线打包问题的原始–对偶指数定价【待核对：Buchbinder & Naor 2009】。
- 所以，即使本轮得到 GO，也只能写成"把 bid-price 控制用于组合泄露约束下的披露"，不能写成新的数学量或新算法。

## 2. 命题 1：只服务时，决策与时域无关

- n_t = h·q_t。把 (y, n) 同时乘以 c > 0，x 不变，可行域与最优解一一对应，所以 LP(c·h) = c·LP(h)，对偶 λ 也按 c 放大。
- 推导集行的右端（|r| − 1 − EPS）只约束 x，不随 h 缩放，因此这一性质严格成立。
- 结论：只服务动作空间下，SP_LP（取价格 argmin）和 SP_DISP（取位移 argmin）的决策与 h 无关。
- 和 A1 一样，SP 在只服务模式下**没有"时域感知"**。时域只通过延迟阈值（SP_D：价格 ≤ 1）起作用。
- 测试：`test_homogeneity_in_h`。

## 3. 命题 2：SP_LP 与 OCOST 不等价

- OCOST 的单元价格 p_u = Σ_{r∋u} 2^{−(|r|−1)}，只依赖残差结构，与 q、需求能否改道无关。
- SP_LP 的价格在约束不紧时为 0，即残差中的其他单元没有需求，或需求能改道到免费选项时。
- **反例**（`test_ocost_counterexample`）：
  - 残差 r1 = {0,1}，单元 1 无人需要；
  - 残差 r2 = {2,3,4}，任务 B 需要 {3,4}；
  - 任务 A 可选 {0} 或 {2}；
  - OCOST 选 {2}（价格 0.25 < 0.5），从而杀死 B；SP_LP 选 {0}（价格 0）。
- 反过来，所有残差都"有需求、不能改道"时，两者都偏向更大的残差，排序可能一致。一致的程度由 P0 实测。

## 4. 命题 3：SP_LP 与 A1 没有一般等价关系

- A1 的得分是 Σ_t q_t(1 − γ^{#存活选项})：
  - 只在选项被**完全杀死**（残差 ⊆ 选项）时才变化；
  - 对存活数是凹的；
  - 不含流体量。
- SP_LP 在选项被杀死之前就会给"消耗残差容量"定价（分数解），而且价格与需求量 q 成线性。
- 两者在"免费替代选项"这类情形上一致，例如 `tiny(True)` 中都选单元 2。
- 没有找到一般等价，用 P0 的决策一致率实测。

## 5. LP 松弛的强度

- 反例 1：三个两两相交的残差 {0,1}、{1,2}、{0,2}，三类任务分别只要单元 0、1、2。
  - 整数解最多披露 1 个单元，服务 1 类；
  - LP 可取 x = 1/2，服务 1.5 类。
  - 松弛有整数间隙，价格因此可能偏低。
- 反例 2：两个单元的残差 {0,1}，两类任务各需一个单元（`tiny(False)`）。LP = 整数最优 = 3，没有间隙。
- 实测 LP(H)/OPT 的比值，见 P0 结果。

## 6. 对偶的非唯一性

- 退化时，对偶 λ 可以取右导数和左导数之间的任意值，HiGHS 只返回其中一个顶点。
- 例：`tiny(True)` 中 λ ∈ [0, 3]。
- 处理：把推导集行收紧 EPS，取左导数，即"消耗容量会造成多少损失"，这正是 bid-price 的含义。
- 在该例中，单元 0 的价格为 3，单元 2 的价格为 0，SP_LP 正确地选择 {2}。
