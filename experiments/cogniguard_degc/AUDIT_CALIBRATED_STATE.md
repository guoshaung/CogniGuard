# 审计：危险放行率从 0.21 降到 0.04 的"校准概率知识状态"结果

> 双重熵（DEGC）的 STOP 结论保留，本审计不再论证第二重熵。
>
> 目的是查清 B1（0.21）→ B2（0.04）的收益**到底来自哪个机制**。范围：
> - 不改 CA-PD 核心算法，不新增无关候选；
> - 全部数据为已暴露的 Protocol B2 诊断数据，**不是**留出结果；
> - 全部组都是 **0 次追加核验**。
>
> 代码：`audit_b2.py`、`mc_audit.py`、`sim_pareto_k1.py`。结果：`results/audit_b2.json`、`mc_audit.json`、`sim_pareto_k1.json`。

## 2. 收益分解（消融阶梯，0 次核验）

| 组 | 改动 | 危险放行 | 误拒 | 正常任务成功率 | 阻断回答数 |
|---|---|---|---|---|---|
| L0 = B1 | 联合检测命中 → 持有；确定性 CA-PD | 0.210 | 0.024 | 0.697 | 69 |
| L1 | 校准概率 ≥ 0.5 → 持有（只把校准当分类器用） | 0.126 | 0.024 | 0.697 | 83 |
| L1t | 校准概率 > 0.05 → 持有（τ 取 0.05–0.2，结果相同） | 0.101 | 0.024 | 0.697 | 86 |
| L1t | 校准概率 > 0.02 | 0.050 | 0.047 | 0.681 | 110 |
| L2 | **未校准**置信度 + 概率状态 + 机会约束（δ = 0.02） | 0.017 | **0.776** | 0.160 | 396 |
| L3 | 当前回答用校准概率，历史状态确定性（δ = 0.02） | 0.168 | 0.035 | 0.689 | 83 |
| **L3h** | **当前回答确定性，历史状态用校准概率累积**（δ = 0.02） | **0.042** | **0.024** | **0.697** | 95 |
| L4 = B2 | 当前与历史都用校准概率（δ = 0.02） | 0.042 | 0.035 | 0.689 | 103 |
| L4 | δ = 0.05 | 0.067 | 0.024 | 0.697 | 91 |
| L5 | 经典逐回答贝叶斯风险，不用见证结构，不看历史（δ = 0.02） | 0.017 | **0.600** | 0.286 | 474 |
| L6 | 安慰剂：L0 加上随机拒绝，拒绝数与 L4 匹配（103），50 个种子 | 0.164 [0.134, 0.193] | 0.137 | 0.617 | 103 |

经典贝叶斯期望损失决策（L(放行) = ΔR，L(拒绝) = λ）与 L4 **数学上等价**，λ = δ。数值上也一致：阶段 B 中 B7 在 0 次核验时与 B2（δ = 0.02）结果相同。

**配对检验**（逐场景 bootstrap，单位为危险放行或误拒的差）：

| 比较 | 危险放行差 | 误拒差 |
|---|---|---|
| L1 − L0（校准当分类器） | −0.084 [−0.143, −0.042] | 0 |
| L1t(0.05) − L1 | −0.025 [−0.059, 0] | 0 |
| **L3h − L1t(0.05)（历史概率累积）** | **−0.059 [−0.109, −0.017]** | **0 [0, 0]** |
| L4 − L3h（当前回答也概率化） | 0 | +0.008 [0, 0.025] |
| L4(0.05) − L0 | −0.143 [−0.218, −0.084] | 0 |
| L6 安慰剂 − L0 | 约 −0.05 | +0.11 |

**结论：收益来自四个部分，不是更保守的拒绝。**

1. **概率校准**（约 0.11）：主要来自一个分箱，即**桥接表上 NLI 分数在 [0.3, 0.9642) 之间**的观测（54 次中 36 次确有披露，比例 0.67）。冻结阈值 0.9642 把这些观测都当作 0。这部分在效果上等价于"针对桥接表、依据标注数据调低 NLI 阈值"，确定性 CA-PD 也能得到。
2. **历史知识状态的概率累积**（约 0.06，显著，且误拒不增加）：多次低于阈值的弱证据（例如桥接表、NLI 在 [0.01, 0.3) 的分箱，比例 0.028，n = 421）按 noisy-OR 累积到历史状态，在补齐组合的那一步被识别出来。**这是唯一不能被确定性阈值替代的部分。**
3. **把当前回答也概率化**：对安全没有额外收益，反而多 1 个误拒场景。
4. **不是更保守的拒绝**：拒绝数匹配的随机安慰剂只到 0.164，误拒却高到 0.137。不校准（L2）或不用见证结构（L5）都能把危险放行降得很低，但误拒达到 0.6–0.78，不可用。

## 4. 校准与测试的隔离，以及标签问题

| 校准方案 | 危险放行 | 误拒 | 正常任务 |
|---|---|---|---|
| 按场景 5 折（主方案，种子 20261125） | 0.042 | 0.035 | 0.689 |
| 按场景 5 折，另外 4 个种子 | 0.042 | 0.035–0.047 | 0.681–0.689 |
| 留一场景 | 0.042 | 0.035 | 0.689 |
| 按来源家族分组 5 折（列名 Jaccard ≥ 0.3 的连通分量：66 个家族，最大 46 个场景） | 0.042 | 0.047 | 0.681 |
| 只用其他折 50% 的场景训练 | 0.042 | 0.047 | 0.681 |
| 只用其他折 20% 的场景训练 | 0.017 | 0.071 | 0.664 |
| 训练标签随机翻转 5% | 0.017 | **0.212** | 0.563 |
| 训练标签随机翻转 10% / 20% | 0.017 | **0.388 / 0.694** | 0.437 / 0.218 |

- **隔离**：
  - 同一场景的 sensitive 和 benign 运行总在同一折，没有场景层面的泄露；按来源家族分组后结果不变。
  - 分箱特征只来自文本和表格（是否精确匹配、语义命中、NLI 与余弦分数、是否桥接表），不含任何标签。
  - 代码中已断言：校准某一折时，不使用该折的任何标签。
- **标签问题（主要风险）**：
  - 校准用的标签和"实质阻断"判定用的标签，都是 **glm-5.2 参照标注，不是人工金标准**。50 对抽检中，模型间一致率为 94%。
  - 危险放行本身由官方判官决定；只看判官的口径下数值完全相同，但判官也是 glm-5.2。
  - 所以"概率与标签一致"在一定程度上是**同一模型家族的自洽**。
- **脆弱性**：方法依赖"负类分箱的披露率接近 0"（例如余弦分箱，1,570 次中 0 次）。训练标签只要有 5% 的对称噪声，负类分箱的概率就升到 0.05 左右，noisy-OR 累积后误拒升到 0.21。这说明结果对标注质量高度敏感。真实标注噪声多半是不对称且较低的，但必须用人工标注集量化。

## 5. 联盟风险（k = 2、3）：知识状态相关性与蒙特卡洛误差

**蒙特卡洛误差**（受控仿真，每个 k 取 120 个决策状态；参照值为 16,384 次采样，不确定变量 ≤ 12 时精确枚举）：

| k | 采样数 N | 剪枝阈值 | 偏差 | RMSE | 决策翻转率（δ = 0.05） |
|---|---|---|---|---|---|
| 2 | 128 | 0.005（仿真所用） | +0.003 | 0.017 | 4.2% |
| 2 | 256 | 10⁻⁶ | −0.001 | 0.014 | 1.7% |
| 2 | 1024 | 10⁻⁶ | 0.000 | 0.007 | 1.2% |
| 3 | 128 | 0.005（仿真所用） | +0.002 | 0.017 | 3.8% |
| 3 | 256 | 10⁻⁶ | −0.001 | 0.015 | 1.7% |
| 3 | 1024 | 10⁻⁶ | +0.001 | 0.007 | 0.3% |

- 剪枝（概率 < 0.005 的变量视为 0）带来约 +0.002 的系统偏差，方向偏保守。
- 仿真中 k ≥ 2 的结论约有 4% 的决策受蒙特卡洛噪声影响；正式实验应使用 N ≥ 1,024，或改为精确枚举。

**知识状态相关性**（受控仿真，0 次核验，δ = 0.05）：

| 设置 | B1 确定性 | B2，noisy-OR（假设独立） | B2，max（假设完全相关） |
|---|---|---|---|
| k = 1，ρ = 0 | 0.285 / 0.007 | 0.110 / 0.109 | 0.250 / 0.029 |
| k = 1，ρ = 0.9 | 0.235 / 0.008 | 0.055 / 0.105 | 0.180 / 0.051 |
| k = 2，ρ = 0 | 0.667 / 0.029 | 0.250 / 0.341 | 0.350 / 0.271 |
| k = 2，ρ = 0.9 | 0.567 / 0.020 | 0.200 / 0.354 | 0.250 / 0.326 |
| k = 3，ρ = 0 | 0.583 / 0.023 | 0.200 / 0.391 | 0.267 / 0.371 |
| k = 3，ρ = 0.9 | 0.550 / 0.014 | 0.183 / 0.399 | 0.217 / 0.368 |

（每格为"新增重构率 / 误拒率"。k = 1 用 200 个世界，k = 2、3 用 60 个世界。）

- **合并方式**比真实相关性 ρ 影响更大：max（假设完全相关）更保守地估计持有，危险放行更高、误拒更低；noisy-OR 则相反。真实相关性介于两者之间，合并方式必须作为显式的敏感性参数报告。
- **联盟条件下（k = 2、3），概率状态非常保守**：误拒达到 0.34–0.40，而 B1 只有约 0.02。原因是多个主体的弱证据都会进入联盟覆盖的计算。概率状态在单一对手（k = 1）时相对可用，**在有界联盟下，相同 δ 的安全–效用权衡显著变差**，需要按 k 调整 δ，或者把弱证据限制在接收方本人身上。这一点应该作为负面结果保留。

## 6. 受控仿真中的安全–效用曲线（k = 1，300 个新测试世界，0 次核验）

| 组 | 参数 | 新增重构 / 误拒 |
|---|---|---|
| B1 | — | 0.26 / 0.008 |
| OCL（校准阈值 τ） | τ ≤ 0.05 | 0.04 / 0.299 |
| | τ ≥ 0.1 | 0.26 / 0.008 |
| B2（概率状态 δ） | 0.01 | 0.030 / 0.267 |
| | 0.02 | 0.063 / 0.159 |
| | 0.05 | 0.087 / 0.114 |
| | 0.1 | 0.153 / 0.051 |
| | 0.2 | 0.257 / 0.010 |
| B2h（只有历史概率化） | 0.01 | 0.107 / 0.125 |
| | 0.02 | 0.120 / 0.088 |
| | 0.05 | 0.137 / 0.072 |
| | 0.1 | 0.213 / 0.027 |

在仿真中，概率状态给出一条**连续的安全–效用权衡曲线**，而不是"免费"的改进：

- δ = 0.01 时，B2 弱优于 OCL 的保守端（0.030 / 0.267 对 0.04 / 0.299）；中间区域确定性阈值没有可比的点。
- B2h 与 B2 大致在同一条曲线上。

阶段 B 中改进近乎"免费"，是因为真实数据的负类分箱非常干净（披露率约 0），而桥接表的弱证据分箱又很集中。这种数据特性**不能假设推广**到新场景。

## 7. 结论与下一步

| 问题 | 结论 |
|---|---|
| 真正有效的机制 | (a) 用标注数据校准检测证据，相当于修正桥接表的语义阈值；(b) **在 CA-PD 的历史知识状态中对弱证据做概率累积**（noisy-OR）。(b) 是唯一不能被确定性阈值替代、且在已暴露数据上显著（−0.059，误拒不增加）的部分 |
| 不是收益来源 | 更保守的拒绝（安慰剂已排除）；把当前回答概率化；未校准概率；去掉见证结构的贝叶斯风险；第二重熵 |
| 是否"稳定的安全–效用优势" | **尚未确立**。在已暴露数据上，各种分折方案下都稳定；但 (1) 校准与评测都依赖 glm-5.2 标签；(2) 对标签噪声高度敏感；(3) 受控仿真中只是一条权衡曲线，对确定性阈值没有明显的支配关系；(4) 在 k = 2、3 的联盟条件下，相同 δ 的误拒达到 0.34–0.40 |
| 等价性查新与留出实验 | 按"有稳定优势才做"的要求，**暂不启动**。建议先完成两项前置工作：(1) 200–300 对人工标注（覆盖桥接表和弱证据分箱），量化标签噪声并重新校准；(2) 由组会确定是否以"概率化历史状态的 CA-PD（L3h）"为唯一候选。之后再做等价性查新（概率数据库与推断控制、noisy-OR 证据累积、OCELOT 的 credal audit），并按 `PROTOCOL_B3_DRAFT.md` 准备独立留出的端到端实验 |
