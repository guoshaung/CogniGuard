# DEGC 实验结果

> 证据层次：
> - **阶段 A**：数学正确性，14 项测试全部通过。
> - **阶段 B**：已暴露数据上的离线诊断，操作点也在同一数据上选，结论偏乐观。
> - **阶段 B′**：受控仿真，测试世界全新生成；不是真实数据。
> - **端到端**：只做了接入冒烟测试，不是正式评估。
>
> 阶段 C（真实留出实验）**没有启动**，原因见第 6 节。
> Protocol A、B、B2 的结果未改动。

## 1. 阶段 A：数学正确性（`cogniguard/tests/test_degc.py`，14/14 通过）

已验证：
- 确定性状态下 R 与 CA-PD 核完全一致（200 个随机状态）；
- 包含-排除精确值；k = 2 联盟，以及接收方本身贡献为零的联盟；
- 三个反例：低泄露高熵、高泄露低熵、联合单元导致的状态偏离；
- 有界保守性；历史泄露不归因；泄露熵单调且有界；
- 相关合并（noisy-OR 与 max）给出上下界；Beta 分位数；合成数据上的校准与区间覆盖；核验预算上限。

详见 `THEORY.md` §6。

## 2. 校准：普通置信度 ≠ 持有概率（阶段 B，4,592 对，按场景 5 折交叉拟合）

| 概率来源 | Brier | ECE |
|---|---|---|
| 普通检测置信度（命中记 1，否则取 NLI 或余弦） | 0.248 | 0.391 |
| **Beta 分箱校准（含桥接表标志）** | **0.016** | **0.005** |
| 真实 LLM 核验器，校准后 | 0.058 | 0.007 |

- 真实核验器（glm-5.2 聚焦提示，4,592 次调用，约 0.97M token）与参照标签一致率 0.887，**精确率 0.531，召回率 0.997**。它偏宽松，几乎不漏检，但误报很多。
- 局限：参照标签来自同一模型家族（多表提示），所以召回率偏乐观。

**两种熵与实际危险放行的关系**（`results/entropy_relation.json`，在未设门控的回答流上统计）：

- 新增重构概率 ΔR 作为预测量：Brier 0.036，ECE 0.048。ΔR < 0.1 的 474 条回答中，实际新增重构率为 2.5%（12 条，即剩余的漏检）。
- 按状态熵 h(R) 分组看机会约束（δ = 0.05）的决策错误率：h < 0.2 时为 0.4%（n = 458）；h 在 [0.2, 0.4) 时为 11%，在 [0.8, 1.0] 时为 12%。**状态熵确实标出了决策可能出错的位置**。
- 泄露熵是 R 的单调变换，它与 Z 的关系就是 R 与 Z 的关系。

## 3. 阶段 B 主结果：真实 LLM 核验器，noisy-OR 合并

各组帕累托前沿（核验调用数 → 危险放行率 / 误拒率）：

| 组 | 前沿点 |
|---|---|
| B0 原始 CGC | 0 → 0.370 / 0.024 |
| B1 CA-PD + 联合检测 | 0 → 0.210 / 0.024 |
| **B2 只用泄露熵（校准后验 + 机会约束）** | **0 → 0.042 / 0.035** |
| OCL 类 OCELOT 保守默认 | 0 → 0.050 / 0.047 |
| B3 只用状态熵 | 571 → 0.244 |
| B4 随机核验 | 571 → 0.180；1,713 → 0.114 |
| B5 低置信度优先 | 571 → 0.042；1,713 → 0.017 |
| B6 普通风险驱动 | 571 → 0.017 / 0.024 |
| B7 经典 VoI | 35 → 0.034；240 → 0.025；511 → 0.017（误拒均为 0.024） |
| B8 全量核验 | 4,552 → 0.017 / 0.035 |
| HZ（h(R) 触发） | 15 → 0.042 / 0.035 |
| EC2 选择器 | 与 Ours **逐点完全相同** |
| **Ours（DEGC）** | 22 → 0.059；50 → 0.042；63 → 0.034；92 → 0.025；122 → 0.017（误拒均为 0.024） |
| Oracle（参照状态） | 0 → 0.042 / 0.024 |

B5、B6、B8 等确定性组以核验器原始的"是/否"为准。另一种做法是把校准后验按 0.5 取阈，这种变体（`-cal`）明显更差：B6-cal 为 0.328，因为宽松核验器的"是"在校准后多数低于 0.5。两种变体都保留在 `analysis.json` 中。

**三类公平比较**：

| 比较 | 结果 |
|---|---|
| 相同预算 | ≤ 100 次调用：Ours 0.025，B7 0.034。≤ 250 次：Ours 0.017，B7 0.025。≤ 50 次：B7 0.034，Ours 0.042 |
| 相同危险放行水平（harm ≤ 0.045） | 误拒：B7、Ours、B5、B6 都是 0.024；B2 为 0.035 |
| 相同安全与效用（误拒 ≤ 0.024） | harm ≤ 0.017：Ours 122 次，B7 511 次，B6 571 次。harm ≤ 0.035：**B7 35 次**，Ours 63 次 |

**配对检验**（逐场景 bootstrap）：

- 在上述匹配点上，Ours 与 B7、B6 的逐场景结果**完全相同**（差值 0，区间 [0, 0]），差别只在调用数。
- 相同 δ、c 下：Ours 比 B7 少用约 5–43 倍的调用，危险放行率高 0.017–0.042。δ = 0.05、c = 2 及 δ = 0.1 时，区间不含 0，即 B7 显著更安全。
- Ours（122 次调用）对 B2（0 次）：危险放行 −0.025（区间 [−0.059, 0]），误拒 −0.012（区间 [−0.035, 0]）。**两个区间都包含 0**。

**稳健性**：

| 设置 | 结果 |
|---|---|
| 理想核验器 | B7 用 33 次调用达到 0.034，Ours 需要 56 次；**B7 占优** |
| max 合并（假设漏检完全相关） | B7 用 57 次达到 0.050，Ours 用 60 次只到 0.067；**B7 占优** |

## 4. 阶段 B′：受控仿真（新生成的测试世界，k = 1、2、3）

设置：
- 测试世界：k = 1 用 300 个，k = 2、3 用 100 个；另有一组 40 个世界的小规模配对运行，只用于 B7。
- 核验器准确率 0.95；桥接单元漏检率 0.4，相关系数 ρ = 0.5。
- k ≥ 2 的风险用 128 次蒙特卡洛采样估计。
- 指标为"新增重构率 / 误拒率（相对 Oracle 门控）"，调用数为每个世界的平均值。

|---|---|---|---|---|---|---|
| 1 | 0.237 / 0.006 | 0.087 / 0.100 | 0.077 / 0.164 | 0.057 / 0.080（7.3 次） | **0.053 / 0.084（0.64 次）** | 0.063 / 0.051（120 次） |
| 2 | 0.48 / 0.017 | 0.09 / 0.258 | 0.05 / 0.372 | 0.15 / 0.156（8.5 次）；v = 0.01 时 0.11 / 0.188（3.6 次） | 0.15 / 0.197（2.05 次）；40 个世界：0.20 / 0.238 | 0.15 / 0.097 |

| k | 比较 | 新增重构率差 | 误拒率差 | 调用 |
|---|---|---|---|---|
| 1 | Ours − B2 | −0.033 [−0.057, −0.013] | −0.016 [−0.022, −0.010] | 0.64 次 vs 0 |

## 6. 按验收标准判定

> 判定只依据任务书中的**预注册**验收标准（三条之一，加上"第二重熵有独立贡献"）。PREREG 第 1 节事后补写的"稳健性要求"和"2 倍节省阈值"**只是探索性标准，不属于预注册验收标准**（见 DEVIATIONS D3）。下表中"不稳健"一类的表述，同样属于探索性观察。

| 标准 | 判定 |
|---|---|
| 相同预算下显著降低危险放行 | **不满足**。≤ 100–250 次调用时 Ours 点估计更低，但逐场景差异只有 1 个场景，置信区间包含 0；≤ 50 次时 B7 更好 |
| 相同安全水平下显著减少误拒 | **不满足**。各组误拒都是 0.024，最多差 1 个场景 |
| 相同安全与效用下显著降低核验成本 | **部分满足，但不稳健**。真实核验器 + noisy-OR 下，harm ≤ 0.017 时 Ours 的调用约为 B7 的 1/4。但在 harm ≤ 0.035、理想核验器和 max 合并这三种情况下都反过来。而且操作点是在已暴露数据上挑的 |
| 第二重熵有独立贡献 | **不成立**。(1) Ours 与 EC2 完全相同，选择器无关紧要。(2) h(R) 触发（HZ）很差。(3) 节省调用的来源是"以 δ 为参照的校准区间触发"，相当于把核验成本 c_v 设为与区间宽度挂钩的 VoI 变体，不是新的不确定性。(4) 对 B2 的增益区间包含 0 |

**结论**：DEGC 作为"双重熵"方法论**不确立**。按任务书要求，保留负面结果，停止该候选机制，**不启动阶段 C**。

**唯一稳健的正向发现**不属于双重熵，而是"**校准后的概率知识状态 + 机会约束**"（B2，属于已有的贝叶斯决策）：在不做任何核验的情况下，把 B1 的 0.210 降到 0.042，误拒从 0.024 升到 0.035（相当于 1 个场景）。

- 原因：桥接表的观测概率被校准到 0.1–0.5，不再被当作 0。
- 这个结果来自已暴露数据上的交叉拟合，需要独立留出集验证。是否把它作为 CGC 的改进单独立项，由组会决定。
