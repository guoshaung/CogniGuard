# DEGC 理论：问题定义、建模与性质

> 本文档说明 DEGC（Dual-Entropy Governance Control，CGC 的决策层）的问题定义、数学建模与理论性质。
> 结论先行：按查新（`NOVELTY_AUDIT.md`）与本文的推导，**两重"熵"都是同一个后验重构概率 R 的函数**。
> - 决策规则等价于带不对称损失的贝叶斯决策或机会约束。
> - 核验选择属于 SBFE / EC2 / 面向决策的 EIG 一类方法。
>
> 可能独立的部分只有问题设定与系统组合：
> - 把 CA-PD 的 k 有界联盟见证覆盖作为被评估的布尔函数；
> - 用自然语言检测器的校准证据构造知识状态后验；
> - 发现并处理"状态偏离"失败模式。

## 1. 对象

| 符号 | 含义 |
|---|---|
| S | 受保护秘密（目标 t），先验最小熵 H₀ = −log₂ max_s P(s) |
| 𝒲(t) | 见证集合族：S 可由覆盖任一 W ∈ 𝒲 的知识恢复（单调 DNF） |
| K*_i ⊆ 𝒰 | 主体 i 的**真实**知识持有集合（未知） |
| E | 治理系统的全部观测：可信事件（主体自身数据、回执）和语义观测（值匹配、BGE + NLI、核验器输出） |
| a | 候选披露：把回答 x 交给接收方 r |
| U_a ⊆ 𝒰 | a 实际披露的单元（未知，只能观测到 o(a, u)） |
| k | 联盟规模上界 |
| C_k(K) | CA-PD 核：存在包含 r、规模 ≤ k 的联盟覆盖某个 W（`check_release`，**不改**） |

## 2. 知识状态后验（第二重不确定性的来源）

1. **校准，而不是把置信度当概率。** 每个观测 o(x, u) 映射到一个分箱 b(o)，分箱依据包括：
   - 精确匹配、语义命中、NLI 分段、余弦分段；
   - 该表是否为"桥接表"（去重后没有独有值）。

   在开发数据上，对每个分箱估计 θ_b = P(u ∈ U_x | b)，采用 Beta(1 + n⁺, 1 + n⁻) 后验。点估计 q = E[θ_b]，并给出 [q_lo, q_hi]（等尾可信区间，水平 ℓ）。
   - 普通分类置信度（NLI 概率、命中即为 1）**不**被当作持有概率。阶段 B 用 Brier 和 ECE 对比两者。
   - 核验器输出同样是观测，按"核验结果 × 是否桥接表"单独校准。
2. **可信事件与语义观测分开。** 可信事件（例如 Alice 自己的表）的概率为 1；语义观测和核验结果永远只是概率观测，不进入确定账本。这与 pe-1.0 一致。
3. **重复观测。** 同一 (i, u) 的多次观测，按 noisy-OR 合并（各次观测独立）或按 max 合并（完全相关）。两者给出真实依赖结构的上下界：桥接表的漏检在不同回答间是相关的。默认用 noisy-OR，并报告两种合并方式的敏感性。
4. **单元相关性。** 不同单元之间假设条件独立。见证内单元的正相关会让 R 被低估，所以用 max 合并做敏感性检验，并在受控仿真中加入相关漏检。

## 3. 第一重：隐私泄露熵

记 Z_a = C_k(K* ∪ U_a)，即放行 a 之后，某个 k 有界联盟能重构 S。在见证模型中，覆盖则 S 被完全恢复，否则攻击者仍处于先验状态：

  V(S | a, E) = R_a + (1 − R_a)·2^{−H₀}，其中 R_a = P(Z_a = 1 | E)

  L_a = H₀ − H∞(S | a, E) = log₂(V · 2^{H₀})　（最小熵泄露，见 Smith 2009）

L_a 对 R_a **严格单调**，所以"泄露熵 ≤ ε"与"R_a ≤ δ(ε)"等价。

**新增泄露**：令 R⁰ = P(C_k(K*) = 1 | E)，即历史上已经可重构的部分。约束只针对新增部分 ΔR_a = R_a − R⁰ ≤ δ，历史泄露不记到当前这次放行上（对应 Protocol B 的分层）。

**R 的计算**：在不确定的见证相关变量 {(i, u) : 0 < p_{iu} < 1} 上精确枚举，每个枚举结果调用 CA-PD 核。变量数超过 14 时改用 4,096 次蒙特卡洛采样。复杂度为 O(2^m · T_CAPD)，其中 m 是不确定的见证相关变量数。Sum Leaks 中 m ≤ 5。

## 4. 第二重：状态认知熵

决策只依赖 Z_a，所以与决策相关的状态不确定性是：

- **一阶**：H_E(a) = h(R_a)，即治理系统对"这次放行会不会完成重构"的不确定性。它只计入见证相关单元，非见证单元的不确定性不进入 H_E（见反例 1）。
- **二阶**：校准不确定性。把每个 θ_b 取到可信区间端点，得到 [R_lo, R_hi]。由于 C_k 对单元单调，R 对每个 θ 也单调，所以端点组合给出 R 的保守区间。在区间内各 θ 独立的条件下，这个区间是有效的；它并非严格的联合置信水平。

**关于用 h(Z) 作决策量（查新指出的问题）**：δ ≠ 0.5 时，h(R) 的最大值在 R = 0.5 处，与"R 相对 δ 的位置"无关。所以 DEGC **不**用 h(R) 触发核验，而是用 δ 相关的区间判据 R_lo ≤ R⁰ + δ < R_hi。h(R) 只用于选择核验对象：完全信息下的最优决策就是 Z 本身，EIG on Z 正是 Filstroff 等人提出的"对最优决策的期望信息增益"。另设用 h(R) ≥ η 触发的对照组 HZ，作为反例检验。

## 5. 决策机制与目标函数

**目标**：在每次放行满足机会约束 P(Z_a = 1 | E) − R⁰ ≤ δ 的前提下，使误拒（损失 c_ref）与核验成本（每次调用 c_v，总预算 B）之和最小。

**算法 DEGC**（每个请求）：

1. 计算 R, R_lo, R_hi 和 R⁰。
2. 若 R_hi ≤ R⁰ + δ：**放行**（校准不确定性下仍然安全）。
3. 当 R_lo ≤ R⁰ + δ < R_hi 且预算未用尽时，在见证相关、尚未核验的观测池中（**包括已放行的历史回答**，用于修复状态偏离）选择 argmax_o [h(R) − E_{o 的结果} h(R′)] 进行核验，然后更新 R。
4. 最终决定：R ≤ R⁰ + δ 则放行，否则拒绝。

**有界保守性（命题 1）**：DEGC 拒绝 ⟺ 点后验 R − R⁰ > δ。证明：步骤 4 只依赖点后验，区间宽度和 H_E 只影响是否核验。所以无论认知熵多高，都不会**仅仅因为不确定**而拒绝；误拒集合 ⊆ 点后验机会约束的误拒集合。

**安全界（命题 2）**：若校准正确（θ_b 是真实条件频率），每次放行的新增重构概率 ≤ δ。在 n 次放行的会话中，期望新增重构数 ≤ nδ；若另设累计预算 ΣΔR ≤ B_R，则 P(会话内发生新增重构) ≤ B_R（联合界）。**校准错误时，这个界不成立**，偏差量等于校准误差（见 ECE）。

**等价性（命题 3，否定性）**：
- 设 VoI 的损失为 L(放行) = ΔR，L(拒绝) = λ。其贝叶斯决策是 ΔR ≤ λ；取 λ = δ 时，与步骤 4 **完全相同**。
- DEGC 与 VoI 只在"何时核验、核验谁"上不同：区间触发 + EIG，对比 VoI > c_v + 期望损失下降。
- 所以 DEGC 是否有独立贡献，是一个**经验问题**，必须在相同预算下与 B7（VoI）和 EC2 比较。

## 6. 反例（阶段 A，`cogniguard/tests/test_degc.py`，14 项全部通过）

| 反例 | 设置 | 期望 / 结果 |
|---|---|---|
| 低泄露、高状态熵 | 6 个不确定单元都不在见证中 | R = 0，DEGC 不核验即放行；只看认知熵的 B3 浪费了 2 次核验 |
| 高泄露、低状态熵 | a 已持有，b 的观测概率 0.99 | 不核验，直接拒绝 |
| 联合单元与状态偏离 | 见证 {a, b, c}，早期 a、b 的观测概率各 0.4，当前 c 确定 | MAP 确定性门控放行；DEGC 得到 R = 0.16 > δ。核验 a 后，按真实情况分别拒绝或放行 |
| 有界保守性 | R_hi > δ ≥ R，预算为 0 | 放行 |
| 历史泄露不归因 | 见证在释放前已被覆盖 | R⁰ = 1，不拒绝 |
| 联盟 | A 持有 a、B 持有 b | k = 1 时安全，k = 2 时 R = p_b |
| 数值与校准 | 包含-排除精确值；Beta 分位数；合成数据上的 ECE、区间覆盖；相关性上下界 | 全部通过 |
