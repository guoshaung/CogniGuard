# DEGC 与校准概率状态：组会摘要

## 一句话结论

**双重熵（DEGC）不成立，按 STOP 处理。**

真正起作用的机制是"**在 CA-PD 的历史知识状态里，对校准后的弱证据做概率累积**"。它在已暴露数据上的效果显著，但还没有达到"稳定优势"的标准。

## DEGC（STOP）

- **查新**：
  - 决策规则就是带不对称损失的贝叶斯决策或机会约束；
  - 核验选择属于 SBFE、EC2，以及"对最优决策的期望信息增益"（Filstroff 2021）；
  - 在见证模型中，两重熵都是同一个重构概率 R 的函数。
- **阶段 B 结果**：
  - Ours 与 EC2 逐点相同；
  - 对 B2 的增益，置信区间包含 0；
  - 对经典 VoI：只在"真实核验器、noisy-OR 合并、低风险区间"下调用更少（harm 0.017 时 122 次对 511 次）；在理想核验器、max 合并，以及 k = 2、3 的仿真中都反转；
  - 用 h(R) 触发核验（HZ）明显较差。
- **按预注册验收标准判定**：第二重熵没有独立贡献，DEGC 不确立。事后补写的稳健性要求和"2 倍节省"阈值**只是探索性标准**，不参与判定。

## 0.21 → 0.04 的审计（0 次核验，已暴露数据）

| 来源 | 危险放行变化 | 误拒 |
|---|---|---|
| 把校准当分类器用（修正桥接表的弱 NLI 证据） | −0.084（显著） | 不变 |
| 降低校准阈值 | −0.025 | 不变 |
| **历史状态的概率累积（L3h）** | **−0.059（显著）** | **不变** |
| 当前回答也概率化 | 0 | 多 1 个误拒场景 |
| 更保守的拒绝（拒绝数匹配的安慰剂） | 只到 0.164 | 0.137 |
| 未校准概率 / 去掉见证结构的贝叶斯风险 | 降到 0.017 | 0.60–0.78，不可用 |

- 两组的分母、保护目标、危险放行定义和初始信息**完全一致**。
- 在各种分折方案下结果都稳定：5 折（多个种子）、留一场景、按来源家族分组（66 个家族）。
- **风险**：
  - 校准和评测都依赖 glm-5.2 标签，不是人工金标准；
  - 训练标签只要有 5% 的对称噪声，误拒就升到 0.21；
  - 受控仿真中，它只是一条安全–效用权衡曲线，而不是"免费"的改进。
- **k = 2、3 的联盟风险**：
  - 256 次蒙特卡洛采样的决策翻转率约 1.7–2.8%，1,024 次时为 0.3–1.5%；
  - 合并方式（noisy-OR 对 max）的影响大于相关系数 ρ；
  - **联盟条件下概率状态非常保守**：相同 δ 时误拒为 0.34–0.40，B1 约 0.02。这是负面结果。

## 建议（等组会定）

1. 保留 DEGC 的 STOP 结论；CGC 不采用"双重熵"名称。
2. 候选机制只保留一个："概率化历史状态的 CA-PD"（L3h：当前回答确定性检测，历史状态用校准概率累积，并加机会约束）。
3. 先做 200–300 对人工标注，量化标签噪声并重新校准；之后再做等价性查新和独立留出的端到端实验（`PROTOCOL_B3_DRAFT.md`）。
