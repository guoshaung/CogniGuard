## 1. 阶段 B 的判定规则

> **时间说明（诚实披露）**：验收标准的三条和"第二重熵必须有独立贡献"来自任务书，实验前即已确定。下面的"稳健性要求"和"显著 = 区间不含 0 / 调用节省至少 2 倍"这两项**是在看到阶段 B 结果之后补写的**，见 DEVIATIONS.md D3。如果去掉这两项，"相同安全与效用下降低核验成本"这一条在真实核验器 + noisy-OR 设置下名义上成立（harm ≤ 0.017 时调用为 122 对 511）。但判定仍不变，因为任务书自身要求"第二重熵具有独立贡献"，而这一条不成立：Ours 与 EC2 逐点相同；Ours 对 B2 的危险放行和误拒差异区间都包含 0。

- 进入阶段 C 的条件：在**真实 LLM 核验器**下，至少满足以下一条，且不以明显牺牲其他关键指标为代价：
  - 相同预算下显著降低危险放行；
  - 相同安全水平下显著减少误拒；
  - 相同安全与效用下显著降低核验成本。
- 【探索性标准，事后补写，不是预注册验收标准】稳健性要求：同一结论在理想核验器、max 合并，以及受控仿真（k = 1、2、3）中不得反转。
- 【探索性标准，事后补写，不是预注册验收标准】"显著"的操作化：逐场景配对 bootstrap 的 95% 置信区间不含 0；对调用数，要求在匹配点上至少节省 2 倍，并在所有稳健性设置中保持同号。
- 第二重熵的独立贡献：Ours 对 B2、B7、EC2 都要满足上述条件。
