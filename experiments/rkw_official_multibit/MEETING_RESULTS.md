# RKW 组会阶段结果

本轮优先核对作者公开的 Qwen2.5 版本。原论文 TinyLlama-1.1B 主表权重仍未公开定位。现阶段可汇报的是官方解码器已在 RTX 5090 以 BF16 实测，主实验正在等待编码器权重。两条官方原文均有 8 个解码分数，完整匹配交替目标码为 0/2。CPU 与 GPU 的 16 位判定中有 1 位变化，发生在分数接近零的一句。

## 5090 持续采样

北京时间 23:45 左右的 61 个样点跨 60.025 秒。GPU 利用率 0%，显存已用 2／32,607 MiB。主机 CPU 平均 14.50%，范围 13.03%–16.91%。主机可用内存约 607 GiB。数据盘剩余约 22.48 GB，md0 平均写入 1.72 MB/s。eth0 接收 1.96 MB/s、发送 0.094 MB/s。磁盘与网络读数是设备合计。采样期间主实验未进入推理，网络传输是当前瓶颈。

## 调度和进度

权重采用按文件分片断点续传，编码与核验分别驻留对应阶段，官方演示保留每样本一批 4 候选。生成的不同样本依次调用上游采样器，每个 token 跑两个编码器的前向。两例共享一轮模型加载。解码器和相似度模型在后续阶段各加载一次。作者采样器没有外部 API 调用。现阶段无法用资源采样推断模型前向吞吐。

GPU 负控的模型加载用时 1.20 秒，两条句级评分分别用时 0.566 秒和 0.018 秒，合计 16 句／0.584 秒。第二条热路径不宜单独外推。带水印样例完成 0／2，剩余 2，生成候选完成 0／8，剩余 8。有限 C4 已冻结 8 条校准和 16 条测试，完成 0／24。知识来源迁移仍等待原生阶段结果。

权重完整并校验后，服务器已部署的任务依次运行 Qwen 演示和 C4。已有真实输出见 `results/decoder_controls_gpu.jsonl`，逐秒采样见 `results/performance_60s.jsonl`。检测 AUC、比特准确率、完整载荷、误归因和知识保真以对应实际实验为准。

Windows 侧已取得并核对官方 MPNet，复用服务器上的 128 MiB 前缀，余下 303.75 MB 拆为八路并行上传。余段耗时 164 秒，平均约 1.85 MB/s。437,971,872 字节的重组文件通过官方 SHA-256，已停止重复的 MPNet 传输。编码器续传与依赖它的两个评测仍在服务器运行。截至 23:53，两个编码器共已落盘约 23.12／60.93 GB，约 37.95 GB 待传或校验。

并行核查已验证官方 C4 训练集 160,000 条、测试 10,000 条和 Pegasus 改写对 10,115 对。蒸馏和 LoRA 各完成一次 CPU 优化及权重重载，使用两条合成序列。这一结果覆盖执行入口，真实水印继承、来源误归因、知识保真和任务效用待有冻结的教师、学生和迁移评估数据后测量。详见 [资产清单](ASSETS_MANIFEST.json) 和 [训练准备](training/README.md)。
