# RKW 继承与来源识别基线核查

2026-11-25 核对原论文、上游公开代码和运行说明。三种方法各自对应不同的观测单位。ReasMark 检测被训练进模型的推理行为，TextSeal 的继承实验检测跨样本聚合的 token 偏好，SemTrace 检测给定文稿副本是否影响了生成评审。RKW 另有从输出恢复已知稳定来源 ID 的要求。

## ReasMark

- ACL 2026 原论文先在教师模型上做 QLoRA，用目标领域的高频提示词构造长、短触发词集，并通过训练损失建立提示得分与推理长度的相关性。验证时对可访问推理轨迹的疑似学生模型查询成对提示，计算平均推理长度差、单侧配对 t 统计量和 p 值。检测单位是模型及领域，论文未定义逐文档载荷或逐条来源 ID。现成文本上无法直接施加同一机制。 [原论文 §4–5](https://aclanthology.org/2026.acl-long.2185.pdf)
- 默认 DeepSeek-R1-Distill-Qwen-1.5B 教师和学生，OpenMathReasoning 主实验按领域构造互斥的 20,000 水印训练、20,000 蒸馏和 200 测试示例。Table 8 的 LoRA 指令微调是蒸馏后额外处理，报告推理长度差的 p 值 0.045。蒸馏和后续 LoRA 是否继承，应分别报告。论文同时测任务正确率，不能用 p 值代替单题正确率或来源识别率。 [原论文 §5.1、§5.7 与 Table 8](https://aclanthology.org/2026.acl-long.2185.pdf)
- ACL 页面、论文正文与 GitHub 仓库名检索均未定位作者确认的实现或可用训练后检查点。当前可用作论文对照。若从论文实现，需标记独立复刻，并用相同采样预算、推理轨迹可见性和测试提示，比较原模型、带标教师、带标输出训练的学生与无标输出训练的学生。逐条来源指标为不适用。 [ACL 论文入口](https://aclanthology.org/2026.acl-long.2185/)

## TextSeal

- 原论文的 TextSeal 在生成时以两把密钥对 Gumbel-Max 采样进行路由。检测器对同一文本按密钥融合计分，输出 p 值并支持标记片段定位。两把密钥是采样设计，官方接口没有任意多比特消息恢复。分配每来源独立密钥并扫描多个密钥属于额外的闭集归因协议，需要同一候选预算和随目录规模校正误接受水平。 [原论文 §3](https://arxiv.org/html/2605.12456v1#S3) · [官方 v2.0.0 生成与检测入口](https://github.com/facebookresearch/textseal/blob/23f921f0646a22848934f0e6700de0671c28b889/docs/README_textseal.md)
- 官方仓库同时提供事后改写接口。它从既有文本重新生成一份带水印的释义，适合与 Xu 等人的事后编码器共享输入底稿。公平比较需记录改写器、生成预算、长度、实际改写及知识保真。直接生成版则需与同模型、同提示、同解码参数的无标记生成配对。 [官方事后 API](https://github.com/facebookresearch/textseal/blob/23f921f0646a22848934f0e6700de0671c28b889/docs/README_posthoc_api.md) · [事后改写论文](https://arxiv.org/abs/2512.16904)
- 原生继承使用 DeepSeek-R1-Distill-Qwen-14B 的过滤推理轨迹对 Qwen2.5-3B 做 LoRA。继承检测是白盒 teacher forcing，在训练轨迹的上下文上查询学生 top-1 并对 token 聚合、去重。论文分别控制训练轨迹数和字符预算，并用 GSM8K 测任务效用。官方仓库可核对生成、检测和通用训练入口。完整原生继承复现仍需核对原筛选数据与训练脚本能否匹配 §E.4，公开接口小样本只能作为适配验证。若加测学生自由生成，每条检测和闭集来源识别应另列。 [原论文 §6](https://arxiv.org/html/2605.12456v1#S6) · [原论文 §E.4](https://arxiv.org/html/2605.12456v1#A5.SS4) · [官方固定版本](https://github.com/facebookresearch/textseal/tree/23f921f0646a22848934f0e6700de0671c28b889)

## SemTrace

- Exact-12 在原 PDF 中为已知文稿副本指定 12 个二进制位置，从 24 条文稿支持事实中为每个位置选择一条，通过文档条件约束引导模型把事实带入结构化评审。固定 DeBERTa-v3-small NLI 按事实对检测，允许擦除，至少观测 8 位才参与已知目标码评分。该流程在输出生成前改造输入文档，要求文档通道保留载体并由评审模型遵循约束。原实验评估已知副本的暴露检测，对照相同文稿的未标记版。准确率按非擦除位计算。 [原论文 §3–4](https://arxiv.org/html/2608.29575v1#S3) · [Exact-12 评测协议](https://arxiv.org/html/2608.29575v1#S4)
- 原论文报告干净评审与黑盒改写，未提供蒸馏或 LoRA 学生继承实验。迁移到正文较短的 OpenStax 时，应报告是否仍能提出满足约束的事实对，以及固定位数、可观测位数和擦除率。盲闭集来源评价需要对所有候选来源使用同等预算，补充错误来源选择率与拒识。事实可直接产自独立资料，应设置自然事实重叠的负例。 [原论文 §4 与附录](https://arxiv.org/html/2608.29575v1)
- 论文 HTML、摘要与可检索仓库中未找到作者确认的该方法实现、原始事实对和评审结果。公开同名仓库分别做文本嵌入反演和图像生成检测。当前只能做论文对照，若移植需标记独立复刻。 [原论文](https://arxiv.org/abs/2608.29575) · [文本嵌入反演仓库](https://github.com/trans/semtrace) · [图像检测仓库](https://github.com/HanhaiNotHai/SemTrace/tree/9b8aefb1fcfed4f780270f8ad3f6cf9873405e23)

## 同一指标的适用条件

- 模型继承组公开训练分组、测试隔离、教师与学生权重、生成和调参预算、过滤后有效样本与 token 数。报告推理行为差或聚合先验偏好的方法，用于衡量模型继承证据。对黑盒和白盒结果分别标注访问条件。
- 来源恢复组固定稳定来源 ID 码本、候选范围、拒识门槛与多重比较校正，评估完整载荷、擦除、错误载荷接受、Top-1 与集合 F1，同时设置无标记和自然事实重叠负例。已知副本暴露评分是独立任务。每条输出另报告知识保真和效用，水印残留为归因提供证据，最终认定仍需要排除自然重合与其他来源。
