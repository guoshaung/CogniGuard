# 官方 Qwen 样例的传播诊断

原八位目标为 10101010。使用冻结的两条入选改写及其未加水印原文，分别执行单跳摘要、改写和双文本融合。传播模型为本机 CPU Qwen2.5-0.5B Instruct。十次调用均自然结束。官方 BF16 句级解码器在 CPU 评分，保留全部浮点分数。先前 GPU 原始负控有 1/16 位因设备数值差异跨过零，本诊断仅在同一 CPU 路径内部比较。

- 摘要两条带码输入的输出分别解对 2/7、4/5 位，完整八位恢复 0/2。对应无标记对照为 1/3、6/8 位。
- 改写两条带码输入均为 6/8 位，完整八位恢复 0/2。对应无标记对照为 2/8、6/8 位。
- 双文本融合的带码输入输出为 7/8 位，未加水印对照为 3/8 位。两份输入是同一技术摘要的英中文版本，且共用一个码。这一场景只测共享码的融合行为，来源区分仍待验证。

十份输出中完整目标码匹配 0/10。带码原文在编入后已存在 1 位错误，因此这些数据反映传播后对目标码的恢复情况。英文带码摘要和改写仍提到 1.1B、99.99% 和 AUC。中文带码摘要仍把指标写成准确率，并省略 1.1B；两臂的改写中也出现生成的占位网址。摘要指令有未压缩到指定句数的个例。该批范围为两篇官方示例、一个传播模型、单跳探索性诊断，不能估计固定 FPR 下的 TPR 或发行身份 Top-1。 [逐条实测](results/official_demo_propagation.jsonl)
