# 官方水印与训练资产核对

- 官方固定提交 `7439ecee8891c6e8226f02fa8c1a650d3e10aaff` 的 C4 训练集 160,000 条、测试集 10,000 条、Pegasus 原文与改写对 10,115 对均已完整缓存在上游工作树。文件逐一与 Git 对象核对。用 casefold 和空白规整后，训练与测试文本的唯一交集为 0，Pegasus 对的原文和改写与测试文本的唯一交集分别为 0。这项检查覆盖逐文本重复。 [固定版本中的数据](https://github.com/xiaojunxu/multi-bit-text-watermark/tree/7439ecee8891c6e8226f02fa8c1a650d3e10aaff/data)
- 作者在发布答复中指向官方 `watermark_demo.py`。该脚本使用两套 Qwen2.5-7B 编码器和 Qwen2.5-1.5B 解码器。作者主页、GitHub 发布与标签、仓库历史和 Hugging Face 模型检索均未定位论文 TinyLlama 水印编码器与解码器的训练后权重。仓库里唯一的 checkpoint 文件是 Qwen 演示使用的 value head。 [作者答复](https://github.com/xiaojunxu/multi-bit-text-watermark/issues/1#issuecomment-3080276330) · [公开模型](https://huggingface.co/xiaojunxu/models) · [演示源码](https://github.com/xiaojunxu/multi-bit-text-watermark/blob/7439ecee8891c6e8226f02fa8c1a650d3e10aaff/watermark_demo.py)
- 官方训练脚本的默认骨干为 TinyLlama-1.1B-Chat-v1.0 编码器和 TinyLlama-1.1B-intermediate-step-1431k-3T 奖励模型。已下载两个固定 revision 的配置和 tokenizer。公开骨干权重均约 2.2 GB，仍待下载。其下载与主实验共用本机网络。 [编码器骨干](https://huggingface.co/TinyLlama/TinyLlama-1.1B-Chat-v1.0/tree/fe8a4ea1ffedaf415f4da2f062534de366a451e6) · [奖励模型骨干](https://huggingface.co/TinyLlama/TinyLlama-1.1B-intermediate-step-1431k-3T/tree/59f6f375b26bde864a6ca194a9a3044570490064)
- 官方 LoRA 初始化使用 `pretrain_DMparaphrase.py --use_lora`。之后的奖励模型与 PPO 训练还需要初始化编码器和解码器 checkpoint。Windows 主环境缺少 `datasets`、`peft`、`deepspeed` 和 `sentencepiece`。已缓存 `peft 0.8.1` 与 `datasets 3.1.0` 的官方 wheel，并按 PyPI release SHA-256 校验。已找到的正式预注册涵盖官方 Qwen 和 C4。原仓库中未找到独立冻结的蒸馏或 LoRA 继承训练协议，相关配置以训练分支的实验登记为准。 [官方训练入口](https://github.com/xiaojunxu/multi-bit-text-watermark/blob/7439ecee8891c6e8226f02fa8c1a650d3e10aaff/run.sh) · [依赖锁定](https://github.com/xiaojunxu/multi-bit-text-watermark/blob/7439ecee8891c6e8226f02fa8c1a650d3e10aaff/requirements.txt)
