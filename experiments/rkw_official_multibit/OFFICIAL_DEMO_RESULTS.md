# 官方 Qwen 演示实测

5090 上的 BF16 发布版完成两篇官方样例和全部八个候选。两个源文本分别为英文和中文。全部候选自然结束，均有八个可解码句子。目标码为 `10101010`，两篇按官方评分选出的最佳候选均解为 `10001010`。Best-of-4 的位准确率为 14/16（87.5%），完整八位恢复 0/2。八个原始候选合计 45/64 位正确，完整恢复 0/8。以上分母为演示样例。 [逐句分数与文本](results/official_demo_predictions.jsonl)

英文终稿仍保留 1.1B 和检测 AUC 99.99%，编码和解码步骤的表述更含混。中文终稿把“检测 AUC 可达 99.99%”改写为“准确率可达 99.99%”，指标发生改变，MPNet 相似度仍约 0.980。这个候选缺少严格知识保真。 [逐句分数与文本](results/official_demo_predictions.jsonl)

生成模型加载 37.29 秒，英文和中文四候选批次分别耗时 188.22 和 182.96 秒。去除 EOS 与补齐位后共有 1,649 个输出 token，实测约 4.44 输出 token/s。解码与 MPNet 加载 2.67 秒，八个候选评分合计 1.16 秒。生成采用既有 BF16 CPU offload 和原始逐 token 双编码器前向。有限 C4 原生复测已经接续，AUC、固定 FPR 下的 TPR、四位完整恢复率和错码误接受率等待其输出。OpenStax 来源迁移和学生模型继承另需具有真实来源与有效载荷的独立样本。
