# E5 合成数据上的组合推断保护：预注册

> 冻结前不得运行第 4 节的正式配置（种子 0–9）。冻结方式：本文件提交后，将 sha256 写入 `PREREG_E5.sha256`，与本文件在同一个提交中推送。之后对本文件的任何修改都记入 `DEVIATIONS.md`。
> 模型定义以 `FORMAL_DEFINITION.md` v0.1 为准（秘密、单元、L / L\*、τ、推导集、引理 1）。

## 1. 评估范围

**纯结构评估**：单元按谓词交付，不经过文本，也不调用大模型；推导集由谓词精确算出（引理 1）。
- 能回答：在 A1–A3 成立（计量器可靠、谓词充分、先验正确）时，各种记账方式能否阻止有界合谋，以及正常学习要付出多少代价。
- 不能回答：文本层面的泄露。H4 只描述 LexicalMeter 离 A1 有多远，不进入主结论。

## 2. 数据

- 合成数据集 `$COGNIGUARD_DATA_DIR/synthetic`（生成器 `experiments/datasets/synthetic/generate.py`，种子 2026；F = 6，V = 3）。数据不进仓库，`MANIFEST.json` 的 sha256 记入 `results/environment.json`。
- K ∈ {8, 16, 32}，每种 200 个秘密，丢弃数为 0（见 MANIFEST），因此**不调整 V**。
- 恒等增益、均匀先验，τ = log₂K − 1；每个秘密 6 个单元，无截断。
- 每种 K 的 200 个秘密构成一张登记表，各 K 分开运行。

## 3. 请求流（与 E2 相同）

- N = 60；合谋小组 6 组，g = 2、2、3、3、4、4；每组随机取一个秘密的一个推导集，单元按轮流方式分给组员。
- 其余学生：比例 c ∈ {0, 0.2} 为完整学习者（各请求一个完整推导集），其余为普通学习者（各随机请求 r = 4 个单元）。
- 种子 s ∈ {0, …, 9}；请求顺序随机打乱。
- 每个请求三个候选：full（交付该单元，效用 1.0）、summary（不交付单元，效用 0.4）、refuse（效用 0）。

## 4. 对照组与参数（全部运行，不得事后增删）

| 组 | 参数 | 说明 |
|---|---|---|
| no_defense | — | 总是选 full |
| per_recipient_bits | B ∈ {1, 2, 3, 4, 6, 8, 12} 比特 | 每个接收者累计获得的 Σ_σ ΔL\*（只看他自己的视图）≤ B；超出就降级 |
| global_bits | ρ ∈ {0.5, 0.75, 0.9, 0.95, 0.98, 1.0} | 全体共享一个预算 B = ρ × 同一请求流在 no_defense 下的总花费；每次交付按接收者自己视图的 ΔL\* 扣费 |
| pairwise_only | k ∈ {2, 3, 4} | 同一个 `ReleaseGate`，但只登记大小 ≤ 2 的推导集（模拟只做成对联合校准）；没有这类推导集的秘密不登记 |
| ours | k ∈ {2, 3, 4} | `ReleaseGate` 登记全部推导集，λ = 0 |

共 20 个配置 × 3 个 K × 2 个 c × 10 个种子 = 1200 次运行。
预算网格的依据（运行前由数据统计得到，不看任何对照组结果）：单个单元的 L 均值是 1.27、1.51、1.55 比特（K = 8、16、32），最大值不超过 τ。普通学习者 4 个单元约需 5–6 比特。

## 5. 指标

- **违规率**：合谋小组中，其合谋视图 A_C（组员实际拿到的单元的并集）对某个秘密满足 L\*(A_C) > τ 的比例。
- **最大合谋泄露**：每次运行中，6 个小组对各自目标秘密的 L\*(A_C) 取最大值（比特）。
- **FAR_normal**：普通学习者的请求中，没有拿到 full 的比例（降级和拒绝都算）。
- **UR_normal**：普通学习者实际获得的效用 ÷ no_defense 下的效用。
- CR_complete（完整学习者没有拿到 full 的比例）、平均决策耗时：只描述。

## 6. 假设与判定

- **H1（实现核对）**：ours 在所有 g ≤ k 的小组上违规为 0，所有 K、c、种子都成立。否则判为不支持，说明实现有错。
- **H2（实现核对）**：对每个 k，pairwise_only 在**所分配推导集大小 w = 2** 的小组上违规为 0，在 w ≥ 3 的小组上合并违规率 > 0。
  - 与草案的差别：草案写的是"按秘密的最小推导集大小分组"。但推导集都是极小的，一个最小推导集大小为 2 的秘密，其大小为 3 的推导集同样拦不住；所以改为按小组实际拿到的推导集大小分组。
- **H3（主假设）**：参照点为 ours（k = 4）。在每个单元格（K, c）中，对每个预算类对照组（per_recipient_bits、global_bits），凡是种子平均 UR_normal ≥ UR_ours(k=4) − 0.02 的参数，都要满足：违规率差（对照组 − ours）按种子做配对 bootstrap（5000 次，随机种子 20261123），95% 区间的下界 > 0。
  - 单元格判定：没有符合效用条件的参数，记为"不可比"；有符合条件的参数且全部通过，记为"支持"；任一参数没通过，记为"不支持"。
  - 每个对照组的判定：任一单元格不支持，就是不支持；至少一个单元格支持且没有不支持，就是支持；全部不可比，就是无法判定。
  - H3 整体：两个对照组都支持才算支持。
- **H4（描述性）**：LexicalMeter（默认阈值 n = 4、覆盖率 0.5、LCS 0.3）在合成文本上的表现。单元库存放每个单元用模板 0（"Item property {f} is {v}."）渲染的句子，计量范围是该文本所属秘密的 6 个单元。报告：unit、combo 文本的单元漏判率、文本漏判率、每段多算的单元数；decoy 文本的误判率。不做判定。
- 最大合谋泄露、pairwise_only 与 ours 的比较、k 的影响：只描述。

各假设按"支持 / 不支持 / 无法判定"报告。不得在看到结果后增减假设，或改动指标、参数网格、参照点。
